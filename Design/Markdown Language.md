# Banyan Flavored Markdown
Banyan Flavored Markdown（BFM）以 Obsidian 的 Markdown 為基礎（CommonMark ＋ GFM ＋ Obsidian 擴充），再加上兩類東西：
1. **引用 Banyan 的物件**：文獻、檔案、註解都有 BibTeX 式的**引用鍵**（`@kahneman2011`），用同一套 `@` 語法引用；卡片與白板用內部 id。
2. **進階排版**：字型、分欄、分頁、注音、直排、圖表編號、文獻引用，給之後的 Writer、Publisher、Slides 使用。

使用者看到的是 **Notion 風格的所見即所得編輯器**（見「編輯器」）：由區塊組成、打字時自動轉成格式，不需要看到原始符號。BFM 是編輯器**存檔的格式**，也是匯出、貼上、進階使用者切換「原始碼」時看到的文字。

> 狀態（2026-11-13）：引擎核心（企劃書 P0a）與所見即所得編輯器（P0b）已實作，程式在 `src/markdown/`。卡片已用它顯示與編輯：基礎語法、GFM（表格、刪除線、待辦、自動連結、腳註）、螢光筆與顏色、`[[ ]]`（卡片，存檔時建立卡片連結）、`#標籤`、數學式、提示框、`%% %%`、中文規則；編輯器有打字時自動轉換、快速鍵、`[[` 與 `@` 建議、雙擊編輯原文、貼上 Markdown。**引用鍵與書目已實作**：條目與註解的引用鍵（資料庫 v20）、`[@…]`／`@鍵`（APA）、`[[@鍵]]`、`![[@鍵]]`（條目卡片與引文；檔案的預覽尚未）、`::bibliography`、```` ```bibtex ```` 文件內書目、`.bib` 匯入匯出；引用格式只有 APA，`bibliography:` 文件屬性與「鍵轉成拼音」尚未。尚未實作：「編輯器」一章的 `/` 選單、區塊把手與拖曳分欄、浮動工具列、原始碼模式、`![[card:…]]`／`![[file…]]` 真正嵌入、屬性 `{…}` 與指令、上下標、`^段落標記`、行內腳註 `^[…]`、進階排版、交互參照、文件屬性、投影片、匯出。

# 設計原則
1. **純文字也讀得懂**：使用者平常不會看到原始文字，但匯出、版本比較、貼到別的程式時會；所以原始文字仍要像一份整齊的筆記。
2. **能用 Obsidian／Pandoc 的寫法就用**：使用者已經會的語法不重新發明；在 Obsidian 打開 BFM 檔案，基礎部分應該照常顯示。
3. **一件事只有一種寫法**：只有為了相容 Obsidian 才保留第二種（例如 `__粗體__`）。
4. **擴充只用通用語法**：新功能一律用「指令」（`:name[…]{…}`、`::name{…}`、`:::name … :::`）或「屬性」（`{…}`），解析器不必再改。只有非常常用的功能才給專屬的簡寫（目前：`[[ ]]`、`==`、`[@ ]`）。
5. **引用不靠標題**：標題可以重複、可以改名。文獻、檔案、註解用**引用鍵**（建立時產生、之後不會自動改變，和 BibTeX 一樣）；卡片與白板用 `類型:id`。顯示時一律換成目前的標題或引用格式。
6. **中文優先**：粗體、斜體、標籤、換行的規則要對中文友善（見「中日韓文字的規則」）。
7. **不認得就照原樣顯示**：不認得的指令顯示內容與名稱，不吞掉文字；匯出到其他格式時降級成普通 Markdown。
8. **跳脫交給編輯器**：使用者在編輯器中打的 `*`、`#`、`@`、`[[` 如果不是要當語法，存檔時自動加上 `\`；使用者不必知道跳脫規則。

# 編輯器
Notion 風格、所見即所得。卡片、Drawer 筆記卡片與之後的 Writer／Layout 文件都用同一個編輯器。

## 區塊
- 每個段落、標題、清單項目、引用、提示框、程式碼、表格、數學式、嵌入、分欄都是一個**區塊**。
- 滑鼠停在區塊上，左側出現把手：拖曳可以重排；拖到另一個區塊的左右邊緣建立**分欄**（存成 `::::columns`）。
- 把手選單：轉換成其他區塊類型、複製、刪除、複製區塊連結（產生 `^id`）、文字顏色與底色、對齊。
- 空白行顯示淡色提示「輸入 / 插入區塊」。

## `/` 選單
在空白行或行內輸入 `/` 打開插入選單，可以輸入名稱篩選（中英文都可以，例如 `/標題`、`/h2`、`/table`）：

| 分組 | 項目 |
|---|---|
| 基本 | 文字、標題 1–3、無序清單、有序清單、待辦清單、引用、分隔線 |
| 進階 | 提示框、摺疊區塊、程式碼、數學式、表格、腳註、目錄、分欄 |
| 嵌入 | 卡片、文獻、檔案（圖片、PDF、影片…）、註解、白板 |
| 引用 | 文獻引用、參考文獻清單、圖表編號 |
| 排版 | 換頁、換欄、留白、注音、直排區塊 |

## 打字時自動轉換
和 Notion、Obsidian 一樣，打出 Markdown 符號時立刻轉成格式，符號本身不留在畫面上：

| 輸入 | 結果 |
|---|---|
| `# `、`## `、`### ` | 標題 |
| `- `、`* `、`1. ` | 清單 |
| `[] `、`[ ] ` | 待辦清單 |
| `> ` | 引用 |
| `> [!note] ` | 提示框 |
| `---` | 分隔線 |
| ```` ``` ```` | 程式碼區塊 |
| `$$` | 數學式區塊 |
| `**文字**`、`*文字*`、`~~文字~~`、`==文字==`、`` `文字` `` | 行內格式（結尾符號打完時轉換） |
| `$式子$` | 行內數學式 |
| `[[` | 連結選單（卡片、文獻、檔案、註解） |
| `@` | 引用選單（文獻、檔案、註解） |
| `#` 接文字 | 標籤 |

- 轉換後立刻按 Ctrl＋Z，變回原本打的符號。
- 快速鍵：Ctrl＋B 粗體、Ctrl＋I 斜體、Ctrl＋Shift＋H 螢光筆、Ctrl＋K 連結、Ctrl＋E 行內程式碼、Ctrl＋Alt＋1～3 標題。
- 選取文字時出現浮動工具列：粗體、斜體、刪除線、螢光筆（5 色）、連結、引用、文字顏色、建立卡片（選取的文字變成新卡片，原處留下連結）。

## 物件在編輯器中的樣子
| BFM | 編輯器中 |
|---|---|
| `[[card:42\|標題]]`、`[[@kahneman2011]]` | 連結標籤（類型圖示＋目前的標題）；點一下開啟，滑鼠停留預覽 |
| `[@kahneman2011, p. 33]` | 依引用格式顯示的文字「（Kahneman, 2011, p. 33）」；點一下編輯頁碼與前後文字 |
| `![[…]]` | 嵌入區塊；滑鼠停留顯示「開啟」「改為連結」 |
| `$…$`、`$$…$$` | 轉譯好的數學式；點一下在原處編輯 LaTeX，旁邊即時預覽 |
| `%% 註解 %%` | 淡色、斜體的區塊，標示「不會匯出」 |
| `^p3` | 不顯示 |
| 不認得的語法 | 「原文晶片」：顯示原始文字，雙擊編輯，存檔時原樣保留 |

## 拖放與貼上
- 從右欄拖文獻、檔案、註解、卡片進文字：放在行內是**引用**（文獻、註解）或**連結**（卡片）；放在區塊之間是**嵌入**。拖曳時游標旁顯示會變成什麼，按住 Alt 切換。
- 從檔案總管拖檔案進來：加入檔案庫，並在放開處嵌入。
- 貼上：Markdown 文字照 BFM 解析；網頁內容（HTML）轉成對應的區塊；Word 的內容保留標題、清單、粗斜體與表格；貼上網址時詢問「連結／嵌入（YouTube、圖片）」。
- 複製：同時放入 BFM 文字與 HTML，貼到別的程式都正常。

## 原始碼模式
- 右上角「原始碼」切換成 BFM 文字（等寬字、語法上色），再切回來時重新解析。
- 給需要大量修改、找取代或從其他地方貼上 Markdown 的人；一般使用者不需要。

# 基礎語法
CommonMark 0.31 ＋ GFM，加上 Obsidian 常用的擴充。

## 區塊
| | 語法 | 備註 |
|---|---|---|
| 標題 1–6 | `# 標題 1` … `###### 標題 6` | `#` 後面**一定要有空格**；`#標題` 是標籤 |
| 段落 | 空一行分段 | |
| 換行 | 直接按 Enter | BFM 中**單一換行就是換行**（和目前的純文字卡片、Obsidian 預設相同） |
| 引用區塊 | `> 引用文字` | |
| 無序清單 | `- 項目`（也可以 `*`、`+`） | 縮排 2 或 4 個空格成為子項目 |
| 有序清單 | `1. 項目` | 從幾號開始就從幾號編 |
| 待辦清單 | `- [ ] 待辦`、`- [x] 完成` | 點核取方塊會改寫原始文字 |
| 程式碼區塊 | ```` ```語言 ```` … ```` ``` ```` | 語言名稱用來上色；`math`、`chart` 等特殊名稱見下方 |
| 分隔線 | `---`（單獨一行，前後空行） | 在投影片文件中是換頁（見「投影片」） |
| 表格 | GFM 表格，`:---`、`:---:`、`---:` 對齊 | 標題與編號見「圖表與交互參照」 |
| 腳註 | 內文 `[^1]`，文末 `[^1]: 說明` | 也可以寫行內腳註 `^[說明]` |
| 提示框 | `> [!note] 標題` | 見「提示框」 |
| 註解（不顯示） | `%% 只有編輯時看得到 %%` | 可以跨行；匯出時刪除 |

## 行內
| | 語法 | 備註 |
|---|---|---|
| 粗體 | `**粗體**` 或 `__粗體__` | |
| 斜體 | `*斜體*` 或 `_斜體_` | 中文旁邊建議用 `*`，`_` 在英數字中間不會生效 |
| 刪除線 | `~~刪除線~~` | 符號和文字之間**不能有空格**：`~~ 文字 ~~` 不會生效 |
| 螢光筆 | `==重點==` | 可以指定顏色 `==重點=={pink}`，見「螢光筆顏色」 |
| 行內程式碼 | `` `code` `` | |
| 上標／下標 | `x^2^`、`H~2~O` | Pandoc 寫法；`~` 一個是下標，兩個是刪除線 |
| 外部連結 | `[YouTube](https://www.youtube.com)` | 網址要有 `https://`，否則會被當成相對路徑 |
| 自動連結 | `https://example.com`、`<https://example.com>` | |
| 圖片 | `![說明](https://…)`、檔案庫的圖片 `![說明](@地圖-2026)` | 見「嵌入」 |
| 標籤 | `#標籤`、`#專案/子標籤` | 見「標籤」 |
| 行內數學式 | `$E = mc^2$` | 見「數學式」 |
| 跳脫 | `\*`、`\#`、`\[` | 任何 ASCII 標點前加 `\` 就是普通文字 |

### 螢光筆顏色
和 Annotator 重點相同的 5 個顏色：`yellow`（預設）、`green`、`blue`、`pink`、`purple`。寫法：`==文字=={pink}`。顏色用 `tokens.css` 的變數顯示，深淺色主題都可讀。

## 提示框
沿用 Obsidian 的寫法：

```markdown
> [!tip] 小技巧
> 內容可以有多段、清單、程式碼。

> [!warning]- 預設摺疊
> 標題後面加 `-` 預設摺疊，加 `+` 預設展開但可以摺疊。
```

支援的類型：`note`、`tip`、`info`、`warning`、`danger`、`quote`、`question`、`todo`、`example`。不認得的類型當成 `note`。

## 標籤
- `#` 後面緊接文字就是標籤；遇到空白、標點（含全形標點「，。、」等）就結束。
- 可以用 `/` 分層：`#讀書/哲學`。
- 純數字（`#1`、`#2024`）不是標籤，避免和編號混淆。
- 標籤可以點，搜尋有同樣標籤的卡片。**是否自動同步成卡片的標籤**見「待決定事項」。

# 引用 Banyan 的物件

## 引用鍵（文獻、檔案、註解）
文獻、檔案、註解都用 BibTeX 式的**引用鍵**表示，前面加 `@`。每個鍵對應一筆書目資料（見「書目格式」）。

| 物件 | 引用鍵的組成 | 範例 |
|---|---|---|
| 文獻（文獻庫條目） | 第一位作者的姓＋年份 | `@kahneman2011`、`@王2020` |
| 檔案（檔案庫條目） | 檔名（不含副檔名） | `@會議紀錄-2026-11` |
| 註解（重點、書籤） | 所屬條目的鍵＋`:h`（重點）或 `:b`（書籤）＋編號 | `@kahneman2011:h3`、`@kahneman2011:b1` |

**產生規則**
- 文獻：英文姓名轉小寫、去掉空格與重音（`García Márquez` → `garciamarquez`）；中日韓姓名**保留原文**的姓（`王小明` → `王`，`@王2020`），不轉拼音。BibLaTeX＋Biber 與 Pandoc 都支援中文的鍵；舊式 BibTeX（只接受 ASCII 鍵）需要時，匯出 `.bib` 可以勾選「鍵轉成拼音」，只影響匯出的檔案，不改 Banyan 中的鍵。沒有作者時用標題的第一個詞；沒有年份就省略年份。
- 檔案：檔名中的空白與不允許的符號換成 `-`。
- 重複時依序加 `a`、`b`、`c`…：`kahneman2011`、`kahneman2011a`。
- 註解：屬於哪個條目，就用那個條目的鍵。附件同時在文獻庫與檔案庫時（文獻的附件），用**文獻**的鍵；只在檔案庫的檔案用檔案的鍵。編號是這個條目中重點（或書籤）的建立順序，從 1 開始，刪除後不重新編號。
- 鍵可以使用中日韓文字、英數字與 `-`、`_`、`.`；`:` 只用在註解。不能以 `fig:`、`tbl:`、`eq:`、`sec:` 開頭（保留給交互參照）。

**建立後固定**
- 和 BibTeX 一樣，鍵在建立條目時產生，之後改作者、年份、檔名都**不會**自動改鍵，已經寫好的引用不會失效。
- 可以在條目詳情手動修改鍵；修改時，所有卡片與文件中的引用在同一個交易中一起改寫。
- 條目或註解被刪除後，引用顯示成紅色的「找不到 @鍵」，文字保留，重新建立同樣的鍵就會恢復。
- 另一個資料庫（文獻庫／檔案庫）的條目使用同一套鍵，在同一個資料庫檔中不會重複。

## 卡片與白板
卡片與白板沒有書目資料，用內部 id：`card:42`、`board:3`。編輯器中只看得到標題，id 只出現在存檔的文字裡。

## 連結：`[[ ]]`
```markdown
[[card:42|心流理論]]              ← 連到卡片
[[card:42]]                       ← 沒有文字時顯示卡片目前的標題
[[card:42#方法]]                  ← 連到卡片中的標題
[[card:42#^p3]]                   ← 連到卡片中標記 ^p3 的段落
[[@kahneman2011]]                 ← 連到文獻（顯示標題）
[[@kahneman2011:h3]]              ← 連到註解（顯示引文開頭）
[[心流理論]]                      ← 只寫名稱：照卡片標題尋找
```

- 編輯器中輸入 `[[` 出現搜尋清單（卡片、文獻、檔案、註解），選擇後插入連結標籤。
- 只寫名稱時（例如從 Obsidian 貼過來）照卡片標題尋找：找到唯一一張就連過去，存檔時改寫成 `[[card:id|標題]]`；找到多張或找不到時顯示成虛線連結，點一下讓使用者選擇或建立新卡片。
- `|` 後面是**顯示文字**。使用者改過的文字會保留；和物件改名前的標題相同時，跟著改名更新。
- 存檔時，`[[card:…]]` 建立卡片連結（`card_links`）；`[[@…]]` 與 `[@…]` 建立引用（`card_items`、`card_annotations`）。從內容刪掉連結時**不會**自動刪除連結，因為連結也可能是在白板上拖曳建立的。

## 段落標記：`^id`
每個區塊在存檔時可以帶一個 ` ^p3` 標記（只有被連到或嵌入的區塊才會加），讓 `[[card:42#^p3]]` 指到它。編輯器中不顯示；在區塊的把手選單選「複製區塊連結」時自動產生。

## 嵌入：`![[ ]]`
在連結前面加 `!`，把物件的內容顯示在這裡（唯讀，點一下開啟原物件）。在編輯器中是一個獨立的區塊。

| 寫法 | 顯示 |
|---|---|
| `![[card:42]]` | 卡片的內容（巢狀嵌入最多 3 層，循環時停止） |
| `![[card:42#方法]]`、`![[card:42#^p3]]` | 只顯示那一節或那一段 |
| `![[@kahneman2011]]` | 文獻資訊卡（類型圖示、標題、作者、年份） |
| `![[@kahneman2011:h3]]` | 引文區塊，加上重點顏色與出處，點一下跳回原文 |
| `![[@會議紀錄-2026-11]]` | 檔案預覽：圖片、PDF、影片、音訊（和 Drawer 預覽相同） |
| `![[@地圖-2026\|300]]`、`![[@地圖-2026\|300x200]]` | 指定寬度（或寬×高），單位是 px；編輯器中拖曳邊緣調整 |
| `![[@會議紀錄-2026-11#page=5]]` | PDF 從第 5 頁開始 |
| `![[board:3]]` | 白板的縮圖 |

要加圖說、編號或用在一般 Markdown 的寫法時，圖片也可以寫成 `![說明](@地圖-2026)`（網址的位置寫引用鍵）；網路上的圖片用 `![說明](https://…)`。

## 文獻引用：`[@ ]`
沿用 Pandoc 的引用語法。文獻、檔案、註解都可以引用：

```markdown
這個效應已被重複驗證 [@kahneman2011]。
多篇文獻 [@kahneman2011; @tversky1974]。
加上頁碼 [@kahneman2011, p. 33] 或前後文字 [見 @kahneman2011, 第 3 章]。
敘述式：@kahneman2011 指出……
不顯示作者 [-@kahneman2011]。
引用註解 [@kahneman2011:h3]          ← 頁碼自動取自註解的位置
引用檔案 [@會議紀錄-2026-11]
```

- 編輯器中輸入 `@` 搜尋文獻、檔案與註解；也可以從右欄把條目或註解拖進文字中。
- 依文件的引用格式（預設 APA，見「文件屬性」）顯示成「（Kahneman, 2011, p. 33）」之類的文字；滑鼠停留顯示完整書目，引用註解時另外顯示引文。
- 引用註解等於引用它所屬的條目加上位置：`[@kahneman2011:h3]` 顯示成「（Kahneman, 2011, p. 33）」，參考文獻中列的是 `kahneman2011`。
- `::bibliography` 放在要產生參考文獻清單的位置；沒有寫時，Writer／Publisher 匯出會自動加在文末。
- 和 `[[@…]]` 的差別：`[[ ]]` 是**筆記的連結**，`[@ ]` 是**正式的引用**，會依格式顯示並出現在參考文獻中。兩者都會讓卡片引用該條目或註解。
- 文字中的 `@` 後面接字（例如 `@某人`、電子郵件 `a@b.com` 前面是英數字的除外）在 Pandoc 中會被當成引用；編輯器存檔時，不是引用的 `@` 自動寫成 `\@`。

# 書目格式
文獻、檔案、註解都可以表示成 **BibTeX（BibLaTeX）式的書目資料**：`@類型{鍵, 欄位 = {值}}`。這是：
- 匯出 `.bib`、讓 Pandoc／LaTeX／Zotero 使用的格式；
- 從 `.bib` 匯入文獻時讀取的格式；
- 在文件中直接寫書目資料的格式（見「文件內的書目」）。

資料庫仍然存在原本的表格中（`items`、`attachments`、`annotations`），不是存成 BibTeX 文字；需要時轉換。

## 文獻
```bibtex
@book{kahneman2011,
  title     = {Thinking, Fast and Slow},
  author    = {Kahneman, Daniel},
  date      = {2011},
  publisher = {Farrar, Straus and Giroux},
  isbn      = {9780374275631},
  keywords  = {心理學, 決策},
  file      = {會議紀錄-2026-11}
}
```

| Banyan 類型 | BibLaTeX 類型 |
|---|---|
| 期刊論文、雜誌文章 | `@article` |
| 新聞 | `@article`（`entrysubtype = {newspaper}`） |
| 書籍 | `@book` |
| 書籍章節 | `@incollection` |
| 會議論文 | `@inproceedings` |
| 學位論文 | `@thesis` |
| 報告 | `@report` |
| 網頁 | `@online` |
| 軟體 | `@software` |
| 音樂、CD | `@audio` |
| 電影、DVD、電視節目、線上影片 | `@video` |
| Podcast | `@audio`（`entrysubtype = {podcast}`） |
| 演出類（演唱會、戲劇、音樂劇、歌劇、舞蹈、喜劇、音樂節、演講） | `@performance`（Banyan 擴充，匯出 `.bib` 時寫成 `@misc` 並保留 `type`） |
| 藝術類（繪畫、藝術品、照片、地圖） | `@artwork`（地圖為 `@misc`，`type = {map}`） |
| 文件 | `@misc` |

| Banyan 欄位 | BibLaTeX 欄位 |
|---|---|
| 標題 | `title` |
| 作者與身分 | `author`、`editor`、`translator`；其他身分（導演、演出者…）用 `editora` ＋ `editoratype` |
| 日期 | `date`（ISO 8601，例如 `2011-10-25`） |
| 刊名／出處 | `journaltitle`（期刊）、`booktitle`（章節、會議）、`maintitle` |
| 卷、期、頁 | `volume`、`number`、`pages` |
| 出版者、地點 | `publisher`、`location` |
| 叢書、叢書號 | `series`、`number` |
| DOI、ISBN、網址 | `doi`、`isbn`、`url` |
| 摘要 | `abstract` |
| 標籤 | `keywords` |
| 片長、媒材、尺寸、典藏號 | Banyan 擴充：`runtime`、`medium`、`dimensions`、`catalognumber` |
| 附件 | `file`：附件在檔案庫的鍵，多個用 `;` 分開 |

## 檔案
檔案庫的條目是 `@file`（Banyan 擴充；匯出 `.bib` 時寫成 `@misc`）：

```bibtex
@file{會議紀錄-2026-11,
  title    = {會議紀錄 2026-11},
  filename = {會議紀錄 2026-11.pdf},
  filetype = {pdf},
  size     = {482133},
  date     = {2026-11-12},
  keywords = {專案},
  related  = {kahneman2011}
}
```

`related` 是關聯的條目（文獻的附件會自動關聯到那筆文獻）。

## 註解
註解是 `@annotation`（Banyan 擴充，不匯出到 `.bib`，只在 Banyan 內與匯出筆記時使用），用 `crossref` 指向所屬條目：

```bibtex
@annotation{kahneman2011:h3,
  crossref = {kahneman2011},
  kind     = {highlight},          % highlight／bookmark
  color    = {yellow},
  pages    = {33},                 % 書籍為 chapter = {第 3 章}
  quote    = {Nothing in life is as important as you think it is…},
  note     = {和聚焦錯覺有關},
  date     = {2026-11-12}
}
```

## 文件內的書目
文件中可以用 ```` ```bibtex ```` 程式碼區塊直接寫書目資料，給還沒有放進 Drawer 的文獻使用：

````markdown
```bibtex
@article{smith2020,
  title = {…}, author = {Smith, John}, date = {2020}, journaltitle = {…}
}
```
````

- 只在這份文件中有效，可以用 `[@smith2020]` 引用；鍵和 Drawer 的鍵重複時，用文件內的版本並提示。
- 編輯器中顯示成可以摺疊的書目區塊，上方有「加入文獻庫」按鈕：加入後刪除這個區塊，引用改指向 Drawer 的條目。
- 也可以在文件屬性寫 `bibliography: 參考.bib` 指向檔案庫中的 `.bib` 檔。

# 通用擴充：屬性與指令

## 屬性 `{…}`
寫在元素的**正後方**（中間不能有空格），格式和 Pandoc 相同：

```markdown
## 研究方法 {#method}
==重點=={pink}
[這幾個字]{color=accent font="思源宋體"}
![地圖](@地圖-2026){#fig:map width=60%}
```

| 寫法 | 意思 |
|---|---|
| `#id` | 元素 id，用於交互參照 |
| `.class` | 樣式類別 |
| `key=value`、`key="有空格的值"` | 設定 |
| `{pink}`（只有一個字） | 只用在 `==螢光筆==`，表示顏色 |

可以加屬性的元素：標題（寫在行尾）、`[文字]`（行內區段）、`==螢光筆==`、圖片、程式碼區塊（寫在 ```` ``` ```` 那一行）、表格與數學式（見「圖表與交互參照」）、指令。

`[文字]` 後面緊接 `{…}` 才是行內區段；單獨的 `[文字]` 仍是普通文字。

## 指令
三種形式，名稱用英文小寫：

```markdown
:name[文字]{屬性}        行內指令

::name[文字]{屬性}       單行區塊（獨佔一行）

:::name{屬性}            容器（可以包任何內容）
內容
:::
```

- 容器可以巢狀：外層用更多的冒號（`::::columns` 包 `:::column`）。
- 只有名稱、沒有 `[ ]` 也沒有 `{ }` 的 `:name` 不是指令（避免把「比例 1:a」「note:abc」當成指令）。
- 不認得的指令顯示內容，並在旁邊標示指令名稱。

# 進階排版
這些語法主要給 Writer、Publisher、Slides 使用；在卡片中也能用，但有些（分頁、分欄）只在排版輸出時有效果，卡片上以提示線表示。

## 文字樣式（行內區段）
`[文字]{屬性}` 可以用的屬性：

| 屬性 | 範例 | 說明 |
|---|---|---|
| `font` | `font="思源宋體"` | 字型（找不到時用文件預設字型並提示） |
| `size` | `size=1.2em`、`size=14pt`、`size=small` | 字級；`small`、`large` 等對應 `tokens.css` 的字級 |
| `color` | `color=red`、`color=accent` | 文字顏色，只能用主題色名稱（深淺色主題都可讀） |
| `bg` | `bg=yellow` | 底色 |
| `weight` | `weight=600` | 字重 |
| `.smallcaps`、`.underline` | `[Banyan]{.smallcaps}` | 小型大寫、底線 |
| `lang` | `lang=ja` | 語言（影響字型選擇與斷行） |

## 對齊與區塊樣式
```markdown
:::center
置中的內容
:::

:::right
— 署名
:::

:::box{font="思源宋體" size=small border=true padding=1em}
任何區塊都可以用 box 包起來套樣式。
:::
```

## 分欄
```markdown
::::columns{widths="2 1" gap=1.5em}
:::column
左欄，佔 2/3。
:::
:::column
右欄，佔 1/3。
:::
::::
```

- 不寫 `widths` 時平均分配。
- 排版輸出中，`::columnbreak` 強迫換到下一欄。
- 卡片與窄視窗中，分欄寬度不足時改為上下排列。

## 分頁與間距
| 寫法 | 說明 |
|---|---|
| `::pagebreak` | 換頁（Writer／Publisher 輸出） |
| `::columnbreak` | 換欄 |
| `::space{h=2em}` | 垂直留白 |
| `::toc{depth=3}` | 目錄（依標題產生） |

## 注音與縱中橫
```markdown
:ruby[漢字]{rt="ㄏㄢˋ ㄗˋ"}
:ruby[東京]{rt="とう きょう"}      ← 用空格分開時，每個字各自對齊
:tcy[12]                            ← 直排中把數字橫放（縱中橫）
```

## 直排
- 整份文件：在文件屬性寫 `writing-mode: vertical`（由右至左）。
- 一部分：`:::vertical … :::`。
- 直排時，半形的兩位數數字自動縱中橫，三位以上維持轉向；需要時用 `:tcy[ ]` 指定。

# 圖表與交互參照
給圖、表、數學式、章節加上 `#類型:名稱` 的 id，就能用 `[@類型:名稱]` 參照，顯示成「圖 2」「表 1」「式 (3)」「第 2 節」，編號自動計算。

```markdown
![研究區域](@地圖-2026){#fig:map}

| 年份 | 數量 |
|---|---|
| 2024 | 12 |

: 各年份的數量 {#tbl:count}

$$
E = mc^2
$$ {#eq:energy}

## 研究方法 {#sec:method}

如 [@fig:map] 與 [@tbl:count] 所示，代入 [@eq:energy]……詳見 [@sec:method]。
```

- 圖：段落中只有一張圖片時，它是「圖」，`[說明]` 成為圖說。
- 表：表格下一行以 `: ` 開頭的是表格標題。
- 參照類型只有 `fig`、`tbl`、`eq`、`sec`，這四個字首保留，引用鍵不能用（見「引用鍵」），所以 `[@fig:map]` 與 `[@kahneman2011]` 不會互相衝突。
- 編號格式（「圖 2」或「Figure 2」）由文件的 `lang` 決定。

# 數學式
LaTeX 語法，使用 KaTeX 顯示。

| | 寫法 |
|---|---|
| 行內 | `$a^2 + b^2 = c^2$` |
| 獨立一行 | `$$` 開始、`$$` 結束（各自一行），或 ```` ```math ```` 程式碼區塊 |
| 化學式 | `$\ce{H2O}$`（mhchem） |

為了不把金額當成數學式：
- 開頭的 `$` 後面不能是空格，結尾的 `$` 前面不能是空格，後面也不能緊接數字。所以「$5 和 $10」不是數學式。
- 要寫錢字號時可以用 `\$`。

# 中日韓文字的規則
CommonMark 原本的規則對中文不友善，BFM 修改以下幾點：

1. **粗體與斜體旁邊可以接中文標點**：CommonMark 中 `**「引號」**後面` 不會變成粗體（因為 `**` 的一邊是標點、另一邊是文字）。BFM 採用 [markdown-cjk-friendly](https://github.com/tats-u/markdown-cjk-friendly) 的規則：符號旁邊是中日韓文字或全形標點時，也算是可以開始或結束強調。
2. **換行不插入空格**：BFM 的單一換行本來就是換行；匯出到其他 Markdown 時，如果要合併成同一段，兩個中文字之間不加空格。
3. **全形符號不是語法**：`＃`、`＊`、`＝＝`、`［［ ］］` 都只是文字；只有半形符號才有作用。
4. **標籤遇到全形標點就結束**：`#讀書，明天` 的標籤是「讀書」。
5. **`#標題` 沒有空格是標籤**：這和 CommonMark 一致，但中文使用者常漏打空格；編輯器在行首輸入 `#文字` 時，提示「要變成標題嗎？」。

# 衝突與跳脫
| 情況 | 規則 |
|---|---|
| 文字中要出現 `[[`、`==`、`%%`、`$`、`#` | 前面加 `\`，例如 `\[[`、`\==` |
| `C#`、`F#`、`#1` | 前面是英數字或後面是純數字時，不是標籤 |
| `a:b`、`10:30` | 沒有 `[ ]` 或 `{ }` 的冒號不是指令 |
| `a@b.com`、`@某人` | `@` 前面是英數字時不是引用；其他不是引用的 `@`，編輯器存成 `\@` |
| `[文字]{…}` vs. 參考式連結 `[文字][id]` | 後面是 `{` 才是行內區段，是 `[` 或 `(` 就是連結 |
| `~` 與 `~~` | 一個是下標，兩個是刪除線 |
| `---` | 文件最開頭是文件屬性；投影片中是換頁；其他情況是分隔線 |
| 程式碼中 | 程式碼區塊與 `` `行內程式碼` `` 中的一切都不解析 |

# 匯出與相容
| BFM | Obsidian | Pandoc／一般 Markdown |
|---|---|---|
| `[[card:42\|標題]]` | `[[標題]]` | `[標題](標題.md)` |
| `![[@地圖-2026]]` | `![[地圖 2026.png]]`，並複製檔案 | `![](files/地圖 2026.png)` |
| `[@kahneman2011, p. 33]` | 文字「（Kahneman, 2011, p. 33）」 | 不變，另外產生 `.bib` 檔 |
| `==重點=={pink}` | `==重點==` | `<mark>重點</mark>` |
| `> [!note]` | 不變 | 引用區塊，第一行粗體標題 |
| `%% 註解 %%` | 不變 | 刪除 |
| `[文字]{…}`、`:ruby[…]` 等指令 | 只留文字 | Pandoc 保留屬性；其他只留文字 |
| `::pagebreak` | 刪除 | `\newpage` |
| `[@kahneman2011:h3]` | 文字「（Kahneman, 2011, p. 33）」 | `[@kahneman2011, p. 33]` |
| `[[@kahneman2011]]` | `[[Thinking, Fast and Slow]]` | `[Thinking, Fast and Slow](#kahneman2011)` |

- 匯出時，文件中用到的文獻與檔案一起寫成 `.bib` 檔（見「書目格式」），Banyan 擴充的類型降級成 `@misc`。
- 從 Obsidian 匯入時反過來：`[[名稱]]` 照標題尋找並改寫成 id，`![[檔案]]` 把檔案加入檔案庫。
- 匯入 `.bib` 時，每筆資料成為文獻庫的條目，保留原本的鍵（重複時加 `a`、`b`…並提示）。

# 實作建議
- 解析：沿用 unified／remark（之前的實作也是），每個語法寫成 micromark 擴充，不用正規表示式後處理。
  - 現成：`remark-gfm`（表格、刪除線、待辦、腳註、自動連結）、`remark-math`、`remark-directive`、`remark-frontmatter`、`remark-cjk-friendly`。
  - 自己寫：`[[ ]]`／`![[ ]]`、`==螢光筆==`、`%% %%`、`#標籤`、`^段落標記`、`[@ ]` 引用、`{…}` 屬性、`> [!type]` 提示框、上下標。
- 編輯器：用 ProseMirror 系的區塊編輯器（Tiptap、Milkdown 或 BlockNote）。關鍵是 **BFM ⇄ 編輯器文件** 能來回轉換而不改變內容：每種語法都要有對應的節點，以及「讀進來 → 存回去」的往返測試。
- 解析器同時給：顯示（轉成 React）、編輯器、後端（存檔時找出 `[[ ]]`、`[@ ]` 建立連結與引用）。建議由前端把參照清單（卡片 id、引用鍵）和內容一起送給後端，避免前後端兩套規則不一致。
- 保留原文：編輯器沒有專屬節點的語法，以「原文晶片」保留原始文字，確保不會在存檔時被改寫（之前 `remarkBanyanRaw` 的做法）。
- 資料庫：`items` 與 `annotations` 各加一個 `cite_key` 欄位（唯一索引），升級時替現有的條目與註解依「引用鍵」的規則產生；註解的編號另外記在 `annotations.seq`（每個條目、每種類型各自編號）。修改鍵時，用後端指令在同一個交易中改寫所有卡片內容中的 `@舊鍵`。
- 書目：`.bib` 的讀寫與引用格式（CSL）用 `citation-js` 或自己寫；決定前先確認中文姓名（不分 given／family）與 `@performance` 等擴充類型的處理。
- 測試：每條規則（特別是「衝突與跳脫」、「中日韓文字的規則」）都要有「輸入 → 解析結果」的測試案例。
