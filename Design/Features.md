## Markdown 區塊編輯器（`src/editor/`）

- **文件就是 Markdown**：文件本體永遠是一段 CommonMark 字串；畫面上的區塊是用 markdown-it（`commonmark` 預設）解析後切出來的視圖。每個區塊記住自己在原始碼的行範圍。
- **CommonMark 0.31.2**：652 個規格範例全部通過，由區塊組回的 HTML 與規格逐字相同，不做正規化（`npm test`）。測試也確認每個非空白行都屬於某個區塊。
- **區塊**：段落、標題、程式碼、引用、分隔線、HTML 區塊各是一個區塊；頂層清單的每個項目各是一個區塊。連結參考定義沒有輸出，以灰色原始碼區塊顯示，仍可編輯。
- **所見即所得編輯**：點區塊就在原地直接編輯排好的文字（粗體、斜體、顏色、連結都照最後的樣子顯示，游標放在點到的字上），不再看到 Markdown 原始碼。區塊語法（`# `、`- `、`1. `、`> `）不顯示，只編輯後面的內容；每次輸入都把內容轉回行內 Markdown，只改動該區塊的行，其他原始碼一字不動。使用者打的 `*`、`_`、`[`、`<`、行首的 `# `、`- `、`1. `、`> ` 等會自動跳脫，不會意外變成格式。強調在 CommonMark 規則下不成立時（例如中文標點旁的粗體）自動改用 `<strong>`／`<em>`。打出 ```` ``` ```` 等會吞掉後面內容的語法時，編輯區自動擴大涵蓋受影響的區塊。
  - 段落開頭打 `# `、`## `、`### `、`- `（或 `* `、`+ `）、`1. `、`> `、```` ``` ```` 直接轉成對應的區塊（像 Notion）。
  - 有選取時按粗體等格式（含顏色、連結）：以畫面上選到的字為準切換（選取裡看得到的字全部都有這個格式就拿掉，否則全部加上；空白不算），選取保留在同一段文字上。不受選取邊界剛好落在 `**` 記號旁影響；跨過好幾段格式也可以。
  - 沒有選取時按粗體等格式（含顏色）：接著打的字就有（或沒有）那個格式，狀態列立即顯示；之後每打一個字、輸入法每選好一個詞都會確認格式正確（就算瀏覽器或輸入法把字插進原本的粗體裡也會搬出來），直到游標移走。在粗體中間按 Enter，前後兩段都保有粗體。
  - 連結：Ctrl＋K 或格式列的連結按鈕開啟網址輸入框，Enter 套用、Esc 取消；在連結裡再按就拿掉連結。
  - 貼上：單行文字以純文字貼上（不帶網頁格式）；多行或 Banyan 區塊照區塊貼上。
  - **輔助打字：中文標點**（`punct.ts`；使用者：「你幫我做一個輔助打字功能 例如：正在打中文時會出中文標點符號」）：正在打的這句是中文時（前一個字是中文；或中文句子裡夾的英文後面，例如 `我在用 Banyan,` → `我在用 Banyan，`，使用者：「有時中文會夾雜英文時 當在英文後輸入標點符號會出現英文的標點符號」），打半形的 `,` `.` `?` `!` `:` `;` 自動換成 `，` `。` `？` `！` `：` `；`；`(` 換成 `（`、`"` 換成 `「`、`'` 換成 `『`，前面有還開著的 `（`／`「`／`『` 時 `)`／`"`／`'` 換成對應的關（關的前面不一定要是中文，例如 `「abc"` → `「abc」`）；`。` 後面再打 `.` 變成 `……`。換完緊接著按 Backspace 還原成原本的半形。判斷是不是中文句子：往回找，先碰到中文字或中文的句中標點就是，碰到開頭、換行、中文句尾（`。！？…`）或後面空一格的半形 `.` `!` `?`（英文句尾）就不是，所以整句英文不換。數字後面的 `.` `,` `:`（`3.14`、`1,000`、`14:00`）、像網址或路徑的字（`https:`、`a/b`、`me@x`）不換；開括號、引號緊接在英文字後面不換（`it's`、`f(x)`），要在中文字或空白後面。行內程式碼裡、程式碼區塊（原始碼文字框）不換；正在打的 Markdown 語法裡也不換（`inMarkdownSyntax`）：`\` 後面、還沒關上的反引號裡、連結與圖片的 `](網址 "標題")` 裡、HTML 標籤與自動連結 `<…` 裡，`!` 換成 `！` 後緊接著打 `[` 會換回圖片語法 `![`；輸入法一次送出好幾個字（`好,`）也照樣逐字換。設定畫面 Typing 的 Chinese punctuation 可以關掉（預設開著）。編輯器用到的地方（日記、頁面、Word、簡報、白板卡片）都有。
  - **輔助打字：中英文**（`typing.ts`；使用者：「請你繼續延伸打字輔助能 要適配中文和英文」）：依正在打的這句是中文還是英文自動修正，每條規則在設定畫面的 Typing 各有一個開關（存在 localStorage `banyan.typing`，舊的 `banyan.cjkPunct` 關掉的設定會沿用），換完緊接著按 Backspace 一樣會還原成原本打的字：
    - **English punctuation**（預設開）：英文句子裡（輸入法還在中文模式）打出的 `，` `、` `。` `？` `！` `：` `；` `（` `）` `「」` `『』` `“”` 換回 `,` `.` `?` `!` `:` `;` `(` `)` `"` `'`。英文句子是：往回到這句開頭（換行、`。！？`、後面空一格的 `.!?`）之間有英文字母、沒有中日韓的字；中文夾英文（`我在用 Banyan，`）不換。
    - **Capitalize sentences**（預設開）：區塊開頭、英文句尾 `. ` `! ` `? ` 後面的小寫字母換成大寫（`e.g. ` `Mr. ` 等縮寫、`3. ` 編號、中文後面的句點不算）；單獨的 `i`（後面打空白或標點，例如 `i am`、`i'm`）換成 `I`。區塊開頭打網址或刻意的小寫時，按 Backspace 還原。
    - **Space between Chinese and English**（預設關）：中文字緊接英文字母或數字（或反過來）時自動空一格（盤古之白：`用Banyan寫` → `用 Banyan 寫`、`第3章` → `第 3 章`）；標點旁邊、已經有空格不加。
    - 一般打字在 beforeinput 換；輸入法選好字（compositionend）時把剛送出的字換掉，所以用注音、倉頡打出的標點與中文也適用。
  - **字預測**（`predict.ts`、`PredictBar.tsx`；使用者：「增加字預測 簡單來說打字時 在光標的下方出現個Bar 內顯示預測我正在打什麼字 支持倉頡、速成和英文」）：打字時游標下方出現一排預測（每個前面標著數字），點了就用；數字鍵 1～9 選第幾個、左右鍵移動選中的字、Tab 或 Enter 選它（使用者：「可以用Enter來確定字」；聯想與英文的下一個字是「接下來可能打的」，Enter 要先用左右鍵移動過才選，不然照常換行）；倉頡／速成組字中空白鍵留給系統輸入法（原本也用來選預測列的字，使用者：「當按空白鍵時觸電腦自帶的輸入法 會造成嚴重的干擾」，網頁擋不住輸入法處理空白鍵，所以拿掉）、Esc 關掉（使用者：「不用顯示倉頡碼 且能用左右鍵或數字選取字」），游標移走、捲動、離開編輯也會關掉。設定畫面 Typing 的 Word prediction（localStorage `banyan.predict`）：English 開關、Chinese input method 選 Cangjie／Quick／Off（預設 English 開、Cangjie）。
    - 區塊編輯器以外所有打字的地方也有（`fieldPredict.ts`，和字預測一起在 document 上接；使用者：「Mind Map 不支援打字輔助」「在軟件中的所有角落 只要打字就要支持打字輔助和預測字的功能」）：文字框、輸入框（便利貼、心智圖主題、Tasks、Drawer、標題、搜尋框、試算表格子…）與純文字的可編輯元素（Draw 圖形的文字、圖片的圖說、表格編輯器的格子）。不換的：程式碼卡片、引用鍵（`data-no-assist`）、`=` 開頭的試算表公式；網址、DOI 等輸入框連預測也不出（`data-no-predict`）。
    - **英文**：游標前正在打的字（一個字母就開始，使用者：「英文只有兩個字母才有預測字」）→ 以它開頭的字：使用者在日記與頁面寫過兩次以上的字排前面（次數多的先，App 用 `setPredictCorpus` 傳內容），其次是內建的常用字（`predict/english.txt`）；大小寫跟著打的字（`Ban` → `Banyan`、`BAN` → `BANYAN`），選了換掉整個字。
    - **Banyan 自己的倉頡／速成輸入**（使用者：「可以改用你的方案」——Windows 輸入法按空白鍵自己選字，網頁擋不住，所以改成 Banyan 自己做輸入）：關掉 Windows 的中文輸入法、用英文鍵盤打字母碼。中文模式下打 a～y 不進文件，預測列分兩層（使用者：「你能優化下UI顯示」）：上面是打了的字根（`竹手戈`）與字母碼（`hqi`），右邊是頁數與 ‹ › 換頁；下面是候選字（完整符合的在前、依字頻，最多 90 個、每頁 9 個，前面標數字，反白的字用綠底白字）；空白鍵、Enter、Tab 選反白的字，數字鍵 1～9 選第幾個，左右鍵移動，上下鍵（或 `-` `=`、PageUp／PageDown）換頁，Backspace 刪一碼，Esc 取消；倉頡最多 5 碼、速成 2 碼，打滿了還繼續打字母就先選反白的字、這個字母開始下一個字（連打，速成常用：`hioi` → 的每；使用者：「你能適配速成」）；打標點、z、大寫字母等先選反白的字再照常輸入（`我,` → `我，`）。選好字後聯想。中文模式下打大寫字母就暫時打英文（`imeTemp`：大寫字母照常輸入、接著的字母數字都是英文，有英文預測；打空白、標點、Enter、Tab、移動游標或點別的地方就回到中文，那個鍵照常作用；右下角標籤這時顯示「英 English · until space」；使用者：「當輸入中文 時打了打大寫英文 就切換成英文 直到打完才切換回來」）。單獨按一下 Shift 切換中／英（游標下方閃一下「中」／「英」，記在 localStorage `banyan.imeChinese`）；視窗右下角一直顯示現在的輸入法（「中 Cangjie」／「中 Quick」／「英 English」，`InputModeBadge`：點「中／英」切換中英，點右邊的 Cangjie／Quick 直接換倉頡或速成，設定畫面跟著更新；快捷鍵 Alt＋`（使用者：「用 Alt+`」，原本是 Alt＋Q）也是互換倉頡／速成（同時切到中文，游標下方閃一下「中 Cangjie」／「中 Quick」；使用者：「增加一個快捷鍵來切換倉頡」）；白板、Draw 有縮放按鈕時往上讓開；Chinese input 是 Off 時不顯示，使用者：「在右下方增加一個顯示現在什麼輸入法」）；英文模式就是一般打字加英文預測。設定的 Chinese input 選 Cangjie／Quick／Off（Off 就沒有中文輸入）。區塊編輯器、文字框、輸入框都可以用；行內程式碼裡照常打英文。`/` 命令選單開著時（使用者：「我講的是/ 命令要強制切換成英文」）打 a～y 也自動暫時打英文，命令名稱照常篩選、不出英文預測（Enter 留給選單），選了命令、Esc 關掉選單、打空白就回到中文（`predictor.ts` 的 `slashCommand`：行首或空白後的 `/` 加英文字母，且 `.slash-menu` 開著）。只會打英文的 Markdown 語法裡（使用者：「使用Markdown強制切換成英文」）打 a～y 也自動暫時打英文（`punct.ts` 的 `markdownEnglish`，同樣用 `imeTemp`，右下角顯示英文）：還沒關上的反引號裡（行內程式碼、```` ``` ```` 後面的語言）、連結與圖片的 `](` 網址裡、`<` 開頭的 HTML 標籤與自動連結裡、行首（或清單標記後面）剛打的 `{`／`[`（任務標記 `{x}`、核取方塊 `[x]`）；打了關上的 `` ` ``、`)`、`>` 等就回到中文。連結文字、`[[頁面]]` 的名稱照常打中文。
    - **倉頡／速成**（配合 Windows 的輸入法，仍然保留）：組字中（compositionupdate）的字根 `竹手`（或英文字母 `hq`）換成碼，列出碼以它開頭的字：完整符合的在前、其次是還沒打完碼的字，各自依字頻（不顯示倉頡碼）。組字中按鍵先給輸入法（key 是 `Process`），改看 `code`：數字鍵、左右鍵、Enter 一樣操作預測列（空白鍵不算），輸入法同時送出的字在 compositionend 換成選的字；按鍵選字時先等輸入法自己結束組字再換，150ms 內沒結束才用焦點切換強迫結束；選字用的數字、空白，以及輸入法又送出一次的同一個字，在換上去之後 600ms 內都丟掉（含全形，修正選完字後多一個數字、空白鍵出現兩個相同的字）。點候選字時焦點暫時移到預測列讓輸入法結束組字，再把組字的內容換成點的字。碼表是 Rime 倉頡五代（rime-cangjie 的 base＋有字頻的 extended），字頻與詞來自 rime-essay（都是 LGPL-3.0），`scripts/build-predict.mjs` 產生 `predict/cangjie.txt`、`phrases.txt`，開始編輯時才載入（不在主程式裡）。
    - **英文下一個字**（使用者：「並且增加預測下一個字」）：打完一個字、空一格後，列出常接在它後面的字（`want ` → to）：使用者在日記與頁面寫過的接法排前面（`countPairs`，兩個字中間只有空白才算），其次是內建的 `predict/english-next.txt`（每行「字 下一個字…」）。選了只插入那個字，再打空格會繼續預測。這一列也可以用數字鍵選（使用者：「英文下一個預測字都能用數字來選取」；所以預測列出現時空格後面的數字會變成選字，要打數字先按 Esc）。
    - **到處都有**（使用者：「除了Word用之外其他地方都用不了」）：區塊編輯器（日記、頁面、Word、簡報）之外，一般文字框與輸入框（白板便利貼、備忘稿、Draw 的文字、Tasks 卡片、試算表的格子、標題、搜尋框…）也有預測（`fieldPredict.ts`，在 document 上統一處理；游標位置用影子元素量）。不預測：區塊編輯器的原始碼文字框（程式碼）、密碼／網址／數字等輸入框、唯讀、`data-no-predict`。選字的按鍵在 window 捕捉階段先處理，所以簡報的 Esc、試算表的 Enter 等不會搶走。預測列在外層捲動時跟著游標移動，游標捲出畫面才關掉（原本一捲動就關掉）。
    - **聯想**：選好字後（輸入法送出、或點了預測），列出以游標前兩個字、再以前一個字開頭的詞，顯示接下來的字（`我` → 們、的、覺得…）；選了之後繼續聯想。輸入法結束組字後 250ms 內的按鍵不拿來選聯想（用輸入法的 1 選「我」時，那個 1 不會再選到聯想的「們」）。
  - 程式碼區塊、HTML 區塊、參考連結定義、分隔線，以及無法拆開的複雜區塊（含巢狀清單或多個段落的清單項目、多段引用、Setext 標題）仍用原始碼文字框編輯。
- **程式碼區塊**（`codeHighlight.ts`、`CodeTools.tsx`）：有寫語言的 ``` 區塊顯示時語法上色（highlight.js，22 種常用語言，別名如 js／ts／py／sh 都認得；淺色、深色主題各一套顏色）；沒寫語言的不上色。滑過區塊右上角出現語言按鈕（點開選單改語言，只改 ``` 那一行；縮排的程式碼區塊改成 ```）與 Copy（複製程式碼內容，不含 ```）。上色在渲染之後做，Markdown 與 CommonMark 渲染結果不變。
- **鍵盤**：Enter 切成新區塊（清單項目延續同樣的標記與編號；空項目按 Enter 離開清單；程式碼區塊內是一般換行）；Shift＋Enter 硬換行（行尾 `\`）；在開頭按 Backspace 先去掉區塊前綴，再與上一個區塊合併；上下左右鍵在區塊間移動；清單中 Tab／Shift＋Tab 縮排；Esc 離開編輯並選取該區塊；Ctrl＋Z／Ctrl＋Y（Ctrl＋Shift＋Z）復原與重做，連續打字合併成一筆。
- **行內格式與下方格式列**：編輯區塊時，畫面下方出現一個小格式列：左邊是區塊類型按鈕（「Text▾」「Bulleted list▾」…，點開「Turn into」選單，直接把編輯中的區塊換成文字、標題 1–3、項目符號清單、編號清單、待辦清單、任務、事件、引言或程式碼，換完繼續編輯、游標留在同一段文字上），中間是粗體 **B**、斜體 *I*、底線 U、刪除線 S、上標 x²、下標 x₂、行內程式碼 `</>`、連結、顏色「A▾」按鈕，右邊顯示游標所在文字的狀態（「粗體」「底線・刪除線」「紅字・黃色螢光・藍底」「一般文字」…），啟用中的按鈕以藍色標示。狀態用 markdown-it 解析判斷，與 CommonMark 渲染結果一致（不成對的 `**` 不算粗體）。
  - 類型選單是所見即所得：下方格式列的「Turn into」、區塊選單與斜線選單裡，每種類型的名稱用它自己的樣子顯示（Heading 1／2／3 的大小與粗細、Quote 左邊直線加斜體、Code 等寬字加底色）。
  - 切換：按鈕或快捷鍵 Ctrl＋B／I／U／E／K、Ctrl＋Shift＋X（刪除線）、Ctrl＋.（上標）、Ctrl＋,（下標）。有選取時包住選取文字（前後空白留在記號外，選取保留在文字上），選取已是該格式時取消，選取在格式中間一段時前後保留原本格式；沒有選取時，在格式裡就取消整段，不在就放一對記號讓接著打的字有格式。行內程式碼內容含反引號時自動加長；連結包成 `[文字](https://)` 並選取網址，在連結裡再按就拿掉連結保留文字。
  - 顏色選單（A▾）：文字顏色、螢光標記、區塊背景三排，各有「預設」與九種顏色（灰、棕、橘、黃、綠、藍、紫、粉紅、紅，與 Notion 相同，淺色／深色模式各有對應的色調）。選「預設」拿掉顏色；游標在有顏色的文字裡沒有選取時整段換色；在紅字中間選一段換成藍字時前後仍是紅字；選取裡原有的同種標籤會先拿掉，不會層層疊。區塊背景作用在整個區塊（清單是整份清單），設定後仍在編輯同一個區塊。區塊選單（⋮⋮）也有「背景顏色」，多選時套用到每個區塊。
  - 儲存格式：CommonMark 沒有刪除線、底線、顏色，用 CommonMark 允許的行內 HTML：`<s>刪除線</s>`、`<u>底線</u>`、`<sup>上標</sup>`、`<sub>下標</sub>`、`<span class="red">紅字</span>`、`<mark class="yellow">螢光</mark>`（`<mark>` 沒有 class 時是黃色）；區塊背景用區塊容器 `<div class="bg-blue">`（與縮排、多欄相同的寫法）。標籤之間的文字仍照常當 Markdown 解析。有背景色的區塊搬移、縮排、當父區塊時背景色跟著區塊走。
  - 程式碼、HTML、參考連結區塊中行內格式按鈕停用（顯示「原始文字」），但可以設定區塊背景。
- **圖片、GIF、影片**：斜線選單的「圖片」「影片」開啟選擇檔案視窗（可多選）；編輯中貼上圖片（截圖、複製的圖片檔）；從檔案總管把檔案拖進頁面（放在滑鼠位置最近的區塊後面）。檔案複製到 App 資料夾的 `media/`（以內容雜湊命名，同一個檔案只存一份），Markdown 寫相對路徑；顯示時換成 Tauri asset protocol 的網址。只有前端（瀏覽器預覽）時改用 data URL。
  - 圖片、GIF 是 CommonMark 的圖片：`![說明](media/xxx.png)`（說明預設是檔名）；影片是 HTML 區塊 `<video src="media/xxx.mp4" controls>` ＋ `</video>`。
  - **圖說**：圖片、影片下方可以直接點來輸入圖說，Enter 或點別處儲存、Esc 取消；沒有圖說時只在滑過或選取時出現「加上圖說…」。圖說一律在圖片（影片）上方或下方的中央，寬度與圖片相同（長的圖說會換行）。CommonMark 沒有圖說語法，寫成圖片標題 `![說明](media/x.png "圖說")`（其他軟體顯示成滑鼠提示），影片寫成 `title` 屬性；引號、`<`、`>`、`&` 會跳脫。
  - **圖說位置**：選單可以切換圖說在上方或下方。上方存成外層容器 `<div class="caption-top">`（和對齊、背景色一樣算是區塊的一部分，可以同時存在），下方就是沒有容器。
  - **物件選單**：選取圖片、影片時，上方浮出選單：對齊（靠左、置中、靠右）、大小（原始、25%、50%、75%、100%）、圖說（「圖說」按鈕直接進入圖說編輯、上方／下方）。選單跟著圖片的對齊位置。
  - **大小**：寬度是版面寬度的百分比，存成外層容器 `<div class="width-50">`（25／50／75／100），原始大小就是拿掉容器；可與對齊、圖說位置、背景色同時使用。
  - **對齊**：CommonMark 沒有對齊語法，置中、靠右存成外層容器 `<div class="align-center">`／`<div class="align-right">`（與背景色相同的寫法），靠左就是拿掉容器；可與區塊背景色同時使用，搬移、縮排時跟著區塊走。
  - 點圖片或影片是選取（可拖曳、刪除、複製），影片的播放控制照常可按；連按兩下開啟原始碼編輯（改說明或路徑）。插入的區塊若是空白區塊就直接取代，否則放在下面，插入後選取。
- **表格**：斜線選單的「表格」插入 3×3（第一列是標題列）。CommonMark 沒有表格語法（`|` 表格是 GFM），存成 HTML 區塊 `<table>`（每列一行、沒有空行），任何 CommonMark 渲染器都會照樣顯示。點表格進入表格編輯：每格是純文字，Tab／Shift＋Tab 換格（最後一格再按 Tab 新增一列）、Enter 到下一列（最後一列會新增）、Shift＋Enter 換行、上下方向鍵換列、Esc 完成並選取表格；上方工具列可新增列（下方）、新增欄（右邊）、刪除列、刪除欄、切換標題列。`<`、`&` 等自動跳脫。
- **斜線選單**：在行首或空白後輸入 `/` 開啟，可打字篩選（中英文關鍵字），方向鍵與 Enter／Tab 選擇：文字、標題 1～3、項目清單、編號清單、引用、程式碼、分隔線。
- **區塊把手**：滑到區塊左側出現「＋」（在下方新增區塊並開啟斜線選單；清單項目後新增同一份清單的項目）與「⋮⋮」（拖曳搬移，點擊開啟選單：刪除、複製、轉換成各種類型）。正在編輯（游標在裡面）的區塊也有把手，拖動或點擊時才結束編輯；Word 裡這個把手一直顯示（`.paper-content .row.editing .gutter`），其他區塊照舊滑過才出現。拖曳時有跟著滑鼠的預覽與藍色插入線，Esc 取消；用指標事件實作，不用 HTML5 拖放（Tauri 在 Windows 上的檔案拖放功能會攔截它）。
- **縮排（子區塊）**：編輯中按 Tab 增加縮排、Shift＋Tab 減少縮排（清單項目仍是清單的巢狀縮排；程式碼區塊內 Tab 插入空格）；區塊選單也有「增加縮排」「減少縮排」。縮排後的區塊是**上方區塊的子區塊**：搬移、刪除、建立副本、拖到旁邊成欄時，父區塊連同子區塊一起；放到子區塊上下就成為同一個父區塊的子區塊；放到有子區塊的區塊「下方」時接在子區塊之後。**縮排只有一層**：已縮排的區塊不能再縮、有子區塊的區塊不能放進縮排；縮排有子區塊的區塊時，子區塊一起移進來成為同層；舊文件裡的巢狀縮排會在下次整理時攤平。上方沒有區塊（文件或欄位的第一個區塊）時不能縮排。減少縮排時，原本在它下面的兄弟區塊變成它的子區塊。空白區塊也可以先按 Tab 再打字。
- **多欄**：把區塊拖到另一個區塊的右側（右邊四分之一）或左緣，出現藍色直線，放開後兩者並排成兩欄；拖到欄位中的區塊旁邊會在多欄中再加一欄。欄位中的區塊可上下搬移、拖出欄外；一欄空了就自動移除，只剩一欄時取消多欄。拖曳欄位之間空隙左半邊的細線可調整欄寬（最小 64px）。欄位中的把手只留拖曳鈕。
- **版面的儲存格式**：CommonMark 沒有欄位與縮排，用 HTML 區塊包起來——`<div class="columns">`、`<div class="column">`（欄寬寫成 `style="flex: 1.44"`）、`<div class="indent">`，每個標籤自成一行、前後空行，中間的內容照常當 Markdown 解析，所以仍是合法的 CommonMark，任何 CommonMark 渲染器都會輸出對應的 `<div>`。編輯器把這些標籤藏起來，以欄位與縮排顯示；標籤不配對時當一般 HTML 區塊顯示。字數不計標籤。
- **空白區塊**：允許空白區塊（像 Notion 一樣可以留空行）。CommonMark 沒有空段落，空白區塊存成只有 `&nbsp;` 的段落（任何 Markdown 軟體都顯示成一個空行）；編輯時編輯框是空的，離開時才寫回 `&nbsp;`。連按 Enter 會留下多個空白區塊；在段落開頭按 Enter 會在上方多一個空白區塊；空白區塊按 Backspace 刪除。空的清單項目也保留。只有整份文件只剩一個空白區塊時離開才清空。點文件下方空白處時，若最後一個區塊是空白區塊就直接編輯它。字數不計 `&nbsp;`。
- **區塊選取與多選**：
  - 選取方式：編輯中按 Esc 選取該區塊；點 ⋮⋮ 選取並開啟選單；在頁面空白處（左右邊界、文件下方）按住拖曳框選；在區塊文字上按住拖到別的區塊，選取中間所有區塊；Shift＋點擊從起點延伸；Ctrl＋點擊加入或移出；未編輯時 Ctrl＋A 全選（編輯中文字已全選時再按 Ctrl＋A 也是全選）。選取的區塊以淡藍底標示，父區塊被選取時子區塊一起標示。
  - 對選取的操作：↑／↓ 移動選取、Shift＋↑／↓ 延伸；Enter 編輯第一個；Delete／Backspace 刪除（之後選取附近的區塊）；Tab／Shift＋Tab 一起縮排；Ctrl＋D 建立副本（選取副本）；Ctrl＋C／Ctrl＋X 以 Markdown 複製、剪下；Ctrl＋V 把剪貼簿的 Markdown 貼在選取區塊後面（選取貼上的區塊）；在編輯中的區塊裡貼上複製的區塊（或多行 Markdown）時，直接貼成區塊：在游標處把區塊切開，貼上的區塊放在中間並選取（程式碼區塊與單行文字照一般文字貼上）；複製同一份清單中相鄰的項目時保持緊湊清單；Esc 或點空白處取消。
  - **整組多欄**：多欄裡的區塊全部被選取時（例如框選兩欄），整組多欄當成一個單位——搬移、複製、建立副本、剪下、刪除都保留 `<div class="columns">` 與欄寬，拖曳預覽顯示「多欄排版」；只選部分欄位時照常把那些區塊搬出欄外。整組多欄不能放進另一個欄位（不做巢狀多欄），也不會被轉換類型或縮排。
  - 拖曳選取中任一區塊的 ⋮⋮ 會一起搬移（保持原順序，搬完仍選取），拖到旁邊則一起成為新的一欄。選取多個時區塊選單顯示「已選取 N 個區塊」，轉換類型、縮排、建立副本、刪除都套用到全部。
- **連結**：一般點擊是編輯；按住 Ctrl 點擊用系統瀏覽器開啟（`tauri-plugin-opener`）。
- **安全**：顯示前以 DOMPurify 清理 HTML，Markdown 中的 `<script>`、事件屬性等不會執行。
- **介面**：Notion 風格的置中頁面（最寬 720px），深色模式跟隨系統。文件開頭的一級標題放大成頁面標題；中文用 700 粗細，避免中文字型沒有半粗體而顯示成一般字重。編輯中的區塊以淡藍底與細框標示（右側原本的區塊類型與 Esc 提示已拿掉）。把手、選單用 SVG 圖示；斜線選單每項有說明與 Markdown 語法，底部有按鍵提示；區塊選單標出目前類型，靠近視窗邊緣時往內收。頂端列為「Banyan / 文件標題」、儲存狀態、字數（中日韓文字每字一個）。原本的原始碼面板（Source，Alt＋M）已拿掉。視窗預設 1100×760，最小 520×400。文件自動存到 localStorage。

### 已知限制

- 複雜區塊（巢狀清單、多段落）與程式碼區塊仍以原始碼編輯。
- 編輯過的區塊會重新產生行內原始碼：參考式連結變成行內連結、軟換行變成空白、`__粗體__` 變成 `**粗體**`（渲染結果相同）；沒編輯過的區塊不受影響。
- 巢狀清單、引用內的內容跟著外層區塊一起編輯，沒有再拆成更小的區塊。
- 欄位與縮排只能包整份清單，不能只包清單中的一個項目；清單項目的 Tab 是清單巢狀，不是縮排區。
- 欄位與縮排在其他 Markdown 軟體中只會是沒有樣式的 `<div>`（GitHub 等會移除 `class`／`style`），內容仍正常顯示。
- 只支援 CommonMark，不含 GFM（`|` 表格、待辦清單）；表格以 HTML 區塊儲存，儲存格只有純文字；刪除線、底線、顏色以行內 HTML 儲存，在 GitHub 等會移除 class 的地方只會剩下刪除線與底線。
- 還不能開啟或儲存 `.md` 檔。

## 日記（`src/journal/`，參考 Logseq）

- **每天一頁**：每天的日記是一份獨立的 Markdown，用同一個區塊編輯器編輯（所有編輯功能都能用：斜線選單、格式、圖片、表格、多欄…）。
- **儲存**：App 資料夾的 `journals/` 底下，一天一個檔，檔名與 Logseq 相同（`2026_11_17.md`）；打字後 0.4 秒自動寫入，關閉視窗前會把沒寫的寫掉。內容刪光（只剩空白或空白區塊）就刪檔。`journals/` 與 `media/` 在同一層，所以日記裡的 `media/檔名` 圖片照常顯示。只有前端（瀏覽器預覽）時存在 localStorage。
- ~~**日記串**~~（2026-11-18 從側邊欄拿掉，程式 `JournalStream` 還在但沒有入口）：像 Logseq 的 Journals，今天在最上面（還沒寫也會出現，顯示「今天發生了什麼？」提示），往下是以前寫過的日子，新的在前；每次顯示 10 天，捲到底再載入更早的。每天的標題是「11 月 17 日」（不是今年的加上年份）、星期，與「今天／昨天／前天」標籤。日期跨過午夜會自動換成新的一天。
- **單日頁面**：點日記串裡的日期標題開啟。上方有前一天／後一天，以及「上一篇／下一篇」（跳到前後有寫的日記）；還沒寫的日子會提示「打字就會建立」。
- **月曆**（頂端列「日曆」）：月份切換、有寫日記的日子有圓點、今天以藍字標示、底下顯示這個月寫了幾天；點任何一天（含未來）開啟那天的單日頁面。「今天」按鈕直接開今天。
- **好幾個編輯器並存**：日記串裡每天各是一個編輯器。復原（Ctrl＋Z／Y）、區塊選取的按鍵、Ctrl＋A、剪貼簿只作用在最後操作的那一天；點到別天時，原本那天自動結束編輯並取消選取。
- 頂端列的字數跟著目前的頁面（單日頁面、頁面）；清單類畫面不顯示字數。上次開啟的畫面會記住；沒記過（或記的是已拿掉的日記串、所有頁面、文件）就開今天的日記。

- **筆記符號**：日記裡一般的清單項目以「–」顯示（子彈筆記的筆記），任務是「•」、事件是「○」。
- 單日頁面下方有反向連結（`[[2026-11-17]]` 連到那一天）。

### 已知限制

- 還沒有標籤（`#標籤`）與全文搜尋。
- 區塊不能從一天拖到另一天（可以複製貼上）；方向鍵不會跨到上一天或下一天。

## 頁面連結與反向連結（`src/pages/`，參考 Logseq）

- **寫法**：`[[頁面名稱]]`（與 Logseq、Obsidian 相同）。CommonMark 沒有這個語法，`[[名稱]]` 照規格渲染成普通文字；編輯器只在顯示時把它換成連結（不改 markdown-it 的規則，CommonMark 規格測試不受影響），在其他 Markdown 軟體裡就是「[[名稱]]」幾個字。名稱不分大小寫；`[[2026-11-17]]` 連到那天的日記。
- **輸入**：打 `[[` 跳出頁面建議（開頭相符的在前，沒有同名頁面時最後一項是「新增頁面」），↑↓ 選擇、Enter／Tab 確認、Esc 關閉；選好後寫成 `[[名稱]]`，游標放在後面。自己打完 `[[名稱]]` 也一樣是連結（所見即所得轉回 Markdown 時，完整的 `[[…]]` 不跳脫方括號；單獨的 `[` 照常跳脫）。編輯時連結後面放一個零寬空白，接著打的字不會跑進連結裡。
- **開啟**：點連結開啟那一頁（像 Logseq）；編輯中按住 Ctrl 點。方括號以淡色顯示。
- **連到 Dock 的文件**（`src/desk/docLinks.ts`）：`[[檔案名稱/文件標題]]` 連到 Desk 某個檔案 Dock 裡的那份文件（Word、簡報、Excel、Draw、筆記都可以）。打 `[[` 的建議清單是分級選單：第一層是頁面，接著 Desk 的檔案（「Trip · 2 documents ›」），Enter、Tab、→ 或點一下進到那個檔案，列出它 Dock 裡的文件（上方「‹ Trip」，← 或點它回上一層；這時打的字是 `[[Trip/`，接著打字篩選文件標題）；第一層有打字時，標題符合的文件也直接列出（「Budget · Excel in Trip」）；顯示時前面有一個小文件圖示，滑過顯示「Excel in Trip」；點了打開那個檔案的 Dock 並選取那份文件（檔案已經開著也會切換）。任何編輯器都能用（日記、頁面、Dock 裡的 Word／簡報／筆記）。同名的頁面優先；這種連結不算頁面，不出現在頁面建議裡。
- **頁面**：每頁一個 Markdown 檔，存在 App 資料夾的 `pages/名稱.md`（Rust 指令 `page_list`、`page_read`、`page_write`；Windows 不允許的字元與 `%` 寫成 `%XX`，和 Logseq 一樣是 URL 編碼）。被連到但還沒寫的頁面點開是空白頁，打字才建立檔案；內容刪光就刪檔。瀏覽器預覽時存在 localStorage。
- **頁面範本**（`src/pages/templates.ts`，參考 Logseq）：名稱是 `Template/…` 的頁面就是範本（跟一般頁面一樣存在 `pages/`、一樣編輯；標題旁有「Template」標籤與用法說明）。任何頁面或日記打「/範本名稱」，斜線選單的「Templates」一組列出範本，選了放在這個區塊（空白區塊整個換掉，有文字就放在下面）；沒有範本時是一個說明項目。空白頁面、今天或單日的空白日記上方有「Start from a template」與每個範本的按鈕。頁面標題旁「Save as template」把這一頁複製成 `Template/頁面名稱`（重複就加數字）並打開它。名稱是 `Template/Journal` 的範本：今天還沒有日記時，App 啟動（或換日）就用它寫上今天的日記（每天一次）。插入時換掉變數：`{{date}}`（`[[YYYY-MM-DD]]`，日記那一天或今天）、`{{today}}`（`Nov 19, 2026`）、`{{weekday}}`、`{{month}}`、`{{year}}`、`{{time}}`、`{{title}}`（頁面名稱；日記是日期），不認得的照舊。
- **嵌入內容**（`src/editor/embed.ts`、`src/pages/embeds.ts`，參考 Obsidian）：段落或清單項目裡只有 `![[名稱]]` 時，不在編輯時顯示成那個東西的內容——名稱可以是任何頁面、日記 `![[YYYY-MM-DD]]` 或 Dock 文件 `![[檔案/標題]]`（Note、Word、簡報顯示內容；Excel、Draw 只顯示標題連結與「Excel · click the title to open」，點了打開那份文件）：上方是頁面名稱（點了開啟），下面是唯讀的渲染結果（任務顯示成子彈筆記符號、待辦是核取方塊，程式碼上色、圖片、頁面連結與引用照常）。原始碼不變（CommonMark 照規格渲染成文字），點一下照常編輯 `![[名稱]]`。嵌入裡的嵌入繼續展開，最多 3 層，外層已經出現的頁面不再展開（顯示「Already embedded above」）；沒有這一頁顯示「No page with this name yet」，空白頁「Empty page」。被嵌入的頁面改了，嵌入跟著重畫（只有嵌入過的頁面改變才重畫）。範本頁面也是頁面，可以這樣嵌入，但變數不會換掉。
- **反向連結**：頁面與單日頁面最下面列出「N 個反向連結」——哪些日記、頁面提到這裡，以及提到它的那幾個區塊（任務顯示符號），日記新的在前、頁面依名稱。點區塊開啟來源，點區塊裡的連結開啟那一頁。啟動時把所有日記與頁面讀進記憶體計算。
- ~~**所有頁面**~~（2026-11-18 拿掉，刪除 `AllPages.tsx`；頁面從連結、收藏、最近開啟）：上方一條搜尋框（打字篩選，Enter 開啟或新增），下面是頁面卡片，一排四張（內容區窄時三、二、一張）。有內容的頁面加上被提到但還沒寫的頁面（虛線框）；卡片固定高度，依原本順序顯示文字摘要與第一張圖片（像 Heptabase 的卡片庫），超出的切掉；滑過出現刪除。
- **刪除**：頁面或單日日記的頂端列有垃圾桶按鈕（日記有內容時才出現，頁面一律有：空白頁刪掉就是從收藏、最近拿掉）；側邊欄收藏、最近裡的頁面滑過出現垃圾桶；白板上頁面／日記卡片的右鍵選單有「Delete page…／Delete journal…」（這張白板上指向它的卡片一起拿掉，其他白板的留著）。確認後刪掉檔案（內容寫成空白，Rust 端刪檔），並從收藏與最近拿掉，畫面回到行事曆。連到它的 `[[連結]]` 保留（再點開是空白頁）；被提到的頁面刪除後仍以「還沒有內容」留在清單。不能復原。

### 已知限制

- 頁面還不能改名；刪除後連到它的連結保留（不會自動清掉）。
- 反向連結是唯讀的，不能在那裡直接編輯；沒有「未連結的提及」。
- 名稱裡不能有方括號；程式碼區塊與行內程式碼裡的 `[[…]]` 不算連結。
- Dock 文件的連結靠名稱：檔案或文件改名時會自動改寫日記、頁面與 Desk 文件裡的連結，但在 App 外面改檔案就會斷（變回頁面連結）；同一個檔案裡標題相同的文件，連到第一份；文件沒有反向連結。

## 子彈筆記（`src/bujo/`，Bullet Journal）

- **快速記錄**：任務與事件是清單項目加上大括號標記 `{ }`（2026-11-18 使用者要求從方括號改成大括號；方括號留給待辦清單），畫面上以子彈筆記的符號顯示（SVG 圖示 `TaskIcon`，各種字型下大小一致、與第一行文字垂直置中；清單項目、右鍵選單、說明都用同一組），標記本身藏起來：

  | 符號 | 意義 | Markdown |
  |---|---|---|
  | □ 方框 | 任務 | `- { } 內容` |
  | 框裡 ✕ | 完成 | `- {x} 內容` |
  | 框裡 ← | 已排程 | `- {<} 內容 [[2026-11-20]]` |
  | 劃掉的方框 | 取消 | `- {-} 內容` |
  | ○ | 事件 | `- {o} 內容` |
  | – | 筆記 | `- 內容`（一般清單項目） |

  沒有傳統子彈筆記的「已遷移」`[>]`（2026-11-18 使用者要求拿掉）：要在別天做一律排程。以前寫的 `- [>] 內容` 現在只是普通的筆記文字。

- **輸入**：段落或清單項目開頭打 `{} `（或 `{ } `）變成任務，`{x} ` 完成、`{o} ` 事件、`{<} ` 已排程、`{-} ` 取消也可以直接打；原始碼裡也可以寫 `- {} 內容`。中文輸入法打出來的大括號（Shift＋方括號鍵的『』、全形｛｝）、全形字（ｘ、ｏ、○、＜…）與全形空白都認得；輸入法一次送出整串也會觸發（組字中不觸發，選好字時再檢查）。只有打字當下開頭變成快捷時才觸發，已經是這樣開頭的文字在後面繼續打字不會轉換。斜線選單與區塊選單有「任務」「事件」（提示 `{}`、`{o}`）。任務按 Enter 下一行還是任務（事件之後還是事件），空的任務按 Enter 離開清單；開頭按 Backspace 先拿掉任務標記（變回筆記）。編輯中按 Ctrl＋Enter：任務切換完成，段落變成任務。
- **切換**：點符號切換任務 ↔ 完成（已排程的點了變完成，再點回到已排程，日期留著）；在符號上按右鍵開啟選單：任務、完成、取消、事件、筆記（拿掉符號）、排程到某一天（日期選擇器）。完成的文字變淡，取消加刪除線；已排程的在寫它的那天也變淡（要做的是排到的那天）。
- **待辦清單（核取方塊）**：和子彈筆記的任務分開的 Notion 風格待辦，畫面上是可以打勾的方框，勾選後文字變淡加刪除線。用方括號：`- [ ] 內容`／`* [x] 內容`（任何清單標記都可以，與 GitHub、Obsidian 的待辦寫法相同）。段落或清單項目開頭打 `[] `（或 `[ ] `）變成待辦，`[x] ` 是勾好的；`*[] `、`* [] ` 也可以；中文輸入法的「」【】［］、全形空白也認得。新建的待辦寫成 `* [ ] `。斜線選單、區塊選單的「待辦清單」（提示 `[]`）插入或轉換；Enter 下一行是未勾選的待辦；點方框或 Ctrl＋Enter 切換；沒有右鍵狀態選單。行事曆的「未完成」也會列出未勾選的待辦。
- **行事曆**（側邊欄「Calendar」、Alt＋Shift＋1；取代原本的子彈筆記頁；參考 Google 日曆、Apple 行事曆、Thunderbird）：每日紀錄仍寫在日記裡，這裡是總覽與排程。
  - **版面**（依使用者畫的線框）：頁面標題就是 App 頂端列的「行事曆」，頁面本身不再有大標題。行事曆填滿整個內容區、不留白：上面一列左邊是目前範圍（「2026 年」「2026 年 11 月」「2026 年 11 月 15 – 21 日」「2026 年 11 月 18 日 星期三」）、「今天」、‹ ›（上一段／下一段），右邊對齊右欄是年／月／週／日切換（記住上次的檢視）與「?」說明；下面左邊是月曆或時間表，右欄上面是小月曆、下面是未完成，之間都用細線分隔。月曆的每一週平均分配高度，一格放得下幾項就顯示幾項（跟著視窗大小）；時間表與未完成各自捲動。視窗窄於 900px 時右欄排到下面，整頁捲動。
  - **快捷鍵**（游標不在輸入框時）：Y／M／W／D 年／月／週／日，T 今天，J、N、→ 下一段，K、P、← 上一段，C 新增（開在月曆上方；原本的「＋ 建立」按鈕拿掉了，點空白處也能新增）。
  - **年檢視**：12 個月的小月曆（視窗夠寬時排成 3、4 欄，自己捲動）。有項目的日子底色依數量變深（1、2、3 項以上三種深淺），有過期沒做的任務是紅字，今天藍色圓底；滑鼠停在日子上顯示「11 月 18 日 星期三：1 個事件、3 個任務」。點日子切到那天的日檢視，點月份名稱切到那個月的月檢視；‹ › 換年。
  - **月檢視**：星期日開頭，只顯示有這個月日子的週（5 或 6 週）。每格列出那天的任務與事件（排在寫的那天；沒時間的在前，有時間的依時間排並顯示開始時間），放不下的收成「還有 N 項」。點日期數字或「還有 N 項」切到那天的日檢視。今天的日期數字是藍色圓底，週末格子底色略深，別的月份的日子變淡，事件有淡藍底，過期沒做的任務是紅字。
  - **週檢視、日檢視**：上方是日期列（點日期切到日檢視；日檢視有「開啟這天的日記」），下面是「全天」列（沒有時間的項目）與 0–24 時的時間表（一小時 48px，打開時捲到早上 7 點或更早的第一個項目）。有時間的項目依開始、結束時間排成方塊（只有開始時間的算一小時），事件藍色、任務灰色；時間重疊的並排並互相蓋住一點（像 Google 日曆）。今天那一欄底色淡藍，有一條紅色的現在時間線（每 30 秒更新）。
  - **時間**：寫在內容最前面 `- {o} 14:00-15:30 開會`（也可以只寫開始 `9:30`），普通文字，其他 Markdown 軟體也看得懂（`time.ts`）。
  - **新增**：點月曆格子的空白處、全天列或時間表的某個時段（對齊半小時，預設一小時），在點的位置旁邊開新增視窗：標題、事件／任務（點時段預設事件，其他預設任務）、日期、開始／結束時間（「全天」清掉時間），Enter 或「儲存」加到那天日記的最後面（`[[連結]]` 保留）。改開始時間時結束時間跟著移。點外面或 Esc 關掉，關掉的那一下不會又開新的。
  - **詳細**：點項目開詳細視窗：標題（裡面的 `[[連結]]` 可以點）、排在哪天的日期標籤、「Schedule」（日期選擇器，重新排程；只有未完成、已排程的任務與事件）、開始／結束時間（直接改、「全天」拿掉時間）、狀態（排程過的是已排程、完成、取消；其他是任務、完成、取消、事件）、寫在哪天、「開啟日記」。點符號仍然是直接切換完成。
  - **拖曳**：同一天裡拖到時間表改時間（對齊 15 分鐘，長度不變）、拖到全天列拿掉時間。拖到別天就是排程：原本那行標成 `<`、行尾寫上日期（事件還是事件，只加日期），拖回寫的那天就取消排程；拖到時間表時一併改時間。完成、取消的拖到別天沒有作用。 也可以拖到右邊小月曆或年檢視的日子（排程到那天）。拖曳時游標旁有項目名稱，拖到時間表會顯示放下的時間，目標格子反白，Esc 取消；放開後不會再開新增或詳細視窗。拖曳用指標事件實作（Tauri 在 Windows 開著原生檔案拖放時，網頁收不到 HTML5 的 drag 事件，在 App 裡拖不動）。
  - **右邊面板**：小月曆（換月、點日期跳過去，今天藍色圓底，有項目的日子下面有一點）與「未完成」：排在今天以前、還沒做的任務，每個有「Schedule」（日期選擇器，可以選今天，原本的標成 <）與「Cancel」。  - 視窗窄於 980px 時右邊面板排到月曆下方。
- **日記的「該做的事」**（`DayAgenda.tsx`、`agenda.ts`）：日記串與單日頁面的每一天，標題下方列出：
  - **Today’s Tasks／Today’s Events**（其他天是「Tasks for Nov 20」「Events for Nov 20」）：排程到這天、寫在別處（別天的日記或頁面）的任務與事件，依時間排，附來源（「from Nov 16」或頁面名稱）與「Reschedule」。排到這天的任務照一般任務顯示（符號是 ←），點符號完成。寫在這天日記裡的不重複列出。未來的日子在單日頁面也看得到。
  - **Overdue**（只有今天）：未完成或已排程、排的日子（排程日期，沒有就是寫的那天）在今天以前的任務，附日期標籤、「Schedule」（可以選今天）與「Cancel」。
  - 沒有項目時整塊不顯示。
- **排程**（2026-11-18 使用者說明：不是搬過去，而是像附加日期一樣出現在那天的「該做的事」）：任務留在寫它的地方，標成 `<`、行尾寫上排到的日期 `- {<} 任務 [[2026-11-20]]`。行事曆把它排在那天（寫的那天不再出現），那天日記上方的「該做的事」列出它，那天的反向連結也有它；過了那天沒完成就出現在今天的 Overdue。重新排程只換日期；排回寫的那天就拿掉日期、變回任務。完成時日期留著（還是排在那天）。沒有日期的 `{<}` 不會出現在行事曆。
- **日期與時間標籤**（2026-11-18 依使用者畫的樣子）：只有一行的子彈筆記任務，行首的時間與行尾的排程日期不顯示在文字裡，改在內容後面顯示外框標籤「2026/11/18 23:00」（只有日期「2026/11/18」、只有時間「09:00 – 10:30」）。未完成或已排程、日期已過的是紅色，今天是藍色，完成、取消的變淡。編輯時也一樣（時間藏在前綴、日期藏在結尾，打字、按 Enter 都不會動到它們，Enter 出來的新任務沒有日期時間）。點標籤開「Date & time」選單：改日期就是排程（標成 `{<}`）、「Clear」取消排程、開始／結束時間（改開始時結束跟著移）、「All day」拿掉時間。反向連結也顯示標籤（唯讀）。待辦清單與多行的任務照常顯示原文。
- **沒有手動附加日期的操作**：日期只由排程寫入（右鍵選單「排程到」、行事曆的「Schedule」、詳細視窗、拖到別天、該做的事的「Schedule／Reschedule」）。
- **Tasks 看板的卡片**（使用者：「Tasks的看板任務給予時間會出現在行事曆上」）：Desk 檔案 Tasks 分頁上有截止日的卡片也出現在行事曆（`CalendarView` 的 `desks`、`desk/tasks.ts` 的 `dueCards`）：排在截止日，有截止時間就放在週／日的時間表上，沒有就在全天列；標題前面有小看板圖示，滑過顯示「Tasks · 檔名 · 清單」。拖到別天改截止日，拖到時間表改截止時間；點符號切換完成；詳細視窗是 Not done／Done、Due date（改截止日）與 Open Tasks（打開那個檔案的 Tasks 分頁）。過了截止日沒完成的出現在 Overdue（可以改截止日，沒有 Cancel）。改的都是 Desk 檔案裡的看板，不寫進日記。
- 任務裡可以寫 `[[頁面]]`，專案或主題頁面的反向連結就會列出所有相關的任務。

### 已知限制

- 行事曆只看日記裡的任務；頁面裡的任務不會出現（但會出現在反向連結）。格子太小時文字會截斷。沒有重複的事件、提醒、拖曳改長度、刪除（用「取消」）；編輯器裡的時間只是普通文字。
- 排程日期只認一行的任務最後面的 `[[YYYY-MM-DD]]`；多行的任務裡的日期、時間照常顯示成文字。
- 沒有優先（`*`）與靈感（`!`）符號、沒有集合（Collections）頁、沒有習慣追蹤表。

## 試算表（`src/sheet/`，介面叫 Excel，參考 Numbers）

Desk 檔案的 Dock 裡的一種文件（取代原本參考 Notion 的資料庫）。像 Numbers：一份試算表有好幾張工作表，每張工作表是一張畫布，上面自由擺放表格與圖表。

- **建立**：Dock 的「＋」或空 Dock 的選擇裡選「Excel spreadsheet」；新的試算表有一張「Sheet 1」與一個 10 列 × 5 欄的「Table 1」（一列標題列、一欄標題欄）。也可以在白板選取卡片「Send to Dock」→ Excel（見 Desk）。
- **儲存**：存在 Desk 檔案（`desk/名稱.json`）的 `docs` 裡，`kind: "sheet"`，內容寫成 `sheet` 物件：工作表、表格（位置、列數、欄數、標題列／標題欄／表尾列的數目、欄寬、樣式、格子）、圖表。格子存打的原始文字（`=` 開頭是公式），沒有內容也沒有樣式的格子不存。
- **舊的資料庫**：Desk 檔案裡舊的資料庫文件（`kind: "database"`）讀進來時直接轉成一張表格（標題是文件名稱）：欄名是標題列、第一欄是標題欄、選項寫名稱、多選用逗號接、核取方塊變成勾選格式、建立／修改時間寫成日期時間；公式欄位與關聯沒辦法照搬，留空。下一次存檔就是試算表。舊的 `databases/*.json` 不再讀（之前已經搬進 Desk）。
- **畫面**（跟 Word、簡報一樣參考 Apple iWork 的 Numbers）：上方工具列是圖示在上、名稱在下的按鈕：Insert ▾（在選取的格子上下加列、左右加欄）、Formula ▾（Sum、Average、Minimum、Maximum、Count、Product、New Formula：在選取的格子開始打 `=SUM(`，接著點格子或拖範圍）、Table ▾（四種新表格）、Chart ▾（五種圖表）、Import、To Whiteboard，右邊是開關檢閱器的 Format 與 Organize。下面是工作表分頁（點了切換、連按兩下改名、「＋」新增、目前這張的「×」刪除）、公式列（左邊是選取的格子名稱，可以直接在這裡編輯），中間是畫布，右邊是檢閱器，下方是狀態列（選取範圍的 SUM、AVERAGE、MIN、MAX、COUNT）。復原、重做用 Ctrl＋Z／Ctrl＋Y。
- **檢閱器**：Format 有 Table、Cell、Text 三個分頁（選了格子先開 Cell，只選了表格開 Table，換過的分頁會記住）：Table 是表格樣式、交替列顏色、表格名稱與顯示名稱、標題列／標題欄／表尾列數、大小、Duplicate 與 Delete Table；Cell 是資料格式（小數位數、貨幣符號、千分位）、填色、條件式醒目提示；Text 是粗體／斜體／底線、文字顏色、對齊。選了圖表時是 Chart（圖表類型、標題、圖例、以列為數列、資料範圍、Delete Chart）。Organize 是排序（照選取格的那一欄遞增／遞減，標題與表尾列不動）與篩選。開著哪一個檢閱器會記住。
- **表格**：名稱在上方（連按兩下改名，Format 可以藏起來）；選取時出現欄名（A、B、C…）與列號，點了選整欄、整列，拖欄名右緣改欄寬。左上角的握把（或名稱）拖曳搬動表格、點了選取整個表格（Delete 刪除）；搬表格、圖表與改圖表大小時有輔助對齊（和 Draw、白板一樣：吸到其他表格與圖表的邊、中線或等距，沒有才對齊 8px 格線，顯示距離；選取後按住 Alt 滑過別的表格或圖表量距離；拖曳時按住 Alt 暫時不吸附）；右邊與下方的「＋」加一欄、一列；右下角的藍點拖曳加減列欄（不再跳確認視窗：直接改，狀態列提示「Removed 2 columns with content · Ctrl+Z to undo」）。刪除列欄還有：工具列 Delete ▾（Delete Row／Column，刪選取的列或欄，至少留一列一欄）、右鍵選單、Ctrl＋−（選了整列或整欄時）、Format → Table → Table Size 的 Rows／Columns（加減表尾前的列、右邊的欄）。標題列、標題欄、表尾列用表格樣式的顏色與粗體；可以開「Alternating row color」。
- **選取與編輯**：點格子選取、拖曳或 Shift＋點選範圍，方向鍵移動（Shift 延伸、Ctrl 跳到表格邊緣），Tab／Enter 往右／往下，Ctrl＋A 選整個表格。直接打字取代格子內容（一個隱藏的輸入框一直拿著焦點，中文輸入法也能用），連按兩下或 F2 編輯原本的內容，Enter／Tab 存起來，Esc 取消。Delete 清除內容；Ctrl＋B／I／U；Ctrl＋D 往下填滿、Ctrl＋R 往右填滿（公式的相對參照跟著位移）；Ctrl＋Z／Ctrl＋Y 復原、重做（每份試算表自己的歷史，最多 200 步）。勾選格點了打勾；星等點第幾顆就是幾分。
- **填滿控點**：選取範圍右下角的藍色小方塊，往下或往右拖就接著填（`features.ts` 的 `autofill`）：兩個以上的數字照等差接（1、3 → 5、7），一個日期每格加一天，「Item 1」→「Item 2」（「Q09」→「Q10」保留前面的 0），月份與星期（Jan、Monday，全名或縮寫，大小寫照原本）接著輪；貨幣、百分比保留寫法；有公式或空格就整組重複，公式的相對參照跟著位移。
- **列高**：選取時拖列號的下緣改列高（拖的列在選取裡就一起改），存在表格的 `rowH`；文字垂直置中。
- **右鍵選單**：上方／下方加列、前面／後面加欄（選了幾列就加幾列）、刪除列或欄、依目前這欄升冪／降冪排序內文列（標題列與表尾不動，同一列的公式跟著搬）、往下／往右填滿、清除內容、連樣式一起清除。
- **複製貼上**：Ctrl＋C／X／V 用 Tab 分隔的文字（可以和 Excel、Numbers、Google 試算表互貼）；在這裡複製的再貼回來會保留公式與樣式，公式的相對參照照位移調整。貼上的範圍超出表格時表格自動長大。
- **公式**（`formula.ts`）：`=` 開頭。參照 `A1`、`$A$1`、範圍 `A1:B5`、整欄 `B:B`（只算內文列，所以表尾可以寫 `=SUM(B:B)`），別的表格 `Table 2::A1`、別的工作表 `Sheet 2::Table 1::A1`（名稱有特殊字元用 `'…'`）。運算子 `+ - * / ^ & %`、比較 `= <> < > <= >=`。編輯公式時點別的格子（或拖一個範圍）就插入參照，參照到的格子用彩色框標出來；公式列右邊顯示目前函式的參數。函式：SUM、AVERAGE、MIN、MAX、COUNT、COUNTA、COUNTBLANK、COUNTIF、SUMIF、AVERAGEIF、PRODUCT、MEDIAN、IF、IFERROR、AND、OR、NOT、ISBLANK、ISNUMBER、ISTEXT、ISERROR、ROUND、ROUNDUP、ROUNDDOWN、INT、ABS、SIGN、SQRT、POWER、EXP、LN、LOG10、PI、MOD、CEILING、FLOOR、CONCAT（CONCATENATE）、LEN、UPPER、LOWER、PROPER、TRIM、LEFT、RIGHT、MID、FIND、SEARCH、SUBSTITUTE、REPT、VALUE、TODAY、NOW、DATE、YEAR、MONTH、DAY、WEEKDAY、DAYS、EDATE、VLOOKUP、INDEX、MATCH。錯誤顯示紅色的 `#DIV/0!`、`#VALUE!`、`#REF!`、`#NAME?`、`#NUM!`、`#N/A`、`#CIRC!`（互相參照）、`#ERROR!`（語法錯誤），滑過看原因。插入、刪除列欄與表格、工作表改名時，整份試算表裡指向它的公式一起改；參照的格子被刪掉變成 `#REF!`。
- **函式自動完成**：編輯公式時打函式名稱的開頭，下面列出符合的函式與參數（常用的排前面，SUM 在 SUBSTITUTE 前面）；↑↓ 選、Tab 或 Enter 插入「NAME(」、Esc 關掉；正在打的函式參數也顯示在公式列右邊。
- **尋找與取代**：Ctrl＋F 尋找、Ctrl＋H 取代：在目前工作表找顯示的文字（可以分大小寫、整格相同），找到的格子標黃色、目前這個深黃色，Enter／Shift＋Enter 下一個／上一個並選取它；「Replace」改目前這格、「All」全部改（只改格子打的文字，公式不動），狀態列顯示改了幾格。
- **資料格式**（Format → Cell）：Automatic（依打的內容：`$5` 貨幣、`15%` 百分比、`2026-11-18`／`11/18/2026` 日期，公式結果沿用來源的格式）、Number（小數位數、千分位）、Currency（符號 $、NT$、€、£、¥、HK$，小數位數）、Percentage、Date & Time（「Nov 18, 2026」）、Checkbox、Star Rating、Text（打什麼就是什麼）。`'` 開頭強制當文字。文字：粗體、斜體、底線、靠左／置中／靠右、文字顏色、格子底色。
- **條件式醒目提示**（Format → Conditional Highlighting）：「Add a Rule for B2:B5」在選取範圍加一條規則：條件（大於、至少、小於、至多、等於、不等於、介於、包含、不包含、開頭是、空白、不是空白、重複）與樣式（紅、黃、綠、藍、紫底，紅字、綠字、粗體）；顯示選取範圍碰到的規則，可以改或刪。數字條件的值可以寫「1,200」「15%」「2026-11-18」；文字比對不分大小寫。插入、刪除列欄時範圍跟著調整。
- **篩選**（Format → Filter）：「Add a Filter」加一條（預設是目前這欄、包含），選欄、條件與值；全部符合的內文列才顯示（標題列、表尾列永遠顯示），「Filter rows」可以暫時關掉。表格名稱旁顯示「Filtered · N hidden」，有篩選的欄名有小三角形；方向鍵跳過藏起來的列，狀態列的加總也不算它們。
- **表格設定**（Format → Table）：名稱、顯示名稱、標題列／標題欄／表尾列的數目（0–5）、六種樣式顏色、交錯的列底色、複製表格（放在原本的下面，名稱加「copy」）、刪除表格。
- **工作表**：分頁右鍵選單可以改名、複製工作表（表格、圖表一起複製，複本裡寫明表格名稱的公式改指向複本）、刪除。
- **匯入**（工具列「Import」，`importer.ts`、`formats.ts`）：
  - **活頁簿**（每張工作表變成一張新工作表與同名表格；目前的試算表還是全新空白就直接換掉）：.xlsx／.xlsm 保留文字、數字、布林、公式（`Sheet1!A1` 改成 `Sheet1::A1`、共用公式展開、拿掉 `_xlfn.`）、日期、百分比與貨幣格式、粗體斜體底線、對齊、欄寬；**舊版 Excel 97–2003 的 .xls**（自己讀 OLE 複合文件與 BIFF8：字串表、數字、RK、日期與百分比格式、欄寬；公式取 Excel 存的計算結果，錯誤顯示成 `#N/A`、`#DIV/0!` 等；有密碼或 Excel 95 以前的檔案會說明要先另存；網站下載、其實是網頁或 CSV 的 .xls 也認得）；**OpenDocument 的 .ods**（LibreOffice、Google 試算表下載：值、日期、百分比、貨幣、布林、公式從 OpenFormula 換過來、重複的列與欄、欄寬）。匯入的工作表或表格跟原本的撞名時加上數字，公式裡的參照跟著改（`=Notes::A1` → `=Notes 2::A1`），不會指到原本就有的同名工作表。
  - **表格**（放在目前工作表最下面，好幾個就一個接一個；第一列都是文字就當標題列）：.csv／.tsv／.tab／.txt（自動判斷逗號、分號或 Tab，支援引號與欄位裡的換行；編碼看 BOM、UTF-8、UTF-16，都不是就當 Big5——繁體中文版 Excel 存的 CSV）、.json（物件的陣列、陣列的陣列、藏在 `result.records` 這類欄位裡的陣列、以鍵分的物件）、.html（網頁裡每個 `<table>` 一個表格，處理 colspan／rowspan）、.md（Markdown 的表格）。解壓縮用瀏覽器內建的 DecompressionStream。Table 按鈕的四種新表格：Basic（標題列＋標題欄）、Header Row、With Totals（多一列表尾）、Plain。
- **圖表**：選一個範圍按「Chart」→ Column、Bar、Line、Area、Pie（只選一格就用整個表格），放在表格下面。範圍的第一列是標題列（或都不是數字）就當數列名稱，第一欄是標題欄（或都不是數字）就當類別。資料跟著表格即時更新。拖曳搬動、右下角改大小、Delete 刪除；Format 改種類、標題、圖例、「Plot rows as series」。
- **匯出 .xlsx**（`xlsx.ts`）：每個表格一張 Excel 工作表（工作表只有一個表格時用工作表名稱），寫入公式與算好的值、數字格式、粗體／斜體／底線／顏色／底色／對齊、欄寬，標題列凍結；指向別的表格的公式只寫值。不用額外的套件（zip 自己寫，不壓縮）。圖表不匯出。
- **To Whiteboard**：把選取範圍裡的內文列變成白板便利貼：第一欄是粗體標題，其餘是「欄名: 值」，排在白板既有內容的右邊。
- **Office 共同功能**（2026-11-19，對照表在 `Design/OfficeParity.md`）：
  - 格式：框線（Format → Cell → Border：全部、外框、內框、上下左右、無；存在格子的 `bd`）、合併儲存格（Merge／Unmerge 與右鍵，留左上角的內容，存在表格的 `merges`；方向鍵跳過合併的格子）、自動換行、垂直對齊（上、中、下）、字級、刪除線（Ctrl＋5）、增加／減少小數位數。
  - 資料：下拉清單（格式 Pop-Up Menu，選項一行一個；點格子的 ▾ 或 Alt＋↓ 選）、附註（Format → Cell → Note，格子右上角紅色三角形，滑過顯示）、隱藏列與欄（右鍵 Hide Rows／Columns、Unhide All，存在 `hideR`／`hideC`）、移除重複的列（Organize → Remove Duplicates，照選取的欄或整列）、Ctrl＋; 今天的日期、Ctrl＋Shift＋; 現在時間。
  - 函式多了 35 個左右：SUMIFS、COUNTIFS、AVERAGEIFS、MAXIFS、MINIFS、XLOOKUP、HLOOKUP、IFS、SWITCH、CHOOSE、IFNA、ISNA、NA、TEXT、TEXTJOIN、EXACT、CHAR、UNICHAR、CODE、LARGE、SMALL、RANK、STDEV、STDEVP、VAR、VARP、MODE、SUMPRODUCT、RAND、RANDBETWEEN、TRUNC、LOG、ISODD、ISEVEN、HOUR、MINUTE、SECOND、TIME、EOMONTH、NETWORKDAYS。
  - 匯出：Export 選單有 Excel workbook（.xlsx，多寫合併、框線、換行、字級、刪除線、垂直對齊、隱藏列欄、列高、下拉清單的資料驗證）、CSV（最後選的表格，UTF-8 加 BOM）、Print or Save as PDF（目前這張工作表，縮到一頁橫向 A4 的寬度）。

### 已知限制

- 沒有凍結窗格；換行的格子不會自動長高（拖列號改列高）；沒有換行的格子文字超出寬度就截斷。
- 匯入 .xlsx 不讀圖表、合併儲存格、條件式格式、顏色與框線；Excel 有、這裡沒有的函式會顯示 `#ERROR!`。圖表不會匯出到 .xlsx。
- 篩選與醒目提示不會匯出到 .xlsx；填滿控點只能往下或往右。
- 表格很大（上千列）時每次修改整份重算、整個表格重畫，會變慢。
- 只有表格與圖表，沒有文字方塊、圖片等其他畫布物件；表格、圖表不能跨工作表搬。
- 舊資料庫的公式、關聯欄位轉換時留空。

## Desk（`src/desk/`：Whiteboard 發想＋Dock 整理）

側邊欄「Desk」（Alt＋Shift＋2）。Desk 由檔案（File）組成，每個檔案是一個專案，有兩個部分。切換在 App 頂端列的檔名後面：只有圖示的兩格分段按鈕（白板、Dock，目前的那格是白底與藍色圖示，名稱在提示裡），或按 Alt＋D 互換；檔案內容上方不再另佔一列：

- **Whiteboard**（發想）：把想到的直接貼上去，不用管順序。從之前拿掉的 Heptabase 式白板（commit 35beb08）改回來，加上便利貼。
- **Dock**（整理）：把想法整理成可以發表的文件，五種：Word 文件、簡報、Excel 試算表、Draw（圖表）、一般筆記；試算表與 Draw 以外都是 Markdown。
- **Tasks**（任務，參考 Trello）：和 Whiteboard、Dock 並列的第三個分頁（獨立於 Dock，一個檔案一個看板），詳見下方。

存成 App 資料夾的 `desk/名稱.json`（`desk_list`／`desk_read`／`desk_write`，檔名編碼和頁面相同，名稱不分大小寫）：`board`（卡片、連線、區段）與 `docs`（每份文件的 id、標題、種類、Markdown；試算表是 `sheet` 物件、Draw 是 `draw` 物件；在資料夾裡的文件有 `folder`），以及 Dock 的資料夾 `folders`（id、名稱，沒有就不寫）。只有前端時存在 localStorage。白板的畫面位置與 Dock 上次開的文件是個人瀏覽狀態，存在 localStorage。

- **Desk 首頁**（`DeskHome.tsx`、`home.ts`）：標題列只有「Desk」、搜尋框、New file。
  - **New file**：先跳出範本選擇器（`TemplateGallery.tsx`，參考 Pages／Keynote／Numbers：一格一格的縮圖，方向鍵選、Enter 建立、Esc 取消），內建 Blank、Project（To do／Doing／Done 看板＋Project brief Word＋Tasks Excel）、Research（研究問題心智圖＋Notes 筆記＋Write-up Word）、Presentation（Hook→Ask 五張連起來的便利貼＋Slides 簡報＋Speaker notes）、Meeting（Agenda／Parking lot＋Minutes Word），後面是使用者存的範本（滑過可刪）。挑好後標題下出現檔名輸入列（預設是範本名稱，空白範本是「Untitled」，不重複），Enter 建立並開啟（同名的已經有了就開那一個），Esc 或離開取消（`deskTemplates.ts`）。
  - **存成範本**：檔案卡片滑過出現範本按鈕，把整個檔案（白板＋Dock）存成使用者範本（名稱同檔名，重複加數字），存在 `desk-templates/名稱.json`（Rust `desk_template_list`／`desk_template_read`／`desk_template_write`；瀏覽器預覽存在 localStorage）。
  - **檔案卡片**：白板縮圖（區段、連線、卡片、便利貼顏色、心智圖主題的方塊）、檔名、文件數與「Opened／Edited … ago」。最近打開或編輯的排前面，沒有紀錄的照名稱。滑過出現刪除（先確認，連同白板與所有 Dock 文件；白板上的頁面與日記不受影響）；鍵盤 Enter 打開、Delete 刪除。
  - **搜尋**：檔名、文件標題、便利貼文字、頁面與日記卡片、區段標題、心智圖中心主題（空白分開的每個詞都要有）。
  - **最近活動**：打開檔案、改了內容時記在 localStorage（`banyan.deskActivity`，個人瀏覽狀態，不寫進檔案；刪檔案時一起清掉）。
  - 沒有檔案時是空狀態「Your desk is clear」。檔案可以收藏、出現在「最近」，頂端列可以刪除。
  - **改名**：首頁卡片的筆按鈕、F2 或按兩下檔名，或在檔案裡按兩下頂端列的檔名；Enter 確定、Esc 取消。和別的檔案同名（不分大小寫）時不改並顯示訊息；只改大小寫也可以。檔案與版本歷史一起搬（Rust `desk_rename`），日記、頁面與各檔案 Word／簡報／筆記裡的 `[[舊名/文件]]` 改成新名稱，收藏、最近、上一頁／下一頁、Desk 上次的地方、白板畫面位置與 Dock 上次的文件都跟著換。
  - **記住上次的地方**：側邊欄的 Desk（Alt＋Shift＋2）從別的畫面按，直接回到上次在 Desk 停的地方（某個檔案的白板，或 Dock 裡的某份文件；上次在首頁就是首頁；檔案刪掉了就回首頁），存在 localStorage（`banyan.deskLast`）。已經在檔案裡再按一次 Desk 回到首頁。
  - **分割視窗**（`panes.ts`＋`DockGroups.tsx`，參考 VS Code 的編輯器群組）：Dock 右邊是一個或多個群組，可以左右或上下分割（巢狀，最多 6 個群組），每個群組上方一排分頁。同一份文件只開在一個群組（分割是把分頁搬過去，不是複製）。清單點一下開成**預覽分頁**（斜體，下次點別的文件時被取代；編輯內容、改標題或按兩下分頁就固定），新增、匯入的文件直接是固定分頁；已經開著就換到那個分頁。分頁：點了切換、拖曳排順序、拖到別的群組的分頁列、拖到群組內容的左／右／上／下邊分割出新群組（中間是放進那個群組，放下的範圍會標出來），× 或中鍵關掉（只剩一個分頁時不能關），右鍵選單有 Close、Close Others、Close to the Right、Close Group、Keep Open、Split Right／Down、Move to Group N。清單上的文件也可以直接拖進群組或群組的一邊。分頁列右邊的分割按鈕（Alt＋\，Alt＋點擊或 Alt＋Shift＋\ 往下）：群組有好幾個分頁就把作用中分頁搬到新群組，只有一個就開清單上下一份還沒開的文件；清單上 Alt＋點擊或右鍵「Open to the side」開在右邊的群組（沒有就分割）。點哪個群組就是操作中的群組（作用中分頁上緣綠線；它的文件就是畫面上的文件，記進最近、收藏、版本歷史）；開在分頁裡的文件在清單左邊有綠線。分隔線可以拖（每邊至少 10%）。Alt＋W 關掉作用中分頁、Alt＋Shift＋T 把最近關掉的分頁放回原來的群組與位置（記住最近 10 個，刪掉的文件跳過）、Alt＋PageUp／PageDown 換分頁（加 Shift 換群組）。群組空了就拿掉。版面、分頁與關掉的紀錄每個檔案記在 localStorage（`banyan.deskPanes.名稱`，改名時跟著搬；舊版的並排窗格自動轉成一排群組）。
  - **Dock 文件的最近與收藏**：在 Dock 打開的文件會出現在側邊欄「最近」（文件標題、種類圖示，右邊是檔案名稱），頂端列的星號或 Alt＋S 收藏的是正在看的文件（在白板上則是整個檔案）；點了打開那個檔案的 Dock 並選取文件。刪掉的文件不再列出；刪除檔案時它的文件一起從收藏、最近拿掉。Dock 換文件也記進上一頁／下一頁。
- **介面（簡化過）**：左上的工具列只有三個圖示（沒有文字，名稱與快捷鍵在滑過的提示裡）：便利貼、頁面與 **＋ Insert**（選單：Section、Mind map、Image or video、Code、Diagram、Table，提示在滑過時出現）；選了東西時後面接著選取數量的小圓標（兩個以上）、Send to Dock 與刪除的圖示。空白處的右鍵選單是 Add note here、Add page or journal here、一列六個圖示（滑過看名稱）與 Fit to screen。畫布上沒有操作提示（空白板有自己的說明），白板快捷鍵在快捷鍵一覽（Ctrl＋/）的 Whiteboard 一組。
- **便利貼**：連按兩下空白處、按 N、工具列「Note」或右鍵「Add note here」新增一張並直接打字；在畫布上貼上文字也成一張（放在滑鼠最後的位置）。內容是 Markdown、存在檔案裡，用和頁面相同的編輯器；預設黃色，右鍵可以換九種顏色。
- **媒體卡片**（`boardMedia.ts`）：圖片、GIF、影片放在白板上，和卡片一樣可以搬移、框選、連線、放進區段、刪除、復原、送到 Dock。
  - 加入：在畫布上 Ctrl＋V 貼上圖片／影片檔（截圖、從檔案總管複製）；從檔案總管拖進來（Tauri 的 `onDragDropEvent`，放在便利貼或頁面卡片的編輯器上的照舊放進那份文件）；工具列「Media」或右鍵「Add image or video here…」選檔案。檔案和編輯器一樣存到 `media/`（`save_media`／`import_media`；瀏覽器預覽存成 data URL）。
  - 網址：貼上 YouTube（watch、youtu.be、shorts、embed，帶 `t=` 的從那裡開始）或 Vimeo 網址是嵌入影片（iframe）；結尾是 .mp4／.webm／.mov 等的網址是影片，.png／.gif／.jpg 等是圖片；其他文字照舊變成便利貼。
  - 大小：照原始比例，長邊最多 480（小圖保持原大），嵌入影片 560×315；拖右下角改大小時保持比例（吸附其他東西的邊）。
  - 影片與嵌入影片沒選取時點下去是選取、拖曳；選取後才能播放，拖上方浮出的握把搬移。找不到檔案時顯示「Image not found／Video not found」。
  - 送到 Dock：圖片是 `![](media/…)`、影片是 `<video>` 區塊、嵌入影片是網址；試算表一列寫「Image／Video」。
  - 存在白板 JSON 的 `cards`：`ref: { kind: "media", type: "image" | "video" | "embed", src }`，`h` 一定有值；格式不對的略過。
- **複製、貼上**：選取後 Ctrl＋C／Ctrl＋X 複製、剪下（卡片、區段連同裡面的東西、心智圖，以及兩端都有複製到的連線），Ctrl＋V 貼在滑鼠位置（全部換新 id，頁面／日記卡片白板上已經有的不再加、連線接到原本那張），Ctrl＋D 原地複製一份。剪貼簿裡是 JSON 文字（`copyItems`、`clipText`、`parseClip`、`pasteItems`）。
- **圖表卡片（Draw）**：工具列 Insert ▾ 的「Diagram」、右鍵選單的圖示列放一張空白的圖表卡片，直接在白板上方打開完整的 Draw 編輯器（圖形、連線、文字、畫板、圖片、樣式列，和 Dock 的 Draw 同一套 `DrawView`）；改了就存回卡片，Done 回到白板。卡片上顯示圖表的圖（和匯出的 SVG 同一套，白底），連按兩下、卡片右上角的 Edit 或右鍵「Edit diagram」再打開；大小固定、可以拉大縮小、可以和其他卡片連線。編輯器上方的 Send to Dock 把這張圖表變成 Dock 裡的 Draw 文件；在白板上選取卡片送到 Draw 文件時，圖表卡片整張貼過去（其他卡片各變成一個圖形），送到 Word／簡報時寫出圖上的文字（一個圖形一個清單項目）。圖表存在卡片的 `text`（`board.ts` 的 `{ kind: "draw" }`、`addDraw`、`fixedSize`；`draw.ts` 的 `appendDiagram`、`diagramText`）。
- **表格卡片**：工具列 Insert ▾ 的「Table」、右鍵選單的圖示列放一張表格卡片（3 欄 4 列、第一列是標題），直接在白板上方打開完整的 Excel（和 Dock 的 Excel 同一套 `SheetView`：公式、格式、多個表格、圖表）；改了就存回卡片，Done 時卡片照表格調整大小。白板上直接畫出表格（算好的值、標題列與表尾列上色、跟著淺色／深色），連按兩下、Enter、卡片的 Edit 或右鍵「Edit table」再打開。從 Excel、Google 試算表、Numbers 複製格子貼到白板（每列有 Tab、欄數一樣）就變成表格卡片。送到 Dock：送到 Excel 文件是整份接上（新的工作表，撞名改名、換新 id），送到 Word／簡報是表格區塊（顯示的值）；編輯器上方的 Send to Dock 變成新的 Excel 文件。活頁簿存在卡片的 `text`（`board.ts` 的 `{ kind: "sheet" }`、`addTableCard`、`editsInPlace`；`boardSheet.ts`；`bridge.ts` 的 `cardsIntoWorkbook`；`importer.ts` 的 `appendWorkbook`）。
- **程式碼卡片**：工具列「Code」、右鍵「Add code block here」，或在畫布上貼上一整段 ``` 區塊（認得語言）。和便利貼一樣直接在卡片裡打字（Tab 兩個空白、Shift＋Tab 減少、Esc 回到畫布），語法上色、上方的語言選單與 Copy 和編輯器的程式碼區塊共用；高度跟著內容，可以改寬高、連線、放進區段、複製貼上。存在白板 JSON：`ref: { kind: "code", lang }`，程式碼在 `text`。送到 Dock 是一個 ``` 區塊。
- **心智圖範本**：白板只剩心智圖一種範本：工具列「Mind map」、空白白板的「Start a mind map」或右鍵「Add mind map here」放一張（`templates.ts`）；從工具列或空白白板加的放在畫面中央，白板已有內容時排在右邊；右鍵加的以按的位置為左上角。放好後選取它並讓畫面對準它。
- **心智圖**（參考 XMind，`mindmap.ts`、`MindMapView.tsx`）：白板上的一種物件，存在白板 JSON 的 `maps`（主題樹：id、文字、子主題、收合）。新的一張是 XMind 的預設：「Central Topic」＋四個「Main Topic」。
  - 自動排版：主要主題左右平均分配（前一半在右邊由上往下、其餘在左邊，順時針），子主題往外長、父主題在子主題群的垂直中央；主題大小用 canvas 量字寬，打字時跟著長。
  - 樣式：中心主題深色實心（深色主題反過來）、主要主題用分支顏色實心白字（八種顏色輪流）、子主題只有分支顏色的底線；連線是分支顏色的曲線（主要分支較粗）。主題是純文字，Shift＋Enter 換行。

    - Board：清單一欄一欄由左到右，清單下方「Add a card」打標題按 Enter 加一張並繼續輸入下一張（Esc 或空白結束）；最右邊「Add a list」。拖曳卡片換位置或換到別的清單（插入的位置顯示一條綠線），拖曳清單標題換清單的順序；點清單名稱改名；清單的「⋯」選單有 Add a card、Delete list（有卡片時再按一次確認，連卡片一起刪）。卡片上顯示標籤色條（有名稱就顯示名稱）、標題、截止日（今天或明天到期是黃色、過期是紅色、完成是綠色；點了切換完成）、有說明的圖示與檢查清單進度。
    - 選了卡片右邊出現 Card 檢閱器：標題、所在清單、Mark as complete、截止日（日期＋可省略的時間，顯示 Due today／Due tomorrow／Overdue）、標籤（六種顏色，點色塊加上或拿掉，旁邊改名稱，名稱整個看板共用）、說明（純文字）、檢查清單（勾選、改字、刪除、Enter 新增，上方進度條）、Delete Card。Delete 鍵刪除選取的卡片、Esc 取消選取、Ctrl＋Z／Y 復原（打字時同一個欄位連續的修改併成一步）。
    - Calendar：**有卡片設了截止日才出現**（`hasDue`；沒有了就回到 Board）。月曆（星期日開頭，6 週），卡片依截止日顯示（有時間的照時間排、標籤小圓點、過期與快到期在左邊加色條、完成的劃掉）；‹ › 換月、Today；打開時這個月沒有到期的卡片就跳到最近一張的月份。拖曳卡片到別天就是改截止日；連按兩下某一天在第一個清單加一張那天到期的卡片；點卡片打開檢閱器。看的是 Board 還是 Calendar 每份文件記在 localStorage（`banyan.tasksView.文件id`）。
    - Export：Markdown（每個清單一個標題，卡片是待辦清單，截止日與標籤寫在後面，說明與檢查清單縮排在下面）或 CSV（一張卡片一列：清單、卡片、截止日、時間、完成、標籤、檢查清單進度、說明）。

    - 有截止日的卡片也出現在側邊欄的 Calendar（Alt＋Shift＋1），在那裡可以改截止日與時間、標成完成。
    - 存檔寫成檔案的 `tasks` 物件（`lists`、`labels`、`cards`；卡片的 `list` 指向清單，清單裡的順序就是 `cards` 的順序）。版本歷史在 Tasks 分頁只看看板的版本（`part` 是 `tasks`），預覽是唯讀的看板，新增或改過的卡片加框；還原只換回看板，做副本是只有看板的新檔案。

  - **Slides** 工具列的 Import 把投影片接在最後面（原本只有空白投影片就換掉，經過 `commit` 可以 Ctrl＋Z 一次復原，匯入的投影片會被選取）：.pptx 與 .odp（標題、內文版面配置區的段落變成項目符號、文字方塊是一般段落、圖片、備忘稿放進每張的設定；版面位置、字型與動畫不保留）、Markdown（單獨一行的 `---` 分張，Marp／Slidev 的 front matter 去掉；沒有的話照 `#` 或 `##` 標題分張）。舊的 .ppt 會說明要先另存成 .pptx。
  - **Dock 的新增選單「Import a File…」**：依副檔名建立新文件（簡報檔 → Slides、試算表檔 → Excel、其他 → Word），標題是檔名，放在開著的文件所在的資料夾並打開；結果顯示在 Documents 上方。
- **匯出**：`docx`、`pptxgenjs` 用到時才載入（`export.ts`）；共用 `mdblocks.ts` 把 Markdown（CommonMark token）轉成段落與有格式的文字。檔案存到「下載」資料夾（Rust `export_save`，同名加 (1)、(2)…），存好在檔案總管裡選取它（`opener:allow-reveal-item-in-dir`）；只有前端時用瀏覽器下載。

### 已知限制

- Word 的分頁以區塊為單位，一個很長的區塊不會被切開（照樣跨過頁邊界）；匯出的 .docx 由 Word 自己重新分頁。
- 投影片編輯時改區塊結構（例如插入 `---`）會重新分張，編輯中的那張會結束編輯。
- 匯出不含表格、影片、縮排與多欄排版（只留文字或略過）、文字顏色。
- 便利貼不是頁面，不會出現在反向連結與「所有頁面」。
- 檔案不能改名。
- Draw：連線不能自己加轉折點、沒有旋轉、不能匯入 .drawio 或 Figma 檔；直角路線不會繞開中間的圖形。網頁設計沒有元件（Component）、自動排版（Auto layout）、約束（Constraints）與巢狀畫板；匯出的 HTML 是固定位置，不會隨視窗寬度調整。

## Drawer（`src/drawer/`，文獻庫，參考 Zotero）

- **入口**：側邊欄「Drawer」（Alt＋Shift＋3），回到上次看的那一頁（記在 localStorage `banyan.drawerTab`）。跟 Desk 檔案的 Whiteboard／Dock／Tasks 一樣分成兩頁：頂端列標題後面只有圖示的切換鈕 Library（文獻庫）／Files（檔案庫），Alt＋D 輪流換，上一頁／下一頁也記得換頁；左欄只顯示那一頁的樹。從別的地方跳過來（備註的引用、Show 重複檔案、Convert to item、加入檔案）會自動換到對的那一頁。Library 頁三欄：左邊上方是 Library（My Library、Unfiled Items、Trash），下面另一段是 Collections（自己的收藏，標題旁的 ＋ 新增，沒有收藏時顯示 New collection），最下面是標籤；中間是條目清單，右邊是選到的條目的資料（視窗窄於 1100px 時右欄移到下面）。
- **儲存**：整個文獻庫是一份 `drawer/library.json`（Rust 指令 `drawer_read`、`drawer_write`，先寫暫存檔再改名；在 `data_root()` 底下，換儲存位置時一起複製）；瀏覽器預覽時存在 localStorage（`banyan.drawer`）。用 `useDocs` 管理，只有一份文件（鍵 `library`）。左欄選的範圍、檔案庫打開的資料夾、排序、引用格式、收合的收藏記在 localStorage（`banyan.drawerUi`）。
- **條目**（`model.ts`）：八種類型（Journal Article、Book、Book Section、Conference Paper、Thesis、Report、Web Page、Document），各有自己的欄位（期刊／書名／會議名稱、卷、期、頁、出版社、地點、版次、日期、DOI、ISBN、網址、存取日期、語言）、作者與編者、摘要、標籤、所屬收藏、附件。右欄直接編輯，打字就存；作者一列一位（姓、名、作者／編者），在空的姓欄貼上「Smith, John; Lee, Ann」會拆成好幾位。
- **引用鍵**：加入時自動產生（第一作者的姓＋年份＋標題第一個有意義的字，例如 `vaswani2017attention`，重複的加 a、b…），可以改（不能重複或空白）。
- **筆記與引用**：每個條目的筆記是一般頁面 `@引用鍵`（右欄「New note／Notes」，第一次打開時寫上 APA 參考文獻）；在日記或頁面寫 `[[@引用鍵]]` 就是引用它，`[[` 自動完成會列出所有條目，右欄「Cited in」列出引用它的日記與頁面（反向連結）。
- **在 Markdown 裡引用**（`citeRef.ts`）：任何編輯器（日記、頁面、Desk 的 Word／簡報）打 `[[@` 或斜線選單「Citation」出現「Cite from Drawer」，依標題、作者、年份、引用鍵搜尋條目，選了寫入 `[[@引用鍵]]`（原始碼不變，仍是頁面連結，CommonMark 照舊）。不在編輯時顯示成文中引用「(Smith & Lee, 2020)」，相鄰的引用（中間只有空白或分號）合成一個括號「(Smith & Lee, 2020; Adams, 2019)」；滑過顯示完整參考文獻，點了打開條目的筆記頁面（第一次打開寫上參考文獻）。格式跟著 Drawer 選的 APA／MLA。編輯中顯示原始的 `[[@引用鍵]]`（虛線底線、滑過顯示引用）；文獻庫不認得的引用鍵照常是頁面連結。斜線選單「Bibliography」把這份文件引用到的條目排好，一筆一個清單項目插入（沒有引用就不插入）。
- **備註**（Remarks 分頁）：條目上的短筆記（摘錄、發現、想法），一則一張卡片，可以記頁碼（`12`、`12-14`、`chap. 3`），可以上下搬移、刪除；Add remark 新增後游標直接放進去。每則有固定編號（`r1`、`r2`…，刪掉的編號不再使用，舊的引用不會指到別則）。別的地方用 `[[@引用鍵#r1]]` 引用：顯示成帶頁碼的文中引用「(Vaswani et al., 2017, pp. 3–4)」（MLA「(Vaswani et al. 3–4)」），可以和相鄰引用合併，滑過看備註文字與參考文獻，點了在 Drawer 選取條目、打開 Remarks 並標出那一則；`![[@引用鍵#r1]]` 單獨一段時嵌入備註內容（Markdown）與引用。`[[@引用鍵#` 的自動完成列出那個條目的備註，`[[@` 一般搜尋也找得到備註文字；卡片上可以複製引用或嵌入的寫法，並列出引用它的日記與頁面；條目的 Cited in 包含引用備註的地方；引用備註也算引用了條目（Bibliography）。Drawer 的搜尋也找備註文字。
- **新增**：New item（選類型，放進目前的收藏）；Add by identifier（貼上 DOI、DOI 網址、arXiv ID、ISBN 或網址，一行一個）：DOI 與 arXiv 向 doi.org 要 CSL-JSON，ISBN 查 Open Library，網址建一個網頁條目；已經有的（DOI、ISBN 或標題＋年份相同）不重複加，改成選取它。Import：BibTeX（`@string` 巨集、`#` 串接、LaTeX 重音、機構作者）與 CSL-JSON（Zotero 等匯出的 .json）。在 App 裡從檔案總管把檔案拖進來：放在條目上是附加，放在其他地方每個檔案建一個條目（附件就是那個檔案）。
- **收藏**：可以巢狀（New subcollection），選一個收藏時也列出子收藏裡的條目；條目可以在好幾個收藏裡。把條目拖到左欄的收藏就加入（拖到 Trash 是丟掉、拖到 Unfiled Items 是移出目前的收藏）；收藏也能拖到別的收藏底下，拖到 Collections 標題或 My Library 是移到最上層。右鍵：新增子收藏、改名（F2、連按兩下）、移到最上層、刪除（條目留著）。另有 My Library（全部）、Unfiled Items（不在任何收藏）、Trash。
- **標籤**：左下列出所有標籤，點一下篩選（可以多選，要全部符合）；右鍵改名（改成已有的就是合併）或刪除。右欄打字加標籤（Enter 或逗號，有自動完成）。
- **清單**：Title、Creator（Smith、Smith and Lee、Smith et al.）、Year、附件欄，點欄名排序（空的排最後），附件欄排的是加入時間；搜尋標題、作者、年份、出處、標籤、引用鍵、DOI、摘要。點選、Shift／Ctrl＋點擊、↑／↓、Ctrl＋A；Delete 丟到垃圾桶（在垃圾桶裡是永久刪除，會先確認）；Ctrl＋C 複製參考文獻、Ctrl＋Shift＋C 複製文中引用；連按兩下打開第一個附件（沒有就開 DOI 或網址）。右鍵選單（沿用白板的 `block-menu`）：複製參考文獻／文中引用／`[[@引用鍵]]`／BibTeX、打開筆記、加入收藏、移出收藏、丟到垃圾桶；在垃圾桶是還原與永久刪除。拖曳用指標事件。
- **附件**：Attach file（存到 `media/`，和圖片一樣以內容雜湊命名）、From Files…（從檔案庫選，可以連續選好幾個）或 Attach link。檔案附件一律也存在檔案庫（使用者：「文獻庫添加附件可以自動儲進檔案庫 而檔案庫亦能成為附件」）：附加時檔案庫已經有同樣內容的檔案就連到那一筆（在垃圾桶就拿出來），沒有就在 Unfiled 新增一筆；舊資料打開 Drawer 時自動補上。附件旁的 Drawer 圖示是 Show in Files；拿掉附件時檔案留在檔案庫。點檔案（附件或檔案庫的檔案）在 Drawer 裡打開檢視（`FilePreview.tsx`、`preview.ts`）：PDF 與 HTML（沙盒，不跑程式）用 iframe；圖片、影片、音訊直接播放；Markdown 照編輯器的樣子渲染；程式碼與純文字依副檔名上色（超過 200 KB 不上色，超過 2 MB 只顯示前面）；CSV／TSV 與 Excel（.xlsx）變成唯讀的試算表（可以換工作表、捲動、選取，公式照算）；Word（.docx）顯示標題、段落、粗體斜體底線刪除線、上下標、清單、表格與連結；PowerPoint（.pptx）每張投影片一張卡片（標題與內文）；其他副檔名內容是文字的也當純文字顯示。文件裡的連結用瀏覽器開，不會讓 App 跳走。Show in folder 在檔案總管裡選取。
- **檔案庫**（`files.ts`、`FilesPane.tsx`；使用者：「檔案庫的資料邏輯 和文獻庫的資料庫一樣」）：Drawer 的 Files 頁，運作方式和文獻庫一樣（參考 Zotero）。左欄上方是 Files（All Files、Unfiled Files、Trash），下面是 Folders（資料夾樹，標題旁的 ＋ 新增，沒有資料夾時顯示 New folder；新增後直接改名），最下面是檔案的標籤（點了篩選，可以選好幾個；右鍵改名或刪除，和條目的標籤分開）。資料夾像收藏：一個檔案可以在好幾個資料夾，資料夾的範圍包含子資料夾；把檔案拖到資料夾上是加入（原本的資料夾保留），資料夾拖到別的資料夾是搬過去、拖到 Folders 標題是搬到最上層；刪資料夾（連同子資料夾）時檔案留在 All Files。中間是範圍裡的檔案：上方是範圍名稱或資料夾路徑（每一層都能點、也能把檔案拖上去）、搜尋（名稱與標籤）；Add files（加進目前的資料夾，不在資料夾裡就是 Unfiled）、New folder（Ctrl＋Shift＋N，在目前的資料夾裡）、Find duplicates、大圖示（圖片顯示縮圖、其他依類型上色並標副檔名）／詳細資料（名稱、加入日期（All Files 與搜尋時換成所在資料夾）、類型、大小；點標題排序，記在 localStorage `banyan.drawerFilesSort`）切換（記在 `banyan.drawerFilesView`）。點選、Shift／Ctrl＋點擊、方向鍵、Ctrl＋A；Enter 或連按兩下在 Drawer 的檢視器打開；F2 改名；Delete 移到垃圾桶（在 Trash 裡是永久刪除，先確認；Empty Trash）；Ctrl＋X、Ctrl＋V 剪下貼上（從剪下時的資料夾搬到目前的資料夾）。檔案名稱可以重複（像條目），資料夾同一層不重名（加 (2)，不分大小寫，不能用 `\ / : * ? " < > |`）。右欄是選取的檔案：預覽、類型、大小、所在的資料夾（點了過去，滑過可以從那個資料夾拿掉）、加入日期、標籤、Open、Show in folder、Attach to item…（選條目附加，可以連續選好幾個，已經附加的打勾）、Create item（用這個檔案建一個新條目、附件連到它，檔案留著）、Move to Trash（在 Trash 裡是 Restore、Delete permanently；永久刪除時連到它的附件一起拿掉，確認時會說），以及「Attached to」（連到它的條目，Show 過去）與「Same file also in」（另外存放的副本）。右鍵選單：Open、Show in folder、Attach to item…、Create item from file、Add to folder（資料夾清單）、Remove from folder（在資料夾裡時）、Cut、Rename、Move to Trash；空白處右鍵是新增資料夾、加入檔案、貼上、找重複。在 App 裡從檔案總管拖進來：放在 Files 頁的畫面或左欄的資料夾上就加進那個資料夾。資料夾與檔案存在同一份 `library.json`（`folders`、檔案的 `folders`、`tags`、`trashed`；舊版一個檔案一個 `folder` 的資料讀進來時轉換），檔案內容和附件一樣在 `media/`；永久刪除只拿掉紀錄，`media/` 的檔案留著。
- **插入 Excel 的表格、圖表**（`src/sheet/sheetEmbed.tsx`、`embedEdit.tsx`、`SheetPicker.tsx`、`pickSheet.ts`；使用者：「在Dock的Word, Slides和Note都可以插入Excels的表格和圖表」「會感覺像Notion的Database Excel就母體 … 我在Word更改資料時Excel都會改變 唯一不同的是表格的樣式可以不一樣」，參考 Notion 的 Linked database、Pages／Word 從 Numbers／Excel 插入）：Word 與 Slides 工具列的 Table 變成選單（New Table、From Excel…），Note（以及日記、頁面）用斜線選單「Excel table or chart」。對話框：左邊是所有 Desk 檔案 Dock 裡的 Excel 文件（標題＋檔案名稱），中間是它的表格與圖表（照工作表分組），右邊是預覽；搜尋文件與表格、圖表的名稱；點一下選取、連按兩下或 Enter 插入、Esc 取消。插入的是連結 `![[檔案/標題#^id]]`（嵌入的寫法加上表格或圖表的 id，表格改名、Excel 文件或檔案改名都不會斷）。**資料只有一份，Excel 是本體**：表格顯示 Excel 現在的值（公式算好、照格子的格式、條件式醒目提示、篩選掉與藏起來的列欄不顯示、合併格子）；在文件裡點格子直接編輯（浮出輸入框，內容是原始文字、公式顯示公式；Enter 存並往下、Tab／Shift＋Tab 往右／左、Esc 取消、點別處存），改的是 Excel，所有嵌入這個表格的地方與 Excel 一起變；在 Excel 改了文件也跟著變。**樣子可以每個位置不一樣**：滑過表格時標題列右邊出現「Linked · edits update Excel」與 Style，Style 選單有顏色（Excel 的、六種主題、不上色）、Banded rows、Text size（Small／Normal／Large）、Fit to page width、Use Excel’s style；選項寫在連結的 `|` 後面（`![[Budget/Q1#^t1|orange banded full]]`），Excel 裡的表格樣式不變。圖表顯示試算表同一個 SVG（縮放到文件寬度），跟著試算表變。**來源列**（使用者：「我希望有引用的外框」，之後「把那個綠色外框刪掉」）：嵌入的表格與圖表上方是淡綠色的來源列「▢ 檔案/標題 ↗ · 表格名稱」，內容是白底，一看就知道是從 Excel 引用的；沒有外框線。標題列的「檔案/標題」點了打開那份 Excel；表格或圖表刪掉了顯示「This table or chart was deleted」；點格子以外的地方照常編輯那一行參照。在文件裡改格子不會進 Word 的復原（改的是 Excel）。匯出 .docx／.pptx 時還不會換成表格或圖片（寫的是參照的文字）。
- **插入圖片的對話框**（`drawerImages.ts`、`ImagePicker.tsx`、`imagePicker.css`；使用者：「Dock 可以嵌入Drawer的圖片」「把Image改成Google Drive的插入圖片的樣式」，參考 Google 文件／雲端硬碟的插入圖片選擇器）：Word 與 Slides 的 Media 選單上方是 Image（Upload from computer、Drawer、Item attachments、By URL，跟 Google 文件的 Insert → Image 一樣），斜線選單「Image」也打開它（筆記、日記、頁面）。對話框：上方標題與圓角搜尋列（搜尋 Drawer 所有圖片的名稱與位置），分頁 Recent（所有圖片，新加的在前面，同樣內容只列一次）、My Files（麵包屑＋資料夾格子＋這一層的圖片）、Attachments（條目的圖片附件，垃圾桶的不算）、Upload（Browse 或直接 Ctrl＋V 貼上，存到 `media/`、不放進 Drawer）、By URL（貼網址，載得到才能插入，預覽在下面，文件裡寫網址本身）；縮圖點一下選取（可以選好幾張，角落標順序），連按兩下直接插入，下方「N selected」、Clear、Cancel、Insert；Enter 插入、Esc 關掉。Drawer 的圖片寫同一個 `media/檔名`（不複製），之後在 Drawer 改名、搬動、刪掉紀錄都不影響文件。
- **重複內容偵測**（`files.ts`、`Duplicates.tsx`）：`media/` 的檔名本來就是內容雜湊，所以檔名、副檔名、資料夾不同，內容一樣也認得出來（瀏覽器預覽的 data URL 用資料本身算）。檔案庫的檔案與條目附件一起比對。加入檔案（Add files、拖進來、附加到條目、拖檔案建條目）前先檢查：有重複就跳出對話框，列出每個檔案已經在哪裡（資料夾路徑、Unfiled（在垃圾桶裡會標出來），或 Attached to「條目」），可以 Show 過去看、Skip duplicates（預設，只加新的）、Add anyway 或取消；同一批裡選了兩次的也算。Find duplicates 檢查整個 Drawer，依內容分組（最早加入的標 Oldest），每一份可以 Show 或移到垃圾桶，或一次把檔案庫裡多出來的副本移到垃圾桶（每組留最早的，附件不動；垃圾桶裡的檔案不算重複）。
- **引用格式**（`cite.ts`）：APA 第 7 版、MLA 第 9 版的參考文獻與文中引用（APA：名字縮寫、`&`、超過 20 位作者、沒有日期 n.d.、沒有作者時標題在前、網頁的月日、DOI 網址；中日韓作者不縮寫）。Cite 分頁預覽並複製（同時放 HTML 斜體與純文字）；選好幾個時右欄是整份參考文獻（依作者排序），複製成 Markdown 清單，貼進編輯器就是一筆一個區塊、保留斜體。
- **匯出**：Export 把畫面上的條目（或選取的）存成 BibTeX `.bib`（下載資料夾），或複製參考文獻。

### 已知限制

- 只有 APA 與 MLA，沒有 CSL 樣式檔；文中引用不處理同作者同年份（2020a、2020b）。
- 網址新增不會讀網頁的標題與作者（瀏覽器的跨網域限制），只填網址與網站名稱。
- PDF 沒有標註、螢光筆或全文搜尋，也不會從 PDF 讀出書目資料。
- 沒有復原；刪除先進垃圾桶。移除附件不會刪掉 `media/` 裡的檔案。
- 沒有瀏覽器外掛（Zotero Connector）、雲端同步或群組文獻庫；同步靠把儲存位置設在同步資料夾。

## 版本歷史（`src/history/`，參考 Google Docs 的 Version history）

- **自動記錄**：日記、頁面、Desk 檔案每次存檔後記錄版本（`useDocs` 的 `onSaved`，`VersionLog.record`）。同一段連續編輯（離上個版本不到 10 分鐘、整段不超過 60 分鐘）只更新最後一個版本，所以一個版本是「一段編輯結束時的樣子」。第一次記錄時把存檔前的內容補成基準版本（「Before version history started」）。空白內容（刪除）不記。
- **儲存**：資料夾的 `history/<journals|pages|desk>/<名稱>/`：`index.json`（版本清單：時間、名稱、還原自哪個版本）與每個版本一個 `<id>.txt`（Rust `history_read`、`history_write`，名稱編碼和頁面檔名相同）；瀏覽器預覽存在 localStorage。沒命名的版本最多留 150 個（從最舊的刪），命名的一律留著。換儲存位置時跟著複製。
- **打開**：頂端列的時鐘圖示或 Alt＋H（存成檔案的日記、頁面、Desk 檔案才有）；Esc 或左上的箭頭回到文件。
- **畫面**：右邊是依日期分組的版本清單（Today、Yesterday、November 17），最上面是 Current version；All versions／Named versions 篩選；↑↓ 換版本；每個版本的 ⋯：Name this version／Rename、Remove name、Make a copy。左邊是唯讀預覽，上方「Restore this version」。
- **所見即所得的預覽**（使用者：「版本歴史的預覽效果 我要 WYSIWYG 的效果」）：用真正的畫面畫出那個版本，外面包 `inert` 變成唯讀，隱藏編輯用的東西（區塊把手、工具列、縮放、Excel 的公式列與 Format 面板、選取框）。頁面與日記是平常的頁面（標題＋編輯器，多欄、縮排、任務、表格、圖片都照原樣）；Word 是 A4 紙（照版面設定分頁，窄時縮小）；簡報是一張張投影片（含文字方塊、圖片、形狀）；Excel 是試算表畫布（好幾張工作表時上面切換）；Draw 是畫布；白板是白板。
- **Show changes**（記在 localStorage）：和前一個版本比較，直接標在畫面上。刪掉的區塊插回原位（`merge.ts` 把它們插進原始碼，畫好後依 `.row[data-start]` 標記）劃線標紅、新增的標綠、改過的在字詞層級標出增刪（中日文一個字一個詞，`diff.ts`）；簡報標出新增、改過（含字詞）、刪掉的投影片；Excel 標出改過的格子與新的表格；Draw 標出新增或改過的圖形；白板標出新增、改過的卡片，刪掉的卡片放回原位、虛線框。
- **Desk 檔案只看正在處理的那一部分**（使用者：「只顯示該文件的歷史記錄就可以」）：在 Dock 打開就是開著的那份文件，在 Whiteboard 打開就是白板；清單只列那一部分有改的版本（版本仍是整個檔案存一份，打開時讀出所有版本來篩），面板標題下寫著「Report · Word」。還原只放回那一部分，檔案的其他部分維持現在的樣子。
- **還原**產生一個新版本（「Restored from …」），原本的版本都留著；**Make a copy** 把那個版本做成新頁面（日記也是，「名稱 (copy)」）；Dock 文件是在同一個檔案裡多一份「標題 (copy)」，白板是只有白板的新 Desk 檔案。

### 已知限制

- 預覽是唯讀的，畫布（Excel、Draw、白板）不能捲動或縮放，只看得到一開始的畫面範圍；Draw 不標出刪掉的圖形與連線的變化；白板卡片指向的頁面與日記顯示的是它們現在的內容。
- 刪掉的區塊插回原始碼時，如果原本在別的欄或縮排裡，會出現在接著它的區塊所在的地方。
- Desk 檔案打開版本歷史時要讀出所有版本（最多 150 多個）才能篩出那份文件的版本；已經刪掉的 Dock 文件打不開，也就看不到它的歷史。
- 版本只記在這台電腦的資料夾；Drawer 文獻庫沒有版本歷史。
- 改名的 Desk 檔案（目前沒有改名功能）或刪掉再建立的同名文件會接著原本的版本歷史。

## 介面（`src/shell/`）

- **左側邊欄**：Today、Calendar、Desk、Drawer；下方是「收藏」與「最近」（最近開過的 8 個日記或頁面，已收藏的不重複列出）。可收合（Ctrl＋），狀態記在 localStorage；視窗窄於 760px 時變成蓋在內容上的抽屜，切換畫面後自動收起。
- **頂端列**：上一頁／下一頁（App 內的瀏覽紀錄，最多 50 筆）、目前畫面的圖示與標題、收藏星號（單日日記、頁面、Desk 的檔案）；右邊只有圖示：儲存狀態圓點（綠色已儲存、灰色閃爍儲存中，文字在滑過提示）、字數（文件、日記、頁面）、日曆、版本歷史、刪除，說明都在滑過提示裡。
- **收藏**：單日日記或頁面按星號或 Alt＋S 加入／取消，存在 localStorage（`banyan.favorites`）。
- **設定**（`Settings.tsx`，側邊欄底部的 Settings、Alt＋,）：
  - Appearance：主題跟隨系統／淺色／深色，三張縮圖卡片（`banyan.theme`）。
  - About：目前版本；「Check for updates」手動檢查新版本（Tauri updater，GitHub Releases 的 `latest.json`），有新版顯示版本與說明，「Install and restart」下載（進度條）、安裝後重新啟動；還在儲存時先等。不會自動檢查。
  - Storage：所有資料（journals/、pages/、media/、desk/、drawer/、databases/）放在同一個資料夾，預設是 App 資料夾。可以換成別的資料夾（例如同步資料夾）：「Copy notes and switch」把目前的資料複製過去（不覆蓋新位置已有的檔案，原檔留著），「Switch only」直接改用那個資料夾的資料；也能回到預設位置、在檔案總管顯示。位置記在 App 設定資料夾的 `settings.json`（Rust `storage_info`、`storage_set`），換完重新載入 App。瀏覽器預覽沒有這一項。
