## Desk（Markdown 工作區）

- **樣式組**：YAML 的 `Style:` 下定義多個樣式組，每組可覆寫內建標記（粗體、斜體、底線、刪除線、高亮、行內程式碼、連結、上下標、正文 `normal`）、定義自訂文字樣式，並在 `paragraph` 設定段落、標題（`heading`、`heading1`～`heading6`）、引言與清單。只寫要改的屬性，其他沿用外層，像 CSS 一樣繼承。
- `::push(樣式組)` 開始套用、`::pop()` 回到上一層；可巢狀、可跨 `::page`，前後不必空行。`::style(名稱){文字}` 套用目前樣式組的自訂文字樣式，只在目前的樣式組裡找。名稱忽略空白與大小寫（`style A` = `styleA`）。
- **文字樣式快捷鍵**：自訂文字樣式可加 `shortcut Ctrl+Alt+1`（一行寫法），或在逐行寫法用 `shortcut:`（也接受 `hotkey:`、`keys:`）。在 Markdown 原始碼中按下快捷鍵時，套用游標所在樣式組的那個樣式：有選取時包成 `::style(名稱){選取文字}`，沒有選取時插入 `::style(名稱){}` 並把游標放在大括號內。快捷鍵需包含 Ctrl、Alt 或 Meta；Banyan 與編輯器已用的組合（Ctrl+B、Ctrl+I、Ctrl+Z、Ctrl+1～9、Ctrl+W、Alt+Shift+F 等）會被忽略。`based-on` 沿用基礎樣式組的快捷鍵。游標所在樣式組沒有、但別的樣式組有這個快捷鍵時顯示提示。樣式彈窗的自訂文字樣式有「快捷鍵」欄位：在欄位中按下組合鍵即記錄，Backspace 或 × 清除；同一樣式組內重複或保留的組合會顯示錯誤。
- **一行寫法**：每個樣式可寫成一行，例如 `normal: 11pt "Noto Serif TC" line-height 1.7 after 6pt`、`bold: #c0392b`、`h1: 22pt bold center`、`重點: 14pt #2f7a55 bold`。純數字或長度是字級，`#色碼` 是文字色（不必加引號），`bold`／`italic`／`underline`／`center` 等是關鍵字，`line-height 1.7`、`indent 2em`、`before 6pt`、`after 6pt` 等以「名稱 值」寫，其他字詞是字型。項目直接寫在樣式組底下，`h1`～`h6`、`quote`、`list`、`table` 是段落，`normal` 是正文（其中的對齊、縮排、段距套用到段落），其他名稱是自訂文字樣式。舊的 `text:`／`paragraph:` 分層與逐行屬性寫法仍可讀取，屬性名稱可用簡寫、連字號或駝峰寫法，不安全的值會被略過。
- **透明度**：文字色與底色可半透明或完全透明，YAML 寫 `#rrggbbaa`、`#rgba` 或 `transparent`。樣式彈窗的文字色、底色旁有「透明度 %」（0 不透明、100 完全透明），換顏色時保留透明度；常用的文字色也會保留。預覽與 PDF 照實顯示；Word 不支援透明，匯出時依透明度與紙色混成實色，完全透明則不寫顏色。
- **繼承**：樣式組寫 `based-on: 另一組` 會先沿用那一組的全部設定再覆寫；可多層沿用，迴圈會自動停止。樣式彈窗的「基於」選單可設定；欄位只顯示這一組自己寫的值，從基礎樣式組得到的值以灰字提示，未設定的下拉顯示「—」；綠點只標在這一組自己有設定的項目；常用的快速控制也一樣。介面不使用「沿用」字樣。
- 面板與常用控制寫入的新項目一律用一行寫法、直接放在樣式組底下；原本是一行的保持一行，原本是逐行屬性的保持原樣。
- 編輯器補全 `Style` 的鍵、`::push(` 的樣式組名稱與 `::style(` 在游標所在樣式組的樣式名稱；找不到的樣式組、目前樣式組沒有的樣式、多出來的 `::pop()` 會以警告標出，預覽中找不到的 `::style` 加上波浪底線（列印時不顯示）。
- **文件預設樣式**：YAML 頂層的 `Default Style: 樣式組名稱` 指定 `Style:` 中的一組為文件的預設樣式，不用 `::push` 就套用到全文，其他樣式組疊在它上面。任何樣式組都可以設為預設：樣式彈窗中非預設的樣式組有「設為預設」，預設的那一組標「全文」並顯示「文件預設樣式・套用到整份文件」，沒有刪除按鈕（先把其他樣式組設為預設才能刪除）；改名時 `Default Style:` 一起更新。樣式名稱以英文為主：新文件與新簡報會寫好 `Default Style: Default` 與 `Default` 樣式組（正文 Microsoft JhengHei 11pt、行高 1.6、段後 6pt、標題 1～3 為 22／17／14pt；簡報為 20pt 正文與 40／30pt 標題）；沒有樣式組的文件加入第一個樣式組時，它自動成為預設，樣式彈窗也提供「建立預設樣式」；面板新增的樣式組與自訂文字樣式依序命名為 `Style 1`、`Custom 1`。沒有 `Default Style:` 時，名為 `Default`／舊的 `預設` 的樣式組視為預設（`based-on: 預設`、`::push(預設)` 仍有效），舊的頂層 `Default:` 區塊轉換成 `Default` 樣式組；之前的頂層 `Default:` 區塊仍可讀取，第一次修改時改成 `Default Style:` 寫法。常用的樣式下拉在 `::push` 之外顯示「預設樣式名稱（全文）」，可直接調整。
- **對齊與段落間距**：對齊用 `::left{}`、`::center{}`、`::right{}`、`::justify{}`。常用的對齊按鈕只作用在選取的文字：選取段落中間的文字時，只把那段文字包成對齊區塊，前後文字各自成段；選取剛好是某個對齊區塊的全部內容時原地切換。沒有選取時作用在游標所在段落，游標留在區塊內，再按其他對齊會原地切換；前後不會多出空行。段落格式旁的設定按鈕開啟「更多樣式」，預選游標所在樣式組（或「預設」）的段落／標題 n 項目，可調左右縮排、首行縮排、段前、段後與行高。
- **常用的樣式控制**：常用功能區的「樣式」群組跟著游標，顯示所在的樣式組與正在調整的項目（正文、粗體、標題 2、自訂樣式…），可直接改字型、字級（含 −／＋）與文字色。下拉選單可把段落放進樣式組、改成另一個樣式組（改寫外層的 `::push`），或選「無樣式組」移除外層的 `::push` 與對應的 `::pop()`。
- **樣式彈窗**：常用的設定按鈕或下拉的「新增或管理樣式組…」開啟完整面板，並預先選好游標所在的樣式組與項目；Esc 或點外面關閉。面板以圓角標籤切換樣式組，可新增、改名（同步更新正文的 `::push`）、刪除樣式組。左欄列出自訂文字樣式與內建文字（正文、粗體、斜體…），中欄列出段落、標題、引言、清單；有設定的項目以綠點標示。右側可調整字型、字級、文字色、底色、粗細、斜體、裝飾、字距、行高，段落另有對齊、首行縮排、段前與段後；欄位留空表示這一組不設定，「清除設定」清除該項目的設定。範例文字以文件的紙色顯示。
- 自訂文字樣式可新增、改名（同步更新該樣式組範圍內的 `::style`）與刪除。「套用到段落」以 `::push`／`::pop` 包住游標所在或選取的段落；「套用到文字」以 `::style(名稱){…}` 包住選取文字，選取範圍不在該樣式組內時會提示先套用到段落。面板的修改直接寫回 YAML（保留原有鍵名、順序與註解），可用 Ctrl＋Z 復原。
- PDF 與 Word 匯出套用樣式組；Word 從預覽讀取字型、字級、顏色、粗斜體、底線、刪除線和底色。

- 檔名列提供 Markdown 與預覽切換。預覽工具列可縮小、放大或符合寬度，並支援 Ctrl＋滾輪。預覽區可上下捲動，放大時也可左右捲動。

- 上方功能區分為檔案、常用、插入、版面配置及檢視。插入可加入圖片、文獻和標註。版面配置可調整紙張、方向、邊界、欄數，開啟「頁面設定…」彈窗，並插入排版指令。檢視可切換編輯、預覽或簡報放映。

- 文件工作區可收起檔案清單、切換編輯與預覽，並在預覽工具列選擇符合寬度或固定縮放。原始碼工具依素材、排版、編輯分組。

- 常用功能區的對齊按鈕會使用獨立的 `::left{內容}`、`::center{內容}`、`::right{內容}`、`::justify{內容}`，可原地切換既有對齊。

- 文件與簡報的原始碼工具列可插入本機圖片。PNG、JPEG、GIF、WebP、BMP 和 AVIF 可嵌入 Markdown，單檔上限 10 MB。圖片會隨 Markdown 匯出，預覽、放映和 PDF 可顯示。
- 「插入 Drawer 圖片」可依標題或檔名搜尋檔案庫，將圖片內容嵌入目前文件或簡報。

- YAML 的 `mode: writer` 或 `mode: slides` 決定開啟文件排版或簡報放映。新增檔案時會寫入對應模式，既有檔案缺少模式時沿用原類型。

- 「Markdown／排版」提供行號、Markdown／YAML 與常用程式碼區塊的語法突顯、指令與樣式名稱補全（Ctrl＋Space）、搜尋與取代、縮排和復原。排版可整理 YAML、Markdown 標題與 JSON 程式碼區塊。

- 從左側導覽開啟 Desk。按「新增」可選擇建立文件或簡報。「匯入 .md」也可選擇類型，讀取 UTF-8 的 Markdown 檔案。檔案可依名稱搜尋、重新命名、刪除及匯出 `.md`。
- 舊版 Desk 試算表以文件開啟，保留原有 Markdown 表格及公式文字。
- 文件可切換 Markdown 原始碼與預覽。
- 文件在 Markdown 編輯時同步顯示排版，紙張可選 A3、A4、A5、B5（JIS）、Letter、Legal，直向或橫向。匯出選單提供 Word（`.docx`）與 PDF，PDF 可在列印視窗選「另存為 PDF」。兩種格式都採用所選紙張。
- **自動分頁**：預覽會量出每個區塊的位置，內容超過頁面下緣時，從第一個超出的區塊開始放到下一頁（以段落、標題、清單、表格、引言、分欄等整個區塊為單位，不從段落中間切開）；`::page` 仍強制換頁。比一頁還高的單一區塊（很長的表格或清單）不會切開，那一頁會拉長顯示。圖片或字型稍後載入使內容變高時會再次分頁。PDF 與 Word 依預覽的頁面輸出，頁碼也跟著自動分頁。Word 輸出保留可編輯文字與表格，圖片以替代文字呈現。
- **清單縮排**：Markdown 編輯器在清單項目上按 Tab 成為上一項的子項目（縮到上一項的文字開頭：`- ` 2 格、`1. ` 3 格），Shift＋Tab 回到上一層；項目底下的內容與子項目一起移動，新的有序子清單從 1 開始、受影響的同層項目重新編號；可一次選取多項。清單第一項按 Tab 不動作；YAML 與程式碼區塊內維持一般縮排。Enter 延續清單。
- **頁面設定彈窗**（版面配置的「頁面設定…」）：分「紙張」（尺寸、直向／橫向、紙張顏色）、「邊界」（標準、窄、中等、寬、Word 預設五種預設，或上右下左自訂 mm，不符合預設時標「自訂」）、「分欄」（1～4 欄、欄距、欄間分隔線）、「頁首與頁尾」（左中右各一欄，多項用「、」分隔，`pageNumber` 是頁碼；顯示頁碼、首頁不顯示頁首與頁尾、一鍵在頁尾置中加入頁碼）。右側縮圖即時畫出紙張比例、邊界、欄與頁首頁尾位置，下方顯示紙張摘要；「版面還原預設」還原紙張、方向、邊界、欄與頁碼設定（保留頁首頁尾文字與紙色）。每項修改立即寫入 YAML，背後的預覽同步更新；Esc、點外面或「完成」關閉。功能區另有紙張、方向、邊界、欄的快速下拉。頁首和頁尾各保留至少 10 mm 的正文留白。
- **分欄**：整份文件的正文由左到右填滿各欄後換頁（自動分頁依欄計算，段落可跨欄）；PDF 用 CSS 多欄，Word 寫入 `w:cols`（欄距、分隔線）。表格與框線在 Word 中以欄寬輸出。**橫向**：預覽、PDF（`@page size`）與 Word（`w:orient`）都轉成橫向。**首頁不同**：預覽第一頁不顯示頁首頁尾，PDF 用 `@page :first`，Word 用 `w:titlePg`。
- YAML 留白可寫成 `padding: 20` 或 `padding: (10, 20, 30, 40)`，依上、右、下、左排列。Markdown 原始碼內按 Tab 插入兩個空格，先按 Esc 再按 Tab 可移出編輯區。
- 新建文件時，Desk 會在 Markdown 開頭自動加入預設的 YAML front matter `page` 欄位，可在「Markdown／排版」直接編輯。舊版註解格式在編輯時轉成 YAML。
- 文件預設在頁尾顯示頁碼，可在「頁面設定」關閉，或在 YAML 設定 `page.pageNumbers: false`。即時預覽依自動分頁後的頁面編號，PDF 和 Word 依輸出分頁編號。
- 頁首與頁尾可分別設定 `left`、`center`、`right`。各區可放文字清單，`pageNumber` 會換成目前頁碼。舊版單行文字會放到中區。
- 頁首和頁尾在上、下留白內垂直置中，左右邊緣對齊正文留白，調整 `padding` 時會一起移動。
- 文字格式接受 CSS 風格屬性及連字號寫法，例如 `font-weight`、`line-height`、`letter-spacing`、`text-decoration` 和 `highlightColor`。對齊、邊框、內外距與分頁由各自的排版功能處理。
- 文件與簡報的「版面配置」可插入等寬或自訂比例的多欄、置中、靠右、框線區塊、分頁線、可跳轉的三級目錄與參考文獻。預覽與放映會套用排版，窄欄會改為上下排列。
- 排版工具會插入 `::Col(){左欄},{右欄}`、`::center`、`::page`、`::refs` 等簡寫。`Col` 的每組外層大括號對應一欄，預設等寬。「自訂多欄」可指定比例，例如 `::Col(2:1:1){主欄},{次欄},{側欄}`，比例套用到預覽、PDF 與 Word。
- 從 Desk 搜尋 Drawer 條目，插入 APA 文內引用或來源卡。從 Annotator 搜尋重點與書籤，插入可點回原文的標註。Drawer 重新命名引用鍵時會同步更新 Desk 的引用。
- 簡報以 Markdown 頂層的 `---` 分隔線拆成投影片，支援全螢幕放映，可用按鈕或方向鍵翻頁。
- 編輯內容自動儲存至目前的 Banyan 資料庫，隨資料庫備份、搬移與還原。資料庫升級至 v22 時建立 Desk 資料表。停止輸入約 0.6 秒後儲存；切換檔案、離開 Desk、切到背景或關閉視窗時會先送出未儲存的修改（關閉視窗最多等 2 秒）。
- 打字時預覽可稍微落後於原始碼，以保持輸入順暢；同一段原文的解析結果由編輯器、格式工具列與預覽共用。
- 文件編輯時左右分割：左側 Markdown 原始碼（長行自動換行，配色跟隨淺色／深色主題），右側依紙張尺寸顯示的頁面預覽，每個 `::page` 一頁，含頁首、頁尾與頁碼。紙張與文字顏色依 YAML 設定，在深色主題下也維持原樣。
- 原始碼中 Ctrl＋B／Ctrl＋I 切換粗體／斜體；排版、插入圖片等結果以畫面底部的提示訊息顯示。檔案清單顯示類型與最後編輯時間。

## Drawer（文獻庫＋檔案庫）

介面分三欄：左欄資料夾與標籤、中欄條目清單、右欄條目詳情。Drawer 有兩個資料庫，在左欄最上方切換：

| 資料庫 | 參考 | 說明 |
|---|---|---|
| 📚 文獻庫 | Zotero | 書目資料：文獻、影音、現場表演、藝術與圖像、其他（30 種類型）。以下各節未特別註明的，都是文獻庫的功能 |
| 📁 檔案庫 | DEVONthink、Eagle | 個人檔案：拖進來的每個檔案都成為一個條目，類型依副檔名決定（見「檔案庫」） |

- 兩個資料庫有**各自的資料夾樹**；標籤共用同一套名稱，但左欄只列出這個資料庫有用到的標籤，數量也只算這個資料庫的條目。
- 條目不能在兩個資料庫之間移動：不能放進另一個資料庫的資料夾，也不能改成另一個資料庫的類型（單筆與大量修改都會拒絕）。
- 關聯、筆記卡片、白板引用兩邊的條目都可以使用；從關聯或白板開啟另一個資料庫的條目時，會自動切換過去。
- 上次使用的資料庫會被記住。

### 檔案庫
| 功能 | 說明 |
|---|---|
| 加入檔案 | 中欄的「＋ 加入檔案」選擇檔案，或直接把檔案拖進視窗（不需要先選條目）。每個檔案建立一個條目，標題是檔名（不含副檔名），放進目前檢視的資料夾；在標籤的檢視中加入則同時加上那個標籤。某個檔案無法加入時（例如被其他程式鎖住），其他檔案照常加入，訊息列出無法加入的檔案與原因 |
| 類型 | 依副檔名自動判斷：📄 文件（PDF、Word、ODT、RTF…）、📚 電子書（EPUB、MOBI、AZW、AZW3、FB2、CBZ…）、🖼️ 圖片、🎞️ 影片、🔊 音訊、📝 文字（TXT、Markdown…）、📊 試算表（Excel、CSV…）、📽️ 簡報、⌨️ 程式碼、🗜️ 壓縮檔、📦 其他檔案。之後可在右欄改成其他檔案類型 |
| 略過 | 資料夾不會加入；拖進畫廊時只加入圖片，其他檔案略過；完成後提示加入與略過的數量 |
| 大檔案 | 和附件相同：超過 5 GB 只記錄位置、不複製（見「附件」） |
| 檢視（像 Windows 檔案總管） | 中欄標題列切換「大圖示」或「詳細資料」，會記住。**大圖示**：在資料夾中先列出子資料夾（黃色資料夾圖示，下方顯示有幾個子資料夾；畫廊以圖片圖示顯示），再列出檔案（圖片顯示縮圖，其他顯示類型圖示並標上副檔名），名稱含副檔名、最多兩行（選取時展開）；滑桿調整圖示大小（72–200px）。**詳細資料**：表格，資料夾中的子資料夾列在最前面（類型欄顯示「資料夾」），標題欄改稱「名稱」並含副檔名 |
| 所有檔案 | 左欄最上方的「所有檔案」列出檔案庫中的**每一個檔案**（包括資料夾裡的），**不顯示資料夾**（資料夾在左欄）；「未分類」只列出不在任何資料夾中的檔案。進入資料夾後才會在中欄看到它的子資料夾 |
| 雙擊開啟 | 雙擊資料夾進入；雙擊檔案（或選取後按 Enter）開啟：閱讀器能顯示的在閱讀器中開啟，其他（Word、Excel、壓縮檔…）用系統預設程式開啟 |
| 路徑與上一層 | 標題列顯示路徑「所有檔案 › 工作文件 › 2026」，點任一段前往；↑ 按鈕、Backspace 或 Alt＋↑ 回到上一層 |
| 拖曳到資料夾 | 和檔案總管一樣，在資料夾中把檔案拖到資料夾圖示（或左欄的資料夾）是**移動**；按住 Ctrl 放開則同時留在原處（一個檔案可以在多個資料夾裡）。從「所有檔案」「未分類」或標籤拖曳時是放進該資料夾。拖曳中資料夾圖示會高亮，游標旁顯示「移到「X」」「也放進「X」」或「放進「X」」 |
| 選取 | 和清單、畫廊相同：點選、Ctrl／Shift＋點、框選、方向鍵、Ctrl＋A；點一下資料夾只會標示它（Enter 進入） |
| 清單欄位 | 詳細資料預設顯示類型、大小、加入日期；可另外勾選副檔名、檔名、日期、修改日期、附件數。欄位設定和文獻庫分開記住 |
| 預覽（右欄） | 條目的第一個檔案顯示在「預覽」區塊：圖片、PDF（可翻頁）、影片與音訊（可播放）、文字與程式碼（含 `.md`，以純文字顯示）；旁邊有「閱讀」（整個視窗的閱讀器，見「閱讀器」）、「開啟」（預設程式）與「位置」（檔案總管）。雙擊預覽打開閱讀器（影音除外）。沒有預覽的類型或太大的檔案（圖片 50 MB、PDF 100 MB、影片 300 MB、音訊 200 MB、文字 2 MB 以上）顯示提示，但仍可用閱讀器開啟 |
| 欄位 | 名稱、日期、來源網址、說明；沒有作者與身分。下方的「檔案」區塊可以再加入其他檔案 |
| 畫廊 | 檔案庫的資料夾也可以是畫廊，只放圖片類型（在左欄建立；畫廊一律以圖片顯示） |
| 大量編輯 | 類型只能改成檔案類型；「設定欄位」只有日期、網址、說明；沒有「加入人員」 |
| 文獻的附件 | 文獻庫條目每加入一個附件，檔案庫就**自動**多一個檔案條目：類型依副檔名、標題是檔名、未分類，並和那筆文獻互相「關聯」。兩邊**共用同一份檔案**，不會多佔空間。檔案條目可以另外放進檔案庫的資料夾、加標籤。右欄附件旁標示「檔案庫」（文獻那邊）或「文獻」（檔案庫那邊），預覽下方顯示「與文獻共用」 |
| 共用檔案的刪除 | 在檔案庫刪除檔案條目，或移除它的檔案：只移除檔案庫這邊，文獻的附件不受影響；檔案條目就是它的檔案，移除最後一個檔案時條目也一併移除（確認視窗會先說明）。刪除文獻的附件：檔案庫對應的檔案一起移除，因此沒有其他檔案的檔案條目也會刪除。刪除整筆文獻條目：附件在檔案庫的檔案條目**保留**，檔案移到檔案條目自己的資料夾 |

### 閱讀器
在 Banyan 裡直接閱讀檔案，不必開其他程式。文獻庫的附件和檔案庫的檔案都可以使用，蓋住整個視窗。

| 開啟方式 | 說明 |
|---|---|
| 右欄附件／檔案 | 每列的「閱讀」按鈕，或雙擊那一列（不能閱讀的檔案仍用預設程式開啟） |
| 預覽 | 檔案庫右欄「預覽」區塊的「閱讀」，或雙擊預覽 |
| 中欄 | 雙擊展開的附件列；檔案庫中雙擊檔案或按 Enter |
| 分頁 | PDF 與電子書從以上任何地方開啟時，改開在分頁中（見「分頁」）；閱讀器上方也有「在分頁開啟」 |
| 畫廊 | 雙擊圖片；在閱讀器中可以用 ← → 瀏覽整個畫廊的圖片 |

| 種類 | 功能 |
|---|---|
| 📄 PDF | 所有頁面連續捲動，捲到附近才繪製；**串流讀取**，大檔案不必整個讀進記憶體，前幾頁很快出現（無法串流時改為整個讀入）；**可以選取、複製文字**；**搜尋**（Ctrl＋F 或「搜尋」：全部頁面的符合數，Enter／Shift＋Enter 前後跳，符合處以黃色標示、目前的以橘色）；**目錄**側欄（PDF 本身的書籤目錄，含頁碼，標示目前所在章節，點一下前往）；**畫重點、筆記、書籤**（見「Annotator」）；縮放：符合寬度、整頁或 50%–400%（會記住，縮放後停留在同一頁）；頁碼輸入框跳頁、PageUp／PageDown、Home／End；記住上次讀到的頁 |
| 📖 書籍 | 支援 **EPUB、MOBI／AZW／PRC、AZW3、FB2／FBZ、TXT**。一次顯示一章，用和介面相同的配色與易讀的寬度；「目錄」側欄；上一章／下一章（← →），在章末按 PageDown 或空白鍵接到下一章；字體大小 A−／A＋（7 級，會記住）；**搜尋全書**（Ctrl＋F：所有章節的符合數，跳到該章並標示）；**直排／橫排**：直排書（EPUB 標示由右至左或樣式表使用直書）自動以直排、由右至左顯示，滑鼠滾輪往左捲，← 是下一章；任何書都可以按「直排」「橫排」切換，每本書分別記住；書中的連結可以跳到其他章節，外部連結用瀏覽器開啟；記住上次讀到的章節與位置。書中的程式碼（script）不會執行 |
| 各種書的細節 | **EPUB**：EPUB 3 的 nav 或 EPUB 2 的 NCX 目錄。**MOBI／AZW／PRC**：解開 PalmDOC 壓縮，依分頁符號分章，書內 filepos 連結可跳轉，顯示書中圖片，書名取自書的資料。**AZW3（KF8）**：以簡化方式顯示（內容與圖片依序呈現、套用書的樣式，書內連結無法跳轉），開啟時會提示。**FB2**：每個章節一章（含子章節目錄）、內嵌圖片、註釋另成一章；FBZ（壓縮的 FB2）也可以。**TXT**：自動判斷編碼（UTF-8、UTF-16、Big5、GB18030；不是 UTF-8 時顯示判斷結果），依「第X章」「卷X」「序章」「Chapter 1」等標題自動分章並建立目錄，很長又沒有標題的內容每約 3 萬字切一段 |
| 🗯️ 漫畫（CBZ） | 一次一頁，依檔名自然排序（p2 在 p10 前）；整頁／符合寬度；**雙頁**並排；**右翻**（日式漫畫，← 是下一頁，雙頁由右至左）；← →、PageUp／PageDown、空白鍵或點畫面左右半邊翻頁；記住頁數與設定 |
| 🖼️ 圖片 | 預設符合視窗；放大縮小（Ctrl＋滾輪或按鈕，10%–800%）、原始大小、雙擊切換；放大後拖曳移動 |
| 🎞️ 影片／🔊 音訊 | 直接串流播放，大檔案不必整個讀進記憶體；記住上次播放的位置 |
| 📝 文字 | 置中的閱讀欄位，以純文字顯示（`.md` 也一樣） |
| 其他 | 顯示「用預設程式開啟」 |

- 上方列：‹ › 切換同一個條目的其他檔案（顯示「2 / 4」）、檔名、這種檔案的工具、「預設程式開啟」、×（或 Esc）關閉。

- 書籍格式的程式在 `src/drawer/books/`（每種格式一個檔案，共用 `Book` 介面與 ZIP 讀取），不使用外部套件。

### 資料夾（左欄）
左欄分為「資料夾」與「標籤」兩個區塊；點區塊標題（▾ / ▸）可摺疊，標題旁顯示數量。摺疊狀態會記住。

| 功能 | 說明 |
|---|---|
| 全部文獻／所有檔案 | 顯示這個資料庫的所有條目（所有檔案不顯示資料夾，見「檔案庫」） |
| 未分類 | 顯示不屬於任何資料夾的條目 |
| 新增資料夾 | 「資料夾」標題右側的 ＋，選「資料夾」或「畫廊（只放圖片）」；資料夾列上的 ＋ 建立子資料夾（可多層巢狀） |
| 顯示方式 | 每個資料夾可選「清單」或「畫廊」，在中欄標題列右側切換；畫廊資料夾在左欄以圖片圖示顯示（見「畫廊」） |
| 重新命名 | 雙擊資料夾名稱 |
| 刪除資料夾 | 子資料夾一併刪除；裡面的條目**保留**在 Drawer |
| 完整路徑 | 滑鼠停在資料夾上顯示完整路徑，例如 `資料夾/資料夾01` |
| ⚙ 資料庫位置 | 在左欄底部，點一下開啟「設定」頁的「資料儲存位置」（見「資料庫位置」） |

### 標籤（左欄）
用法和資料夾相同，列在資料夾下方。

| 功能 | 說明 |
|---|---|
| 標籤清單 | 依名稱排序，右側顯示使用該標籤的條目數 |
| 依標籤檢視 | 點標籤，中欄只顯示有這個標籤的條目（可再搜尋）；清單標題為「標籤：名稱」 |

### 條目清單（中欄）
| 功能 | 說明 |
|---|---|
| 新增條目 | 「＋ 新條目」選單依分類列出條目類型；新條目會自動放進目前所在的資料夾 |
| 搜尋 | 比對標題、所有作者與其他身分的姓名、標籤、摘要、原文、筆記卡片的標題與內容、附件檔名，以及長度、媒介、尺寸、地點、編號等欄位。Ctrl＋F 移到搜尋框（閱讀器開著時是閱讀器的搜尋）；搜尋框中 Esc 清除搜尋（已經空白時回到清單），↓ 或 Enter 進入清單並選取第一個；標題中符合的字以黃底標示；沒有結果時顯示「清除搜尋」按鈕 |
| 排序 | 點欄位標題（標題、作者、日期、大小…）依它排序，標題旁顯示 ↑／↓；文字依中文排序並把數字當數字（第 2 章在第 10 章前），日期、大小、數量第一次按是新的／大的在前；再按一次反向，第三次恢復預設（最近修改的在前）。空白的值一律排在最後。排序和欄位設定一起記住（兩個資料庫分開）；大圖示與畫廊沒有欄位標題，改用標題列的排序選單 |
| 沒有條目時 | 顯示「＋ 新條目」（檔案庫是「＋ 加入檔案」）按鈕 |
| 清單標題 | 顯示目前檢視的位置；在子資料夾中顯示完整路徑，例如 `資料夾/資料夾01` |
| 清單欄位 | 類型圖示與標題一定顯示；其他欄位可選：作者（多位時顯示「第一位 等」；該類型的主要身分排在前面，例如書籍先列作者、再列譯者）、類型、日期、出處、出版社、系列、地點、新增日期、修改日期、附件數。預設顯示作者、日期、附件數 |
| 選擇欄位 | 標題列右側的 ⚙，或在欄位標題上按右鍵，勾選要顯示的欄位；「還原預設」恢復預設欄位與欄寬 |
| 調整欄寬 | 拖曳欄位標題左側的分隔線；標題欄佔用剩下的寬度（最少 160px），欄位太多時清單可左右捲動。欄位與欄寬會記住（存在這台電腦的瀏覽器儲存空間） |
| 摺疊顯示附件 | 有附件的條目前方有 ▸，點開後以縮排列出附件（檔名、大小；連結檔案顯示 🔗 與「連結」標籤）；雙擊附件列即開啟；新增或刪除附件後自動更新 |
| 全部展開 / 收合 | 點標題列的 ▸ / ▾ |
| 鍵盤操作 | ↑ / ↓ 切換選取（Shift＋↑ / ↓ 擴大選取範圍）；Ctrl＋A 全選；Esc 只保留一個；→ / ← 展開或收合選取條目的附件；+ / − 全部展開或收合；Delete 刪除選取的條目（會先確認） |

### 多選與框選
| 操作 | 結果 |
|---|---|
| 點一下 | 只選這個條目 |
| Ctrl＋點 | 加入或取消選取這個條目 |
| Shift＋點 | 選取從上一個點選的條目到這裡的範圍（Ctrl＋Shift＋點則加到原本的選取） |
| 框選 | 從條目的作者、日期、附件欄，或清單下方的空白處按住拖曳，畫出選取框；框到的條目被選取（按住 Ctrl 則加到原本的選取）；拖到清單上下邊緣會自動捲動 |

### 大量編輯（右欄）
選取兩個以上的條目時，右欄改為「大量編輯」，所有變更套用到每個選取的條目：

| 區塊 | 功能 |
|---|---|
| 上方 | 列出選取的條目（最多 6 個，其餘顯示「還有 N 個」）；「取消多選」、「刪除 N 個」 |
| 標籤 | 顯示選取的條目已有的標籤與比例（例如「1/4」、「全部」）；按 × 從全部移除；輸入名稱按 Enter 為全部加上 |
| 資料夾 | 顯示所在的資料夾與比例；按 × 全部移出；「全部加入資料夾…」 |
| 類型 | 顯示各類型的數量；「全部改為…」（會先確認，欄位內容保留） |
| 設定欄位 | 選擇欄位（日期、出版社、出處、網址、摘要等）並輸入值，「套用」後取代全部的內容；留空則清空（會先確認） |
| 加入人員 | 選擇身分並輸入姓名，加到每個條目的人員清單最後；已有同身分同姓名的條目會略過 |

### 畫廊
資料夾的一種顯示方式：整個中欄只顯示圖片，沒有欄位與文字。

| 功能 | 說明 |
|---|---|
| 只放圖片類條目 | 只能放繪畫、藝術品、照片、地圖；把其他類型拖進畫廊會被拒絕並提示（拖曳中游標旁顯示「畫廊只能放圖片類的條目」）；在條目的「資料夾」區塊中不會出現畫廊；畫廊裡的條目不能改成其他類型（類型選單中其他類型無法選擇，大量修改類型也會被拒絕） |
| 改成畫廊 | 資料夾裡全部都是圖片類條目時才能改成畫廊；否則提示有幾個不是圖片類的條目 |
| 顯示的圖片 | 每個條目的第一個圖片附件（PNG、JPG、GIF、WebP、BMP、AVIF、SVG）；沒有圖片附件的條目顯示類型圖示；滑鼠停留顯示標題；捲動到附近才讀取圖片 |
| 圖片大小 | 標題列的滑桿（80–360px），會記住 |
| 選取 | 點選、Ctrl／Shift＋點選、從空白處框選；方向鍵上下左右移動；選取後右欄顯示條目詳情，沒有選取時右欄隱藏，畫廊佔滿寬度 |
| 開啟 | 雙擊圖片，在閱讀器中開啟，可用 ← → 瀏覽這個畫廊的所有圖片 |
| 拖曳 | 拖曳圖片到其他資料夾或標籤，和清單相同 |
| 拖入圖片檔 | 沒有選取條目（或選取多個）時，把圖片檔拖進視窗：每個檔案建立一個「照片」條目（標題為檔名）並加入這個畫廊；非圖片檔會略過。只選取一個條目時，則和清單相同，把檔案加為該條目的附件 |
| 新增條目 | 「＋ 新條目」只列出圖片類的類型 |

| 操作 | 結果 |

### 引用鍵與 BibTeX
每筆條目（文獻庫與檔案庫）都有 BibTeX 式的**引用鍵**，在卡片中寫 `[@引用鍵]` 引用（見 Whiteboard「引用文獻」）。

| 功能 | 說明 |
|---|---|
| 自動產生 | 文獻：第一位作者（依類型的主要身分，例如電影是導演）的姓＋年份，例如 `kahneman2011`；英文名取逗號前或最後一個字、去掉重音（`García Márquez, Gabriel` → `garciamarquez`）；中日韓姓名保留原文的姓（`王小明` → `王2020`，複姓取兩字）。沒有作者用標題第一個字（英文略過 the、a 等），沒有年份就省略。檔案庫的檔案用檔名（空白換成 `-`）。重複時加 `a`、`b`、`c`… |
| 什麼時候固定 | 還沒被任何卡片引用的自動鍵會跟著標題、作者、年份更新；一旦有卡片寫了 `@鍵`、或手動改過、或從 .bib 匯入，就不再自動改變 |
| 手動修改 | 在「引用鍵」欄位修改，按 Enter 或離開欄位套用；只能用中英文、數字與 `- _ .`；和其他條目重複時拒絕。所有卡片中的 `@舊鍵`（含 `@舊鍵:h3`）一起改成新鍵 |
| 複製 | 欄位旁的按鈕複製 `[@鍵]` |
| 註解的鍵 | 重點是 `條目的鍵:h編號`、書籤是 `:b編號`（例如 `kahneman2011:h3`），依同一條目中建立的順序編號、刪除後不重用；文獻附件的註解用文獻的鍵 |
| 匯入 .bib | 文獻庫清單上方「BibTeX」→「匯入 .bib 檔…」：每筆成為一個文獻條目，放進目前的資料夾；保留原本的鍵（已被使用就加字尾並提示）。支援 `@string`、`#` 串接、`@comment`、常見 LaTeX 重音與跳脫；類型與欄位依 BibLaTeX 對照（見 `Design/Markdown Language.md`「書目格式」），作者、編者、譯者成為對應身分，`keywords` 成為標籤 |
| 匯出 .bib | 「BibTeX」→「匯出選取的 N 筆…」或「匯出整個文獻庫…」：選擇存檔位置，寫成 BibLaTeX（UTF-8，特殊字元加上跳脫）；「複製選取條目的 BibTeX」放到剪貼簿 |

### 原文
新聞條目可以把整篇文章直接貼進來保存。

| 功能 | 說明 |
|---|---|
| 貼上 | 在原文欄按 Ctrl＋V，或按區塊標題列的「貼上」從剪貼簿貼上（已有原文時會先確認是否取代） |
| 保留原樣 | 換行、空行與縮排都照貼上時保留，不做排版 |

### 筆記卡片（參考 Heptabase）
條目不再有自己的筆記欄位。筆記是**卡片**，卡片引用條目；同一張卡片可以引用多個條目，也可以放到白板上和其他卡片連結。

| 功能 | 說明 |
|---|---|
| 清單 | 只顯示每張筆記卡片的名稱（🗒 標題）；滑鼠停留顯示內容開頭；在白板上的卡片右側有 🧩，點一下到白板中開啟 |
| 展開編輯 | 點卡片名稱展開，可編輯標題與內容（離開欄位時自動儲存），並使用下方的白板與取消連結功能；按「收合」回到只顯示名稱。一次只展開一張 |
| 內容 | 展開後以 Markdown 顯示（和白板卡片相同，見 Whiteboard「卡片內容」）：點一下就在該位置編輯，離開或 Esc 結束並儲存 |
| 新增 | 詳情欄「筆記卡片」按「＋ 新增」：建立標題為「筆記：條目標題」的卡片，直接展開並聚焦內容 |
| 連結已有卡片 | 搜尋所有卡片（標題或內容），點一下讓它引用這個條目 |
| 放到白板 | 不在白板上的卡片有「🧩 放到白板…」選單，放在該白板現有卡片的右側 |
| 在白板中開啟 | 已在白板上的卡片顯示白板名稱，點一下切換到 Whiteboard 並選取、捲動到這張卡片 |
| 取消連結 | 只取消卡片和條目的關係，卡片本身保留 |
| 刪除條目時 | 只屬於這個條目、且不在任何白板上的筆記卡片一併刪除；放在白板上或也引用其他條目的卡片保留 |
| 舊筆記 | 升級到資料庫 v6 時，每個條目原本的筆記自動轉成一張「筆記：條目標題」的卡片並引用該條目 |

### 關聯（參考 Zotero 的「相關」）
兩個條目之間的關聯，例如論文和它的補充資料、同一部作品的書與電影版。關聯一定是**雙向**的：A 關聯到 B，B 的「關聯」區也會列出 A。

| 功能 | 說明 |
|---|---|
| 清單 | 類型圖示、標題、作者與年份，依標題排序；滑鼠停留顯示完整標題 |
| 前往 | 點一下選取那個條目；它不在目前的清單中時，切換到它所在資料庫的「全部」並清除搜尋，清單會捲動到該條目 |
| 新增 | 按「＋ 新增」，搜尋標題或作者，點結果加入（可連續加入多個，已關聯的顯示「已關聯」）；按「完成」或 Esc 結束 |
| 拖曳加入 | 把中欄清單的條目拖到右欄的「關聯」區塊放開（區塊會高亮，游標旁顯示「加入關聯」）；可一次拖多個已選取的條目 |
| 移除 | 滑鼠停在該列時出現 ×；兩邊的關聯一起移除，條目本身不受影響 |
| 多個條目 | 大量編輯的「關聯」區可讓選取的條目互相關聯 |
| 刪除條目時 | 它的關聯一併移除 |
| 修改時間 | 新增或移除關聯時，兩個條目都算修改過 |

### 關聯圖
以一個條目為中心，畫出它和卡片、其他條目之間的關係。按中欄清單上方的「關聯圖」按鈕（或右欄上方的同一個按鈕），中欄的條目清單就換成關聯圖：沒有選取條目時以清單的第一個條目為中心，選了多個時以最後點的那個為中心；再按一次或按關聯圖左上的 ← 回到清單。開或關會被記住；選取多個條目或沒有選取時顯示清單。

| 功能 | 說明 |
|---|---|
| 節點 | 中心條目（大圓，強調色）、其他條目（圓，依類型分組上色並顯示類型圖示）、卡片（圓角方塊，顯示物件類型圖示）、白板（虛線小方塊）。標籤顯示標題（過長截斷），滑鼠停留顯示完整標題與說明 |
| 關係 | 卡片引用條目（實線）；卡片只引用條目檔案上的註解（虛線，線上標示「N 則註解」；檔案庫中共用同一份檔案的條目也算）；條目「關聯」（點線）；卡片連結（灰線，有方向時畫箭頭，備註標在線上）；卡片所在的白板（細線） |
| 層數 | 1 層：直接相連的卡片、關聯條目，以及卡片所在的白板。2、3 層：再沿著卡片引用、關聯、卡片連結往外走；圖中所有節點之間的關係都會畫出。層數會被記住。最多 150 個條目與卡片，超過時提示 |
| 顯示白板 | 勾選框，可隱藏白板節點（記住選擇） |
| 排列 | 力導向排列，各層靠近各自的虛線圓圈，中心固定；拖曳節點移動、拖曳空白處平移、滾輪縮放；「重新排列」「顯示全部」按鈕 |
| 點一下 | 選取節點：相鄰的節點與線保持清楚、其他變淡，左下角顯示類型、相鄰數與前 6 個關係，以及動作按鈕；點空白處取消 |
| 雙擊／按鈕 | 條目：設為中心（同時在 Drawer 中選取它，右欄跟著切換；不在目前清單時切換到它的資料庫）。卡片：在白板中開啟（不在白板上的卡片在 Whiteboard 的側邊面板開啟）。白板：透過圖中在那個白板上的卡片開啟 |
| 更新 | 在右欄新增筆記卡片、修改條目等之後重新讀取 |

### 附件
| 功能 | 說明 |
|---|---|
| 加入附件 | 用按鈕選擇檔案，或把檔案拖進視窗 |
| 5 GB 以下 | 檔案**複製**到資料庫的 `storage` 資料夾；檔名重複時自動改為 `檔名 (2).pdf` |
| 超過 5 GB | **不複製**，只記錄原始檔案的完整路徑（連結檔案）；會提示「請勿移動或刪除原始檔案」 |
| 連結檔案的顯示 | 🔗 圖示、「連結」標籤、斜體；滑鼠停留顯示完整路徑 |
| 閱讀 / 開啟 / 位置 | 「閱讀」在閱讀器中開啟（雙擊也是）；「開啟」用系統預設程式開啟；「位置」在檔案總管中顯示；連結檔案若已被移動、刪除或磁碟未連接，會顯示錯誤訊息 |
| 刪除附件 | 複製的附件：連同檔案一起刪除。連結檔案：按鈕變為「移除」，只刪除紀錄，**不會刪除原始檔案** |

連結門檻定義在 `src-tauri/src/drawer.rs` 的 `LINK_THRESHOLD`。

### 資料庫位置
資料庫由 `banyan.db` 和附件資料夾 `storage` 組成，兩者一起搬移。在「設定 → 資料儲存位置」（或 Drawer 左欄底部的「⚙ 資料庫位置」）選擇資料夾後：

| 選擇的資料夾 | 可用選項 |
|---|---|
| 還沒有資料庫 | **把目前的資料庫搬到這裡**：複製資料庫與所有附件並改用新位置，原本的資料保留，需自行刪除<br>**在這裡建立新的空資料庫** |
| 已經有資料庫 | **開啟這個資料庫**：切換過去，之後可以切回來 |

- 其他選項：「在檔案總管中開啟」、「改回預設位置」。
- 切換後立即生效，不需重新啟動。
- 選擇的位置存在 `%APPDATA%\banyan\config.json`，下次啟動沿用。
- 啟動時若找不到設定的資料夾（例如 Dropbox 或外接硬碟未連接），改用預設位置並顯示警告，不會在原處建立空的資料庫。
- 拒絕的資料夾：附件資料夾內的資料夾、已有資料庫的資料夾（搬移時）、已有自己 `storage` 資料夾的資料夾。
- 搬移在背景執行，視窗不會卡住；中途失敗會刪除未完成的複本，原資料庫不受影響。

### 資料儲存
- 預設位置：`%APPDATA%\banyan\`（可在「設定 → 資料儲存位置」更改）
- 資料庫：`banyan.db`（SQLite，WAL 模式，結構版本 18；舊版資料庫在開啟時先備份再自動升級，見「更新後的資料庫升級」）
- 升級前的備份：`backups\`（和 `banyan.db` 同一個資料夾；搬移資料庫位置時不會一起搬）
- 附件：`storage\<條目 id>\`
- 關聯圖由後端 `item_graph(itemId, depth)`（`src-tauri/src/item_graph.rs`）以廣度優先查詢 `card_items`、`card_annotations`、`item_relations`、`card_links`、`board_cards`，不另外存資料。
- 資料表：`collections`（`view` 為 `list` 或 `gallery`）、`items`、`item_creators`（作者與身分）、`item_collections`、`tags`、`item_tags`、`attachments`、`item_relations`（關聯，每組只存一筆，`item_a < item_b`）；Whiteboard 使用 `whiteboards`、`cards`、`board_cards`、`card_links`、`card_items`（卡片引用的條目）（同一個資料庫，搬移資料庫位置時一起搬）
- `items.full_text`：原文（資料庫 v14）
- `collections.library`：資料夾屬於 `literature`（文獻庫）或 `files`（檔案庫）（資料庫 v15，原有資料夾都是文獻庫）。條目屬於哪個資料庫由類型決定：檔案庫的類型都以 `file` 開頭（`fileDocument`、`fileImage`…，見 `drawer.rs` 的 `file_type_for`）
- `attachments.mirror_of`：檔案庫條目的附件若是某個文獻附件的共用複本，記錄那個附件的 id（`stored_path` 相同）。資料庫 v16 升級時，替所有既有的文獻附件建立檔案條目
- `items.cite_key`、`items.cite_key_manual`（固定，不再自動更新）、`annotations.seq`（註解鍵的編號）；`cite_key` 不重複（資料庫 v20，升級時替現有條目與註解產生）。程式在 `src-tauri/src/citations.rs`。
- `items.authors` 保留為清單顯示與搜尋用的摘要（每行一位，主要身分在前），由程式自動維護

### 已知限制
- 檔案庫的檢視：沒有「中圖示」「清單」等其他檔案總管的檢視；不能在中欄重新命名（F2）、建立資料夾或右鍵選單，需在左欄或右欄操作；PDF、影片沒有縮圖（顯示類型圖示）；切換大圖示／詳細資料是全部資料夾共用，不能每個資料夾分別設定；檔案庫的畫廊資料夾不能改回一般資料夾。
- 閱讀器：註解的限制見「Annotator」；PDF 沒有縮圖側欄、不能旋轉頁面，PDF 內的連結（目錄頁中的連結、網址）不能點，掃描的 PDF 沒有文字可選取或搜尋；書籍沒有分頁模式（每章捲動），書籍與漫畫會整個讀進記憶體；不支援 HUFF/CDIC 壓縮的 MOBI、有 DRM 的 Kindle 書、KFX、CBR（RAR）、CB7、DjVu；AZW3 為簡化顯示；TXT 編碼判斷只區分 UTF-8／UTF-16／Big5／GB18030（日文 Shift-JIS 等會判斷錯誤）；直排模式下搜尋跳到的位置可能不在畫面正中；影片能播放的格式取決於系統的 WebView（MP4／WebM 可以，部分 MKV、AVI、WMV 不行，會提示改用預設程式）；閱讀位置存在這台電腦的 WebView 中，不會跟著資料庫搬移。
- 檔案庫：不能匯入整個資料夾（資料夾會略過）、沒有重複檔案偵測、搜尋不比對檔案內容（只比對名稱、檔名、標籤等）、畫廊沒有縮圖；預覽會把整個檔案讀進記憶體；Word、試算表、簡報沒有預覽。在檔案庫刪掉文獻附件的檔案條目後，不會再自動建立（除非重新加入附件）；檔案條目的名稱、類型和文獻的附件各自獨立，改名不會同步。
- `attachment:` 協定：沒有 Range 的請求（例如 pdf.js 開啟 PDF 時的第一個請求）會把整個檔案讀進記憶體，只有分段請求才是逐段讀取；一次只回應一個範圍（不支援多段 Range）。刪除條目失敗時把檔案搬回原處是盡力而為，搬回也失敗時檔案會留在檔案條目的資料夾中。
- 檔案庫的檔案拖進視窗一律建立新條目；要替檔案庫的條目加入更多檔案，需用右欄「檔案」區塊的「＋ 加入檔案」。
- 附件一次只能加到一個條目；選取多個條目時把檔案拖進視窗會提示只選一個。
- 大量編輯無法一次修改標題，也不能復原（「設定欄位」與「刪除」會先確認）。
- 無法直接在左欄建立還沒有條目使用的空白標籤。
- 關聯依標題的字碼排序，中文標題不是依筆畫或注音排列。
- 沒有垃圾桶，刪除為永久刪除。
- 清單欄位不能排序，也不能調整順序。
- 畫廊直接讀取原始圖片檔，沒有產生縮圖；圖片很大或很多時，捲動時載入較慢。
- 畫廊只顯示每個條目的第一張圖片；圖片類型的判斷依副檔名。
- 姓名只有一個欄位，沒有分開姓與名。
- 附件列只能雙擊開啟；要刪除或在檔案總管中顯示附件，仍需到右欄的「附件」區操作。
- 尚未在真實視窗中驗證：選擇檔案、開啟附件、拖放檔案加入附件、拖曳條目到資料夾、實際搬移或切換資料庫、實際加入 5 GB 以上的檔案、清單中摺疊顯示附件、左欄標籤與右欄區塊摺疊、多選／框選與大量編輯、關聯（新增、拖曳加入、前往、移除）、清單欄位選擇與欄寬調整、畫廊（顯示、切換、建立、拖入限制）。（以上流程已用模擬後端在瀏覽器中測試過。）把圖片檔拖進畫廊建立照片條目只有 Rust 測試，沒有在視窗中測試。

## 切換模組

視窗最左側的直欄最上方是 Banyan 的榕樹標誌，下面列出模組（目前有 Drawer、Whiteboard、Annotator），點一下切換；目前的模組以淡綠底與左側綠色細線標示。上次使用的模組會被記住，下次開啟時直接進入。

## 分頁
參考瀏覽器與 Zotero：PDF 與電子書可以各自開在一個分頁中，和模組來回切換。

| 功能 | 說明 |
|---|---|
| 分頁列 | 有檔案分頁時，畫面最上方出現分頁列。第一個分頁固定是目前的模組（Drawer、Whiteboard、Annotator 或設定，不能關閉），後面每個檔案一個分頁，顯示類型圖示與條目標題（太長時截斷，滑鼠停留顯示完整標題與檔名）。目前的分頁和下方頁面相連，上緣有綠色細線 |
| 開啟 | **Drawer**：PDF 與電子書（EPUB、MOBI、AZW3、FB2、TXT）的「閱讀」、雙擊附件或檔案，改為在分頁中開啟（圖片、影片、文字、漫畫仍用整個視窗的閱讀器）。**Annotator**：上方的「在分頁開啟」，或用滑鼠中鍵點左欄的檔案。**閱讀器**：PDF 與書的「在分頁開啟」。已經開著的檔案直接切換過去，不會重複 |
| 檔案分頁的內容 | 閱讀器與它的工具，右側是這個檔案的註解清單（和 Annotator 的右欄相同：畫重點、筆記、書籤、建立卡片都可以），上方的註解按鈕可隱藏或顯示（會記住）；「在 Drawer 中顯示」、「預設程式開啟」 |
| 切換 | 點分頁；點左側直欄的模組會回到第一個分頁。模組分頁在背景保持原狀（選取、捲動位置、搜尋），檔案分頁切換回來時回到上次讀到的位置 |
| 關閉 | 分頁上的 ×（滑鼠停留或目前分頁時出現）、滑鼠中鍵；關閉目前的分頁時改顯示右邊（沒有則左邊）的分頁。右鍵選單：關閉、關閉其他分頁、關閉右側的分頁、關閉所有檔案分頁、在 Drawer 中顯示 |
| 排列 | 拖曳分頁改變順序；分頁太多時可以用滑鼠滾輪左右捲動，目前的分頁會捲到看得見 |
| 快速鍵 | Ctrl＋Tab／Ctrl＋Shift＋Tab（或 Ctrl＋PageDown／PageUp）下一個／上一個分頁；Ctrl＋1 模組分頁，Ctrl＋2～8 第 N 個分頁，Ctrl＋9 最後一個；Ctrl＋W 關閉目前的檔案分頁 |
| 記住 | 開著的分頁與目前的分頁在下次開啟時恢復 |

- 只有目前顯示的檔案分頁會載入（其他分頁不佔記憶體，切換時重新開啟並回到上次的位置）；模組分頁在背景時，它的快速鍵（例如白板的 Delete、空白鍵平移、Drawer 的 Ctrl＋F）不會作用。
- 白板、卡片與條目還不能開在分頁中。

## 設定

左側直欄最下方的「設定」（取代原本的「更新」與外觀切換兩個按鈕），和模組一樣是一個整頁，一頁裡有三個區塊：

| 區塊 | 內容 |
|---|---|
| 外觀 | 三個選項「跟隨系統／淺色／深色」，點一下立即套用並記住 |
| 更新 | 目前版本、「檢查更新」按鈕與結果（見「檢查更新」）；開啟設定頁時不會自動連線檢查 |
| 資料儲存位置 | 目前的資料夾、「在檔案總管中開啟」「改回預設位置」「變更位置」（見「資料庫位置」）；啟動時找不到設定資料夾的警告也顯示在這裡。下方「更新時的資料庫保護」說明升級時的保護方式，列出所有備份（時間、資料庫版本、大小，還原前存下的標「還原前」）、每份的「還原…」按鈕與「開啟備份資料夾」（見「更新後的資料庫升級」） |

- 設定頁開過一次後會保留在背景，下載更新時切換到其他模組不會中斷下載。
- 從 Drawer 左欄的「⚙ 資料庫位置」進入時，會直接捲到「資料儲存位置」。
- 變更資料儲存位置後回到 Drawer／Whiteboard，會重新載入新位置的資料。

## 更新後的資料庫升級

Banyan 更新後，新版本可能需要升級資料庫的結構（`banyan.db` 的 `user_version`，目前第 18 版）。開啟資料庫時（啟動、在設定中開啟或切換資料庫）依序處理：

| 情況 | 處理方式 |
|---|---|
| 已是最新版本 | 直接開啟，不做任何事 |
| 新的空白資料庫 | 直接建立，不備份 |
| 舊版資料庫 | 1. 完整性檢查（`PRAGMA quick_check`），未通過就不升級、不改動檔案，並說明可能已損壞<br>2. 把原本的資料庫完整複製到資料庫旁的 `backups\banyan-v<舊版本>-<UTC 時間>.db`（只保留最近 5 份），備份失敗就不升級<br>3. 所有升級步驟在**同一個交易**中完成，並確認沒有新增不一致的關聯；任何一步失敗就全部還原，檔案和升級前完全一樣<br>4. 成功後顯示一次提示：「Banyan 已更新：資料庫已從第 N 版升級到第 M 版」與備份位置（Drawer 的提示，或設定頁） |
| 較新版 Banyan 建立的資料庫 | **不開啟**，以免舊版程式誤讀或損壞資料，提示「請把 Banyan 更新到最新版本」。例如在兩台電腦用雲端硬碟共用資料庫、其中一台的 Banyan 較舊 |

- 啟動時，設定的資料庫位置無法開啟（包括上述情況）會暫時改用預設位置並顯示原因；連預設位置都無法開啟時，顯示錯誤視窗說明原因後結束程式，不會在臨時的空白資料庫上繼續工作。
- 附件（`storage` 資料夾）不在升級範圍內，所以不備份。

### 還原備份

在「設定 → 資料儲存位置 → 更新時的資料庫保護」的備份清單中，按某一份的「還原…」並確認：

1. 先檢查備份：必須是 `backups` 資料夾中的檔案、通過完整性檢查、不是較新版 Banyan 的資料庫；不符合就不還原，資料庫沒有變動。
2. 把目前的資料庫另存為 `backupsanyan-v<版本>-<UTC 時間>-before-restore.db`（清單中標「還原前」），之後可以用同樣方式還原回來。
3. 用備份取代 `banyan.db` 後重新開啟；備份是舊版結構時，照上面的流程再升級一次（會再備份一份）。
4. 重新開啟失敗時，自動放回還原前的資料庫並說明原因。
5. 完成後在設定頁顯示「已還原備份 …」與還原前資料庫的位置；回到 Drawer／Whiteboard 時重新載入資料。

- 只還原資料庫，附件檔案（`storage`）不變：備份之後才加入的附件檔案會留在資料夾中但不再出現在 Banyan 裡；之後刪除的附件在還原後會找不到檔案。
- 還原前存下的那份也算在「最近 5 份」中，下次升級時可能被清掉。
- 已開啟的閱讀器分頁不會自動關閉，若該附件在備份中不存在，需自行關閉分頁。
- 要用舊版 Banyan 開啟備份時，仍需手動操作：關閉 Banyan，把備份改名為 `banyan.db` 取代原本的檔案。
- 開發者新增結構變更時：提高 `db.rs` 的 `SCHEMA_VERSION`，在 `migrate_steps` 最後加一個步驟；步驟裡不能自己開始或提交交易。

## 檢查更新（手動）

在「設定 → 更新」按「檢查更新」。只有按下時才檢查，不會在背景自動檢查或下載。

| 狀態 | 畫面 |
|---|---|
| 檢查中 | 按鈕顯示「檢查中…」 |
| 已是最新 | 「已經是最新版本」，可再檢查一次 |
| 有新版本 | 顯示新版本號、發布日期與更新說明，可按「下載更新」 |
| 下載中 | 進度條與已下載／總大小；可以切換到其他模組，下載不會中斷 |
| 下載完成 | 提醒先儲存工作，再按「安裝更新」。若安裝程式無法啟動，可用已下載的更新重試 |
| Windows 安裝 | App 會退出，安裝程式最多等候約 10 秒讓舊程式釋放執行檔，安裝完成後重新開啟 Banyan。若仍有 Banyan 在執行，可儲存工作並關閉其餘視窗後重試 |
| 其他平台安裝完成 | 可按「立即重新啟動」以使用新版本 |
| 錯誤 | 中文說明（找不到 latest.json、無法連線、簽章不符），「詳細資訊」可展開原始錯誤 |
| 尚未設定來源 | 更新網址仍是 `OWNER/REPO` 佔位時，直接提示要改哪裡，不送出請求 |

**技術細節**
- 使用 `tauri-plugin-updater`（只在桌面版啟用）與 `tauri-plugin-process`（重新啟動）。
- 更新來源：`src-tauri/tauri.conf.json` 的 `plugins.updater.endpoints`，目前是 `https://github.com/HaemonMercer/Banyan/releases/latest/download/latest.json`。已發布的版本：v0.1.0（2026-11-11）。目前程式碼的版本是 0.1.3（2026-11-13；新增從設定頁還原資料庫備份）。
- 發布前要先調高版本號（`tauri.conf.json`、`package.json`、`src-tauri/Cargo.toml` 三處一致），已安裝的舊版才會把它當成更新。
- 更新檔必須簽章：公鑰在 `tauri.conf.json`，私鑰在 `%USERPROFILE%\.tauri\banyan.key`（沒有密碼，不在專案中；遺失就無法再發布能被舊版接受的更新）。
- Windows 以 `passive` 模式安裝（顯示進度、不需操作）。
- 發布流程：設定 `TAURI_SIGNING_PRIVATE_KEY` 後 `npm run tauri build`，再執行 `node scripts/make-latest-json.mjs HaemonMercer/Banyan "更新說明"` 產生 `latest.json`，把安裝檔和 `latest.json` 上傳到 `v<版本>` 的 GitHub Release。腳本目前只處理 Windows NSIS 安裝檔。

## Annotator（註解）

獨立的模組（左側直欄的 Annotator），參考 Zotero 的 PDF 閱讀器、Readwise、Heptabase 的 PDF 標註。介面分三欄：左欄檔案、中欄閱讀、右欄這個檔案的註解。可以標註 **PDF** 與**電子書**（EPUB、MOBI／AZW／AZW3、FB2、TXT）。

### 檔案（左欄）
| 功能 | 說明 |
|---|---|
| 檔案清單 | 文獻庫附件與檔案庫中所有的 PDF 和電子書，每個檔案只列一次（文獻的附件和它在檔案庫的檔案是同一份，共用註解）；顯示條目標題、檔名與註解數，最近標註的在前 |
| 搜尋 | 依條目標題或檔名篩選 |
| 只顯示有註解的檔案 | 勾選後隱藏還沒標註的檔案（會記住） |
| 所有註解 | 最上方的項目：中欄以**卡片庫**的樣子列出**有註解的文件**，每份文件一張卡片（標題、檔名、各顏色重點的比例條、最近 3 則重點、重點與書籤數、最後註解日期）。可搜尋引文、筆記、檔名（只留下有符合的文件），排序：最近註解、標題、註解數（會記住）。**點一下卡片，右欄列出這份文件的註解**（同「註解（右欄）」，有目錄時依章節分組），標題旁的按鈕或雙擊卡片打開檔案；點右欄的註解打開檔案並跳到那裡；點空白處取消選取 |
| 記住 | 上次開啟的檔案；閱讀位置和閱讀器相同（見「閱讀器」） |

### 標註（中欄）
中欄就是閱讀器（見「閱讀器」），多了以下功能。在 Drawer 的閱讀器中也一樣可以標註。

| 功能 | 說明 |
|---|---|
| 畫重點 | 選取文字後，下方出現選單：5 種顏色（黃、綠、藍、粉紅、紫）點一下就畫上；「筆記」用上次用的顏色畫上並立刻打開筆記；「複製」複製文字。上次用的顏色有灰色外圈。PDF 的重點畫在頁面上（可以跨行、跨頁），書的重點標在文字上 |
| 選單快速鍵 | 選取文字後：<kbd>1</kbd>–<kbd>5</kbd> 畫上對應顏色、<kbd>N</kbd> 畫重點並寫筆記、<kbd>C</kbd> 複製、<kbd>Esc</kbd> 取消選取（不會關閉閱讀器） |
| 編輯重點 | 點一下重點打開卡片式的視窗：上方是位置、日期與被幾張卡片引用（上緣是重點的顏色），中間引文與筆記，下方換顏色、建立卡片或開啟卡片、刪除。點旁邊、Ctrl＋Enter 或 Esc 儲存並關閉；不在筆記中時 <kbd>1</kbd>–<kbd>5</kbd> 換顏色。打開的重點在文字上以橘色外框標示，右欄同一則也會標示並捲動到看得見 |
| 重點的提示 | 滑鼠移到 PDF 的重點上游標變成手形，停留顯示筆記；有筆記的 PDF 重點在最後一行末端有小圓點，書中的重點下方有虛線 |
| 刪除與復原 | 刪除重點或書籤後，下方出現「已刪除重點　復原」（約 6 秒，也可以按 Ctrl＋Z）。已經做成卡片或被卡片引用的會先確認（卡片上的引用無法復原），確認後不提供復原 |
| 書籤 | 上方的「書籤」：PDF 標記目前這一頁（頁面右上角出現書籤標記），書標記目前的章節位置；在同一個位置再按一次就移除 |
| PDF 的目錄 | PDF 本身的目錄改稱「目錄」，「書籤」是自己加的 |

### 註解（右欄）
| 功能 | 說明 |
|---|---|
| 清單 | 依在檔案中的順序列出重點與書籤：顏色（左側色條）、位置（第 N 頁／章節名稱）與建立日期（一行，太長時位置以「…」縮短）、引文（最多 4 行）、筆記。這份清單的元件（`AnnotationRows.tsx`）也用在 Whiteboard 右欄的「註解」分頁 |
| 依章節分組 | 有目錄時，註解依章節排列，每個章節一個標題（捲動時停在上方，附則數），**只出現有註解的章節**：電子書用註解所在的章節；PDF 用 PDF 本身的目錄，取註解頁碼之前最近的一項（子章節依層級縮排，第一個章節之前的列在「目錄之前」）。沒有目錄的 PDF 照順序列出 |
| 前往 | 點引文跳到原文，該處閃一下；目前這一則以重點顏色的外框標示（在閱讀器點開重點時也會同步標示） |
| 筆記 | 點筆記直接編輯（Ctrl＋Enter 儲存、Esc 取消）；沒有筆記時滑鼠停留出現「＋ 筆記」 |
| 搜尋 | 比對這個檔案的引文、筆記與位置 |
| 篩選 | 全部／重點／書籤（各顯示數量），或只看某個顏色（沒有的顏色變淡）；沒有符合時可一鍵「清除篩選」 |
| 匯出 | 右上角按鈕把這個檔案的註解複製成文字（標題、每則的位置、引文與筆記） |
| 卡片與刪除 | 滑鼠停留時右上角出現「建立／開啟卡片」與「刪除」 |
| 沒有註解時 | 顯示操作提示（選取文字、快速鍵、點重點、書籤） |

### 轉成卡片（和 Whiteboard 連動）
| 功能 | 說明 |
|---|---|
| 建立卡片 | 重點的「建立卡片」產生一張卡片：標題「摘錄：引文開頭」，內容是引文、出處（《條目標題》第 N 頁）與筆記；卡片引用該條目與這段註解（從卡片的「引用的註解」可以回到原文）。卡片不在任何白板上，可以在卡片庫或條目的「筆記卡片」中找到，再放到白板 |
| 同一張卡片 | 已經做過卡片的重點按鈕變成「開啟卡片」：切換到 Whiteboard，在側邊面板打開那張卡片 |
| 刪除 | 刪除重點不會刪除已經做好的卡片（卡片上的引用會消失） |

### 被卡片引用
任何卡片都可以引用註解，和引用 Drawer 條目一樣（見 Whiteboard 的「引用註解」）。

| 功能 | 說明 |
|---|---|
| 從重點建立的卡片 | 自動引用那個重點 |
| 引用數 | 右欄每則註解下方顯示「N 張卡片引用」，點一下展開卡片清單（顯示所在白板），點卡片在 Whiteboard 開啟 |

### 資料
- `card_annotations`（資料庫 v18）：卡片引用的註解（卡片、註解任一刪除時一起刪除）；升級時替已經從註解建立的卡片補上引用。
- `annotations`（資料庫 v17）：`attachment_id`（檔案的原始附件；檔案庫中的共用檔案記在文獻的附件上）、`kind`（`highlight`／`bookmark`）、`color`、`quote`、`note`、`location`（JSON：PDF 是每個方框在頁面中的比例位置，書是章節與文字位置）、`sort_key`（在檔案中的順序）、`card_id`。
- 刪除檔案（附件）時它的註解一併刪除。刪除文獻條目但檔案仍在檔案庫時，註解移到檔案庫的檔案，做過的卡片也改為同時引用檔案庫的條目（否則會被當成只屬於該條目的筆記卡片一起刪除）。

### 已知限制
- 掃描的 PDF 沒有文字層，無法選取文字畫重點（可以加書籤）。
- 書中重點以章節中的文字位置記錄：重新匯入內容不同的同一本書，重點位置可能錯開。直排顯示時一樣可以標註。
- 不能在 PDF 上手繪、加文字方塊或框選區域（只能標註文字）；不能匯入 PDF 檔案內原有的註解，也不會把註解寫回 PDF。
- 卡片的引文不會隨重點的筆記更新（卡片做好之後是獨立的筆記）。
- 匯出只有複製成文字。
- 只在瀏覽器中以模擬後端測試過，尚未在真實視窗中操作。

## Whiteboard（白板）

參考 Heptabase。有**卡片**、**卡片之間的連結**（雙向可見，可加箭頭與備註）、**區塊**、**多選**、**側邊面板開啟卡片**、**卡片標籤**、**卡片庫**和**資料夾**。卡片與連結的整體關係在獨立的 Graph 模組中查看（見「Graph（關係圖）」）。介面分三欄：左欄卡片庫、資料夾與白板，中間畫布或卡片庫（開啟卡片時右側滑出側邊面板），右欄（最右邊是和模組列一樣的直排圖示分頁「卡片／文獻／檔案庫／註解」，左邊上半部是可拖曳的清單，下半部是選取卡片的連結與引用的文獻）。

### 資料夾與白板（左欄）
白板可以放進資料夾，資料夾可以多層巢狀（和 Drawer 的資料夾類似，但一個白板只屬於一個資料夾）。

| 功能 | 說明 |
|---|---|
| 新增 | 標題列的 ＋ 選單：「🧩 新白板」（放在最上層）或「📁 新資料夾」；滑鼠停在資料夾上：🧩 在裡面新增白板、＋ 新增子資料夾 |
| 開合資料夾 | 點資料夾；開合狀態會記住。開啟某個白板時，它所在的資料夾會自動展開 |
| 重新命名 | 雙擊名稱，或滑鼠停留時按 ✎；新白板建立後直接進入重新命名 |
| 移動 | 把白板或資料夾拖到另一個資料夾上；拖到標題列「白板」移到最上層。拖曳時游標旁顯示「移到「研究/論文」」，停在收合的資料夾上約 0.7 秒會展開；不能把資料夾移到它自己或子資料夾裡；Esc 取消 |
| 刪除資料夾 | 子資料夾一併刪除；裡面的白板**保留**，移到最上層（會先確認） |
| 刪除白板 | 滑鼠停在白板上按 🗑；上面的卡片和它們的連結一併刪除（會先確認） |
| 卡片數 | 白板名稱右側顯示卡片數量；滑鼠停留顯示完整路徑 |

### 畫布
| 操作 | 說明 |
|---|---|
| 新增卡片 | 在空白處雙擊，或按「＋ 新卡片」（放在畫面中央）；新卡片會自動聚焦標題 |
| 卡片顯示大致內容 | 平時卡片只顯示放得下的內容（字級略小、程式碼與圖片限制高度），不會出現捲軸；放不下時底部淡出並顯示「⋯」。點內容進入編輯時才看得到全部 |
| 縮小時的概覽 | 縮放到 55% 以下時，卡片改為概覽：標題放大加粗、內容換成約 90 字的摘要（最多 3 行，換行併成空格），隱藏引用的文獻標籤；字級隨縮放調整，縮得很小時仍看得清楚 |
| 編輯卡片 | 直接在卡片上輸入標題；內容以 Markdown 顯示，用所見即所得編輯器編輯：點一下內容就在點的位置開始編輯（在標題按 Enter 則從結尾開始）；離開或按 Esc 結束編輯並自動儲存（見「卡片內容」） |
| 移動卡片 | 拖曳卡片頂端的把手列；選取多張時拖曳其中一張的把手會一起移動 |
| 框選 | 在空白處（或區塊內的空白處）拖曳出選取框，碰到的卡片都會被選取；按住 Shift 框選會加入原本的選取 |
| 多選 | Shift＋點卡片加入或移出選取；Ctrl＋A 選取白板上全部卡片 |
| 卡片頂端列 | 滑鼠停留或選取時出現：最左邊是「摺疊／展開」（▾／▸），接著是「在側邊面板開啟」（↗），中間是拖曳把手，最右邊是「⋯」選單。選單內有：自動適應長度（勾選切換，卡片與便利貼才有）、摺疊／展開、在側邊面板開啟、複製、剪下、建立副本、從白板移除、完全刪除（右側標示快速鍵）。選單中的動作在卡片屬於多選時套用到所有選取的卡片 |
| 摺疊 | 卡片只留頂端列與標題（便利貼留第一行文字、其他物件留類型圖示與名稱），連線改接到摺疊後的大小；摺疊的卡片仍可移動、連結、框選，不能調整大小。原本的高度會保留，展開後回復。每個白板各自記住（資料庫 v19） |
| 自動適應長度 | 卡片與便利貼可開啟：高度隨內容（顯示與編輯時都是）自動變長或變短，不再淡出截斷；拖曳右下角只調整寬度。縮小到概覽時保持最後的高度。每個白板各自記住；新高度會儲存，所以連線、框選與區塊都依實際大小 |
| 複製／剪下／貼上 | 「⋯」選單或 Ctrl＋C／Ctrl＋X（有選取卡片、且沒有選取文字時）。同時把卡片內容以 Markdown（`# 標題` ＋內容，多張以 `---` 分隔）放進系統剪貼簿，可以貼到其他程式。在任一白板按 Ctrl＋V，卡片貼在畫面中央並保持彼此的相對位置、大小、摺疊與自動長度：不在這個白板上的是**同一張卡片**（剪下後貼到另一個白板就是搬移），已經在這個白板上的貼上**副本**。剪貼簿換成其他內容後，Ctrl＋V 照舊處理圖片與 YouTube 連結 |
| 建立副本 | 「⋯」選單或 Ctrl＋D：在右下方 30 px 處建立內容相同的新卡片（標題、內容、類型資料；圖片與 PDF 會複製一份檔案）。標籤、引用的文獻／註解與連結不複製 |
| 開啟卡片 | 卡片頂端的 ↗、選取一張卡片後按 Enter，或點右欄清單中的卡片，在側邊面板開啟（見「側邊面板」）；開啟中的卡片在白板上以虛線框標示 |
| 調整大小 | 拖曳卡片右下角（最小 120 × 60） |
| 從白板移除 | 卡片「⋯」選單的「從白板移除」、右欄的「從白板移除」、側邊面板的「從白板移除」，或選取卡片後按 Delete（多選時一次移除全部）。只把卡片從**這個白板**拿掉，不會詢問；卡片本身、它的連結、標籤和引用的文獻都保留，仍在卡片庫和其他白板上，之後可以從右欄或卡片庫再拖回來。移除後顯示提示 |
| 完全刪除 | 卡片「⋯」選單的「完全刪除」、右欄的「刪除」、側邊面板的「完全刪除」，或選取後按 Shift＋Delete。卡片從**所有白板和卡片庫**中刪除，連結與版本記錄一併刪除；會先確認，確認訊息會提醒「只想從這個白板拿掉請改用從白板移除」 |
| 平移 | 按住空白鍵拖曳、按住滑鼠中鍵拖曳，或用滾輪／觸控板捲動（拖曳空白處現在是框選，和 Heptabase 相同） |
| 縮放 | Ctrl＋滾輪（以游標為中心），或右下角的 − / ＋；點百分比回到 100%；⤢ 顯示全部卡片（20% ~ 250%） |
| 開啟白板時 | 自動縮放到能看見所有卡片 |
| Esc | 取消選取；沒有選取時關閉側邊面板 |
| 點空白處 | 取消選取，並關閉側邊面板（拖曳框選或 Shift＋點空白處不會關閉；關閉前會先儲存正在編輯的內容） |

### 區塊（Section）
白板上有名稱與顏色的區域，用來把卡片分組（參考 Heptabase 的 Section）。

| 功能 | 說明 |
|---|---|
| 新增 | 標題列的「▭ 區塊」：有選取卡片時，建立剛好包住它們的區塊；沒有選取時放在畫面中央。建立後直接輸入名稱 |
| 移動 | 拖曳區塊的標題列；完全在區塊裡的卡片會一起移動 |
| 調整大小 | 拖曳右下角（最小 120 × 120）；調整大小不會移動卡片 |
| 重新命名 | 雙擊標題；輸入框中可以用滑鼠點到任意位置、拖曳選取部分文字 |
| 顏色 | 滑鼠停在區塊上時，標題列右側有 6 個色點（預設、藍、綠、黃、紅、紫） |
| 刪除 | 標題列的 ×，或點標題列選取後按 Delete；只刪除區塊，卡片保留 |
| 排列順序 | 區塊畫在連線與卡片的下方；區塊內的空白處可以框選、雙擊新增卡片 |
| 拖曳加入 | 把卡片或任何物件（便利貼、圖片、心智圖、表格…）拖到區塊上：拖曳中目標區塊會高亮；放開時只要卡片的中心在區塊裡，它就加入這個區塊，卡片超出邊界時區塊自動長大把它包住（上方保留標題列的空間）。區塊重疊時加入最小的那個。把卡片的中心拖出區塊就離開。在區塊內新增的卡片、從右欄拖進區塊的卡片、在區塊中變大的心智圖或表格也一樣 |
| 成員 | 「完全在區塊裡」的卡片就是成員：移動區塊時一起移動，卡片庫顯示「白板 › 區塊」並可依區塊分組 |

### 物件類型（參考 Miro）
畫布左側有直立的插入工具列：卡片、便利貼、區塊、心智圖、表格（Excel 式）、圖表、圖片、影片、PDF。除了區塊，每種物件都是一張「卡片」，所以都能拖曳移動、建立連結、加標籤、引用文獻、在側邊面板開啟、出現在卡片庫，也有版本記錄。

| 類型 | 說明 |
|---|---|
| 🗒 卡片 | 原本的文字卡片 |
| 便利貼 | 方形彩色紙條，沒有標題，字比較大，內容一樣以 Markdown 顯示；把手列有 7 個色點（黃、橘、粉紅、綠、藍、紫、灰）；深色主題下仍是淺色紙條 |
| 心智圖 | Miro 式：中心主題在中間，分支可長在左右兩側，每個第一層分支有自己的顏色，以曲線連接；第一層主題是有色框，更深的主題是加底線的文字。物件會自動配合心智圖的大小，加入左側分支時中心主題留在原位 |
| 🖼 圖片 | 依圖片原始比例顯示（最大約 420 × 360）；調整大小時維持比例；有標題時顯示在圖片下緣 |
| ▶ YouTube 影片 | 先顯示縮圖與播放鍵，按下後在白板上播放；標題自動從 YouTube 取得；調整大小時維持比例。播放器只有在物件被選取時才接收滑鼠，所以平常可以在上面平移白板 |
| 📄 PDF | 在白板上顯示一頁，下方有 ‹ › 換頁、頁數、檔名、↗ 用系統程式開啟；放大白板時會以更高解析度重繪；標題預設為檔名 |

| 操作 | 說明 |
|---|---|
| 加入圖片／PDF | 工具列選擇檔案；或把檔案從檔案總管拖到白板上（放在放開的位置，可一次拖多個）；圖片也可以直接貼上（Ctrl＋V，例如截圖） |
| 加入影片 | 工具列「影片」貼上連結；或在白板上（沒有正在輸入時）直接貼上 YouTube 連結。支援 `youtube.com/watch?v=`、`youtu.be/`、`shorts/`、`embed/`、`live/`，以及 `t=` 開始時間 |
| 心智圖鍵盤 | 點選主題後：Tab 新增子主題、Enter 新增同層主題、F2 或雙擊編輯（直接打字會取代文字）、Delete／Backspace 刪除主題（連同子主題）、方向鍵移動選取、Alt＋↑／↓ 調整順序、Esc 取消選取。編輯時 Enter 完成、Shift＋Enter 換行、Tab 完成並新增子主題、Esc 取消（新主題留空會自動移除） |
| 心智圖滑鼠 | 選取主題時兩側出現 ＋（中心主題左右各一個，可往左或右長分支）；有子主題的主題旁有 − 可收合，收合後顯示隱藏的主題數；拖曳空白處移動整個心智圖 |

#### 圖表（用表格的資料，像 Excel 插入圖表）
| 功能 | 說明 |
|---|---|
| 建立 | 在表格選取範圍後，按表格下方的「插入圖表」或右鍵選單「插入圖表」（只選一格時用整個有資料的範圍）；或工具列「圖表」：選取表格時用它的資料，否則建立一個範例表格（月份、收入、支出）和它的圖表。圖表放在表格右邊，已有東西時往下找空位；名稱為「表格名稱 圖表」 |
| 讀取資料 | 和 Excel 相同：範圍的第一列是文字時當作數列名稱，第一欄是文字時當作類別；預設每一欄是一個數列，「切換列／欄」改用每一列 |
| 類型 | 直條圖、橫條圖、折線圖、區域圖、圓形圖（圓形圖用第一個數列，每個類別一塊） |
| 跟著表格更新 | 表格在同一個白板上時，修改表格（包括公式結果）圖表立即重畫，並保存最新的數字；在卡片庫、側邊面板或其他白板上顯示最後保存的數字 |
| 工具列 | 選取圖表時，下方出現：類型、切換列／欄、圖例、資料來源（表格名稱）與範圍（例如 `A1:C5`，可直接修改） |
| 外觀 | 數列顏色依固定順序（藍、橘、青、黃、粉紅、綠、紫、紅，最多 8 個數列；深色主題有對應顏色，配色已通過色盲與對比檢查）；直條最寬 24、資料端 4px 圓角、相鄰直條間隔 2px；折線 2px、資料點 8px 加外框；區域圖 10% 淡色；格線為細線；兩個以上數列時顯示圖例；軸上的數字取整（1、2、2.5、5 的倍數），10,000 以上用 K／M |
| 滑鼠停留 | 顯示該類別所有數列的數值（折線、區域圖有垂直參考線；圓形圖顯示百分比） |
| 其他 | 可以拖曳角落調整大小、雙擊名稱改名；側邊面板顯示圖表與數字表格 |

#### 表格（Excel 式）
外觀和操作都像 Excel 的工作表：上方是欄字母（A、B、C…）、左邊是列號（1、2、3…）、灰色格線、Excel 的字型（Aptos／Calibri）。表格名稱在上方：拖曳名稱列移動表格；**雙擊名稱直接在白板上改名**（Enter 完成、Esc 取消），也可以在側邊面板改名。YouTube 影片與 PDF 的名稱也可以這樣雙擊改名。新表格是 4 欄 × 5 列，套用 Excel 的藍色表格樣式（藍色標題列＋帶狀列）。物件大小跟著表格，不能直接拖曳角落縮放。

| 功能 | 說明 |
|---|---|
| 公式列 | 選取表格時，上方出現 Excel 的名稱方塊（目前儲存格，例如 `B3`）、`fx` 與公式列：顯示目前儲存格的原始內容（公式），可以直接在公式列裡編輯 |
| 選取 | 點儲存格；拖曳或 Shift＋點選取範圍（綠色粗框，範圍內淡綠色，所在的欄字母與列號會反白）；點欄字母或列號選取整欄、整列（Shift＋點延伸）；點左上角全選；Ctrl＋A 全選 |
| 輸入 | 直接打字就取代內容（中文輸入法可直接用）；F2 或雙擊編輯原本的內容；Backspace 清除後開始輸入。編輯時 Enter 完成並往下（Shift＋Enter 往上）、Tab 完成並往右、Esc 取消；在最後一列按 Enter 會新增一列 |
| 用點選輸入公式 | 和 Excel 一樣：輸入公式時（`=`、運算子、`(`、`,` 之後），點其他儲存格會把它的位址放進公式，拖曳放入範圍（`B2:B4`），Shift＋點把上一個位址延伸成範圍；再點別格會取代剛放入的位址。直接打字開始的編輯（Excel 的「輸入」模式）可以用方向鍵指向儲存格（Shift＋方向鍵延伸成範圍）；F2、雙擊或公式列開始的編輯（「編輯」模式）方向鍵移動游標。公式裡參照的儲存格以不同顏色的框標示（同一個位址同一種顏色） |
| 移動 | 方向鍵（Shift 擴大範圍、Ctrl 跳到邊緣）、Enter／Shift＋Enter 往下／往上、Tab／Shift＋Tab；選取範圍時 Enter／Tab 在範圍內循環（和 Excel 相同）；Home 到列首、Ctrl＋Home 到 A1、Ctrl＋End 到最後一格 |
| 填滿控點 | 選取範圍右下角的綠色小方塊，往下或往右拖曳：公式會複製並移動相對位址（`=B2*C2` 往下變 `=B3*C3`，`$` 固定的部分不變）；選取兩個以上的數字會延續等差數列（1、2 → 3、4）；其他內容重複。Ctrl＋D／Ctrl＋R 向下／向右填滿選取範圍 |
| 復原 | Ctrl＋Z 復原、Ctrl＋Y（或 Ctrl＋Shift＋Z）重做，表格內的每個變更都可以復原（最多 100 步；重新開啟白板後清空） |
| 清除 | Delete 清除選取範圍的內容（不會刪除表格本身） |
| 數字 | 可以輸入 `1,200`、`30%`、`$15` 等，會當成數字計算，數字靠右對齊 |
| 公式 | 以 `=` 開頭，用 A1 位址（標題列也算一列，和 Excel 表格的儲存格位址相同）：`=B2*C2`、`=SUM(B2:B5)`、`=IF(B5>1000,"超支","OK")`；運算子 `+ - * / ^ &`、比較 `= <> < > <= >=`；函數 SUM、AVERAGE、MIN、MAX、COUNT、COUNTA、PRODUCT、MEDIAN、ROUND、ABS、SQRT、POWER、IF、AND、OR、NOT、CONCAT、LEN、UPPER、LOWER。錯誤以紅字顯示：`#VALUE!`、`#DIV/0!`、`#REF!`、`#NAME?`、`#CIRC!`（循環參照）、`#ERROR!` |
| 右鍵選單 | 在儲存格、欄字母或列號上按右鍵：在上方／下方插入列、在左側／右側插入欄、刪除列／欄（可一次多個）、自動調整欄寬、對齊、向下／向右填滿、清除內容。插入或刪除時，公式位址自動調整，參照被刪除的儲存格變成 `#REF!`。表格右側與下方的 ＋ 在最後新增一欄或一列 |
| 欄寬 | 拖曳欄字母的右邊緣（最小 32）；雙擊右邊緣自動調整成最寬內容的寬度（和 Excel 相同） |
| 對齊 | 右鍵選單的靠左／置中／靠右，套用到選取的欄；沒設定時文字靠左、數字靠右 |
| 表格設計 | 下方的列（對應 Excel 的「表格設計」）：勾選標題列、合計列、帶狀列、首欄，以及 5 種表格樣式（灰、藍、綠、橘、紫，Excel 的 Office 配色）。標題列是彩色底白色粗體字、合計列是粗體加雙線、首欄是粗體 |

### 連結（雙向可見、可指向、可加備註）
一對卡片只會有一條連結，兩張卡片的連結清單都會列出它（雙向鏈結）。連結可以有方向（箭頭）和一段備註。

| 功能 | 說明 |
|---|---|
| 預設方向 | 拖曳圓點或從右欄拖曳建立的連結，箭頭指向放開的那張卡片；升級前就有的連結維持無方向 |
| 編輯方向與備註 | 點連線（或線上的備註）選取，右欄下半部變成「連結」：方向四選一（A → B、B → A、↔ 雙向箭頭、— 無方向），以及備註（例如「支持」「反駁」「導致」）；Enter 儲存，Shift＋Enter 換行。雙擊連線直接跳到備註框 |
| 畫布上 | 有方向的一端畫箭頭（沒有箭頭的一端是圓點）；備註以小標籤顯示在線段中間，點標籤也能選取連結 |
| 連結清單 | 選取卡片時，每條連結前面標 → （這張指向它）、←（它指向這張）、↔ 或 —，有備註時顯示在標題下方 |

| 功能 | 說明 |
|---|---|
| 拖曳建立 | 滑鼠停在卡片上時，右側出現圓點；把圓點拖到另一張卡片上放開。拖曳時顯示虛線，目標卡片會高亮 |
| 從右欄拖曳 | 把右欄清單中的卡片拖到白板上的卡片（見「右欄」）；可以連到不在這個白板上的卡片。**文字卡片（卡片、便利貼）拖到文字卡片上**時，改為把它的標題與內容以引用區塊（`>`）加在目標卡片的最後，結尾是 `— [[card:id\|標題]]`；存檔時依這個連結建立卡片連結。心智圖、表格、圖表、圖片、影片、PDF 拖到卡片上，或拖到心智圖、表格等物件上，維持只建立連結 |
| 畫布上的連線 | 只畫出兩端都在這個白板上的連結；線從卡片邊緣連到另一張卡片的邊緣 |
| 移除連結 | 點連線選取後按 Delete 或線中央的 ×，或在右欄連結清單按 × |
| 連結清單（右欄） | 列出所有連到這張卡片的卡片；卡片在其他白板時顯示白板名稱 |
| 跳到連結的卡片 | 點清單中的卡片：同一個白板就捲動過去並選取；在其他白板就切換過去 |
| 不能連到自己 | 同一張卡片不能連結到自己；重複連結時提示「已經連結了」 |

### 卡片內容
白板卡片、便利貼、側邊面板、Drawer 筆記卡片與版本記錄的內容以 **Banyan Flavored Markdown**（BFM，語法見 `Design/Markdown Language.md`）顯示，由 Banyan 自己寫的 Markdown 引擎（`src/markdown/`）解析。

| 功能 | 說明 |
|---|---|
| 基礎語法 | CommonMark 全部（標題、粗體、斜體、清單、引用、程式碼、連結、圖片、分隔線…）＋ GFM：表格（含對齊）、刪除線 `~~ ~~`、待辦清單 `- [ ]`、網址與電子郵件自動變成連結、腳註 `[^1]` |
| 換行 | 單一換行就是換行（和以前的純文字卡片一樣） |
| 螢光筆 | `==重點==`，可指定顏色 `==重點=={pink}`（黃、綠、藍、粉紅、紫，和 Annotator 的重點相同） |
| 卡片連結 | `[[卡片標題]]` 或 `[[card:42\|顯示文字]]`：點一下開啟那張卡片（白板中在側邊面板開啟；Drawer 筆記卡片切換到 Whiteboard）。找不到時提示。存檔時自動建立雙向卡片連結（見下方「編輯」）。`![[ ]]`（嵌入）目前顯示成連結 |
| 標籤 | `#標籤`、`#讀書/哲學` 顯示為標籤色的文字；純數字（`#2024`）、前面是英數字（`C#`）不算 |
| 數學式 | `$a^2$`、`$$…$$`（獨立一行）或 ````math```` 區塊，KaTeX 顯示；化學式 `\ce{H2O}`。`$5 和 $10` 不會被當成數學式 |
| 提示框 | `> [!note] 標題`（note、tip、info、warning、danger、quote、question、todo、example），`[!tip]-` 預設摺疊、`+` 可摺疊 |
| 註解 | `%% 不顯示的文字 %%`，或用單獨一行的 `%%` 包住多行 |
| 中文 | 粗體、斜體旁邊可以接全形標點（`**「引號」**後面`）；全形的 `＃`、`＊` 只是文字；網址遇到中文或全形標點就結束 |
| 安全 | 原始 HTML 顯示成文字、不執行；只有 http(s)／mailto 連結可以點（用系統瀏覽器開啟）；只載入 http(s) 與 data 圖片 |
| 縮小時的摘要 | 白板縮小時的摘要與右欄卡片清單的預覽去掉 Markdown 符號，只留文字 |

#### 編輯（所見即所得）
點一下內容就在點的位置開始編輯（游標放在原文對應的位置）；離開或按 Esc 結束並自動儲存。編輯時看到的是排好版的樣子，不是符號（ProseMirror，`src/markdown/MarkdownEditor.tsx`）。

| 功能 | 說明 |
|---|---|
| 打字時自動轉換 | `# `～`###### ` 標題、`- ` 清單、`1. ` 編號清單、`> ` 引用、`[ ] `／`[x] ` 待辦、` ``` ` 程式碼區塊、`---` 分隔線；`**粗體**`、`*斜體*`、`~~刪除~~`、`==螢光==`、`` `程式碼` `` 打完結尾符號就變格式。轉換後立刻按 Ctrl＋Z（或 Backspace）變回原本打的字 |
| 快速鍵 | Ctrl＋B 粗體、Ctrl＋I 斜體、Ctrl＋E 程式碼、Ctrl＋Shift＋X 刪除線、Ctrl＋Shift＋H 螢光筆、Ctrl＋Alt＋1～3 標題、Ctrl＋Alt＋0 內文；Shift＋Enter 換行（Enter 是新段落）；清單中 Tab／Shift＋Tab 縮排；Ctrl＋Z／Ctrl＋Y 復原與重做 |
| 清單 | Enter 新增一項（待辦項目新增的是未勾選的待辦）；在空的項目按 Enter 離開清單；在標題或項目開頭按 Backspace 變回內文 |
| 待辦 | 編輯時直接點核取方塊切換 |
| `[[` 卡片建議 | 輸入 `[[` 出現卡片清單（依標題搜尋，顯示所在白板）：↑↓ 選擇、Enter 或 Tab 插入 `[[card:id\|標題]]`；沒有符合的卡片時 Enter 插入 `[[打的字]]`；Esc 關閉。直接打完 `[[標題]]` 也會變成連結。編輯中按 Ctrl＋點一下連結開啟 |
| 提示框 | 標題是可以直接輸入的欄位，內容照一般文字編輯 |
| 其他語法 | 表格、數學式、圖片、腳註、HTML、`%% %%`、連結定義等顯示成排好版的樣子（定義與註解顯示原文），**雙擊**編輯原文：區塊用多行文字框（Ctrl＋Enter 或離開時套用、Esc 取消、清空就刪除），行內用單行欄位（Enter 套用） |
| 貼上 | 純文字當成 Markdown 解析；網頁或 Word 的內容保留標題、清單、粗斜體、刪除線、螢光、連結與程式碼 |
| 複製 | 複製出去的文字是 Markdown |
| 原文保留 | 存檔時，沒有改過的段落、清單、表格**一字不差**地寫回（原本的符號寫法、空行都不變），只有改過的部分重新產生；打出看起來像語法的字（`# `、`1. `、`*`、`[[`、`$5 和 $10`…）會自動加上跳脫，存回去仍是文字 |
| 連結同步 | 存檔後，內容中的 `[[標題]]`／`[[card:id]]` 自動建立雙向卡片連結（指向被提到的卡片），白板上立刻畫出新連線並提示；之前就寫了 `[[這張卡片的標題]]` 的其他卡片也會在這張卡片存檔時連上。從內容刪掉 `[[ ]]` 不會刪除連結（連結也可能是手動拉的） |

- 卡片之間的連結也可以用拖曳建立（見「卡片連結」）；引用 Drawer 條目或註解，把它從右欄拖到卡片上（見「右欄」）。
- 顯示時（不在編輯）待辦的核取方塊不能點，點一下會進入編輯。

### 引用文獻（BibTeX 式引用鍵）
卡片內容中用 Pandoc 的引用語法引用 Drawer 的條目與註解（引用鍵見 Drawer「引用鍵與 BibTeX」）。

| 寫法 | 顯示 |
|---|---|
| `[@kahneman2011]`、`[@kahneman2011, 33]`、`[見 @a2020; @b2021]`、`[-@a2020]` | APA 格式：（Kahneman, 2011, p. 33）、（見 A, 2020; B, 2021）、（2020）；兩位作者用 &、三位以上 et al.；中日韓作者用全名與全形標點（王小明，2020，頁 12）；純數字的位置自動加 p.／頁 |
| `@kahneman2011 指出` | 敘述式：Kahneman (2011)、王小明（2020）。中文後面直接寫 `@王2020` 也可以；前面是英數字（e-mail）不算；不存在的鍵照原樣顯示成文字 |
| `[@kahneman2011:h3]` | 引用一段重點：顯示所屬文獻，頁碼自動用重點的位置 |
| `[[@kahneman2011]]` | 連結，顯示條目標題（類型圖示）；註解顯示引文開頭 |
| `![[@kahneman2011]]` | 條目卡片（圖示、標題、作者、年份）；註解顯示成帶顏色的引文、筆記與出處 |
| `::bibliography` | 單獨一行：產生這份內容引用的所有文獻（依作者、年份排序，APA 格式） |
| ````bibtex```` 區塊 | 文件內的書目：還沒放進 Drawer 的文獻也能引用（同名時用文件內的資料）；顯示成條目清單，「加入文獻庫」一鍵匯入 |

- 滑鼠停在引用上顯示完整書目（註解另顯示引文）；點一下在 Drawer 開啟條目，或在 Annotator 跳到那段重點。找不到的鍵以紅字「找不到 @鍵」顯示。
- 編輯時輸入 `@`（或 `[@`）出現文獻與註解的建議清單（依引用鍵、標題、作者、引文搜尋），選擇後插入 `[@鍵]`；編輯器中的引用也顯示成 APA 格式。打字輸入、不是引用的 `@字` 存檔時自動跳脫（e-mail 不受影響）。
- 存檔後，卡片自動「引用」內容中 `[@…]`、`[[@…]]` 提到的條目與註解（出現在「引用的文獻」「引用的註解」）；從內容刪掉不會取消引用。

### 引用 Drawer 條目
| 功能 | 說明 |
|---|---|
| 卡片上的標籤 | 卡片引用的條目顯示在卡片底部（類型圖示＋標題），滑鼠停留顯示作者與年份；點一下切換到 Drawer 並選取該條目 |
| 摺疊引用 | 卡片底部的引用平時摺成一行「▸ 引用 N 筆文獻 · N 則註解」，點一下展開成標籤（▾ 再點收起）；展開與否每張卡片各自記住（App 開著期間） |
| 右欄與側邊面板的引用 | 右欄下半部（選取的卡片）與側邊面板的「引用的文獻」「引用的註解」預設摺疊，只顯示標題與數量；點標題（▸／▾）展開或收起。「連結」也可以摺疊（預設展開）。兩處共用同一組設定，記在 `localStorage` 的 `banyan.wb.foldSections`，下次開啟時保留 |
| 引用條目 | 從右欄「📚 文獻」把條目拖到卡片上；拖到空白處則建立引用它的新筆記卡片 |
| 取消引用 | 右欄下半部「引用的文獻」清單的 × |
| 雙向 | 條目的詳情欄「筆記卡片」會列出所有引用它的卡片 |
| 放上已有卡片 | 從右欄「🗒 卡片」把卡片（例如在 Drawer 寫的筆記）拖到白板空白處（取代原本標題列的「＋ 已有卡片」） |

### 引用註解
卡片可以引用 Annotator 的註解（PDF、電子書中的重點與書籤），用法和引用條目相同。

| 功能 | 說明 |
|---|---|
| 註解分頁 | 右欄的「🖍 註解」和 Annotator 右欄的註解清單**用同一套元件**，外觀與操作相同：所有檔案的註解（最新的在前，一次最多顯示 200 則，其餘用搜尋或篩選縮小範圍），每則有顏色色條、位置與日期、出處（條目標題）、引文、筆記、「N 張卡片引用」（點一下展開卡片清單）。上方搜尋框比對引文、筆記、位置、檔名與條目標題；全部／重點／書籤與 5 個顏色的篩選顯示數量，沒有符合時可「清除篩選」。點引文切換到 Annotator 並跳到原文；點筆記直接編輯（沒有筆記時滑鼠停留出現「＋ 筆記」）；滑鼠停留時右上角出現「建立／開啟卡片」（在側邊面板開啟）與「刪除」（可復原，被卡片引用的先確認） |
| 引用 | 按住註解（引文或空白處，不含按鈕與筆記）拖到卡片上。**重點拖到文字卡片（卡片、便利貼）上**時，引文直接以文字加在卡片最後：引用區塊＋行尾的 `[@引用鍵:hN]`（顯示成 APA 文中引用），有筆記時筆記接在下面；存檔時依引用鍵記為卡片引用的註解（還沒有引用鍵時直接記錄）。書籤、或拖到心智圖／表格等物件上，維持原本只記錄引用（同一張卡片重複引用時提示「已經引用了這段註解」）；拖到空白處放上這段註解的卡片 |
| 卡片上的標籤 | 引用的註解顯示在卡片底部的引用列（和條目並列；平時摺疊，見下一列），以重點的顏色標示、顯示引文開頭（書籤顯示「書籤：位置」）；滑鼠停留顯示完整引文、出處與筆記；點一下切換到 Annotator 並跳到原文 |
| 側邊面板 | 「引用的註解」區塊列出引文與出處，點一下回到原文 |
| 取消引用 | 右欄下半部「引用的註解」清單的 × |
| 雙向 | Annotator 中每則註解顯示被幾張卡片引用，可以展開並打開那些卡片 |
| 卡片庫 | 卡片庫中的卡片也顯示引用的註解 |

### 資料
- 卡片與白板分開存放（`cards`、`board_cards`），同一張卡片可以出現在多個白板上。
- 區塊存在 `board_sections`（每個白板各自的區塊），卡片標籤存在 `card_tags`（不分大小寫，和 Drawer 條目的標籤分開）；資料庫 v9。
- 連結存在 `card_links`，每對卡片只存一筆（id 小的在前），兩邊都能查到；`direction`（0 無、1 前→後、2 後→前、3 雙向）和 `note` 記錄方向與備註。
- 資料夾存在 `whiteboard_folders`（`parent_id` 巢狀），白板的 `folder_id` 指向所在資料夾（資料庫 v7）。
- 刪除白板時，只刪除**不在其他白板上**的卡片。
- 卡片的版本記錄存在 `card_versions`（資料庫 v11，見「Version Machine」）。
- `board_cards.collapsed`、`board_cards.auto_height`（資料庫 v19）：卡片在這個白板上是否摺疊、高度是否隨內容；指令 `set_card_display`（`null` 表示不變）。摺疊時 `height` 仍是展開後的高度。
- 物件類型（資料庫 v12）：`cards.kind`（`note`、`sticky`、`image`、`video`、`pdf`、`mindmap`、`table`）與 `cards.data`（該類型的 JSON：便利貼顏色、圖片檔名與原始大小、YouTube 影片 id 與開始時間、PDF 檔名／頁數／目前頁、心智圖的樹、表格的欄列與儲存格原始內容）。心智圖另把大綱（巢狀清單）、表格另把顯示的值（以 Tab 分隔的文字）寫進 `content`，所以可以搜尋、在版本記錄中比較。表格加入時不需要升級資料庫。類型清單在 `src/whiteboard/objects.ts` 與 `src-tauri/src/whiteboard.rs` 的 `CARD_KINDS`，兩處需一致。
- 圖片與 PDF 檔案複製到資料庫的 `storage/cards/<卡片 id>/`（單檔最多 200 MB），隨卡片一起刪除（完全刪除卡片、或刪除白板時刪掉只在那個白板上的卡片）；從白板移除不會刪除檔案。

### 已知限制
- 右欄清單一次只能拖一個項目；卡片清單最多顯示 50 張、文獻最多 100 筆，其餘需要搜尋。
- 自動完成的清單在打字後約 0.1 秒才更新，打得很快時按 Enter 可能變成換行。
- 白板操作（移動、刪除、連結、區塊）沒有復原（Undo），復原只在卡片內容編輯器中有效。
- Markdown 編輯器：同一種強調套兩層（`*a *b**`）、setext 標題中的換行、沒有文字的連結，在重新產生時會簡化；還沒有 `/` 選單、浮動格式工具列、區塊把手拖曳；引用鍵 `[[@…]]`／`[@…]` 還不能點，`![[ ]]` 不會真的嵌入；屬性 `{…}`、指令、分欄、圖表編號、文獻引用等進階排版尚未實作；`[[ ]]` 寫在程式碼裡也會建立連結。
- 引用文獻：只有 APA 格式（還不能選 Chicago、MLA、GB/T 7714 等）；參考文獻清單只在寫了 `::bibliography` 的地方出現；匯出 .bib 沒有「鍵轉成拼音」選項；文件屬性 `bibliography: 檔名.bib` 尚未支援；圖表編號 `[@fig:…]` 尚未實作（目前當成一般引用鍵）；存檔後新增的卡片引用要重新開啟白板才會出現在卡片底部；手動改引用鍵時正在編輯中的卡片仍是舊內容，存檔會寫回舊鍵（請先結束編輯）。
- 用中文輸入法時，打字時自動轉換在選字送出後才判斷（例如用輸入法打出的 `＊＊` 是全形，不會變粗體）。
- 區塊不能互相包含（巢狀）；區塊的成員是「完全在區塊裡的卡片」，移動時才計算，沒有另外記錄。
- 多選只能選卡片，不能同時選取區塊或連線；多張卡片還不能一次調整大小或一次建立連結。
- 卡片標籤和 Drawer 條目的標籤是兩套。
- 卡片庫一次最多顯示 1000 張。
- 畫布的位置與縮放不會記住，每次開啟白板都會自動縮放到全部卡片。
- 一個白板只能放在一個資料夾裡。
- 物件類型：心智圖的主題不能用拖曳改變上層（只能 Alt＋↑／↓ 在同層排序）、沒有自訂顏色與樣式；縮小到概覽時心智圖不會放大字級。影片只支援 YouTube（播放需要網路；在 App 視窗中能否播放尚未確認）。PDF 不能選取文字、搜尋內文或加註解。圖片與 PDF 會整個讀進記憶體，很大的檔案會比較慢。Drawer 的附件還不能直接拖到白板成為圖片／PDF 物件。圖表：沒有組合圖、堆疊圖、散佈圖、座標軸標題與數值標籤，不能自訂顏色；只能用同一個白板上的表格當來源（不能跨白板），沒有表格的圖表無法直接輸入數字。表格：沒有合併儲存格、排序／篩選、數字格式（貨幣、日期、小數位數）、儲存格顏色與框線、文字換行、自訂列高、凍結窗格、多個工作表；公式只認 A1 位址，不能用結構化參照（`表格[欄]`）或跨表格參照，沒有自動完成函數名稱；填滿控點只能往下或往右，不能拖出表格範圍；欄列不能拖曳排序。
- 只在瀏覽器中以模擬後端測試過，尚未在真實視窗中操作。

## Version Machine（版本記錄）

參考 Google 文件的「版本記錄」。目前記錄**卡片**（白板卡片與 Drawer 的筆記卡片）的標題與內容，不需要手動存檔。

### 自動儲存
| 功能 | 說明 |
|---|---|
| 自動儲存 | 編輯卡片（白板上、側邊面板、Drawer 筆記卡片）時，停止輸入約 1.5 秒就自動存檔，不必離開欄位；關閉面板或切換卡片時也會先存 |
| 儲存狀態 | 側邊面板上方顯示「儲存中…」／「已儲存」 |

### 版本記錄頁面
在側邊面板按「🕘 版本記錄」開啟，蓋住整個視窗：左邊是版本的內容，右邊是版本清單。按 ← 或 Esc 回到卡片。

| 功能 | 說明 |
|---|---|
| 自動記錄版本 | 每次自動儲存都會記錄；距離上一個自動版本 10 分鐘內的修改併入同一個版本，所以一段連續編輯只留一個版本 |
| 第一次記錄 | 還沒有版本的卡片（例如升級前就有的卡片）在第一次修改時，先把修改前的內容存成一個版本 |
| 版本清單 | 依日期分組（今天、昨天、11月9日…），最新的在最上面；有名稱的版本以粗體顯示名稱、下方是時間；最新的版本標示「目前版本」；↑ / ↓ 切換 |
| 顯示變更 | 預設開啟：和清單中下一個（較舊的）版本比較，在文件中直接標示，新增的文字以綠底、刪除的文字以紅色刪除線顯示（逐字比較，中文以字為單位）；沒變的段落照常排版，有變動的段落以原始文字顯示；標題的變動也會標示。最早的版本以一般文件顯示。上方顯示新增／刪除的字數 |
| 只顯示已命名的版本 | 清單只列出有名稱的版本（加上目前版本），比較的對象也改為上一個已命名的版本 |
| 為版本命名 | 版本右側的 ⋮ →「為這個版本命名」／「重新命名」，在清單中直接輸入（Enter 確定、Esc 取消）；命名版本之後的修改一定會成為新的版本，命名版本不會被自動刪除；清空名稱會改回自動版本 |
| 還原 | 上方的「還原此版本」或 ⋮ →「還原此版本」，把卡片的標題和內容改回該版本（會先確認）；還原本身記錄為新的版本，原本的內容仍在清單中，可以再還原回來；還原後依 `[[ ]]` 建立連結 |
| 刪除版本 | ⋮ →「刪除此版本」（會先確認）；目前版本不能刪除 |
| 刪除卡片 | 卡片的版本記錄一併刪除 |

### 資料
- `card_versions`（資料庫 v11）：每列是卡片的一個狀態（標題、內容、名稱、建立與最後併入時間）；`name` 為空的是自動版本。資料庫 v12 起也保存 `data`（例如心智圖的樹、PDF 目前頁），還原時一起還原；比較時顯示的是心智圖的大綱。
- 每張卡片最多保留 100 個自動版本，超過時刪除最舊的自動版本；命名版本不受限制。

### 已知限制
- 只記錄卡片的標題與內容；標籤、連結、引用的文獻、白板上的位置，以及 Drawer 條目的欄位都沒有版本記錄。
- 以空行分段比較；同一段內只要有改動，整段以逐字差異顯示。
- 只能和前一個版本比較，不能任選兩個版本比較。
- 自動儲存只在 App 開著時有效；輸入後 1.5 秒內直接關閉整個視窗，最後幾個字可能沒有存到。
- 被刪除的卡片無法從版本記錄救回（版本會跟著刪除）。
- 版本清單只在開啟時讀取；面板開著時在白板上修改同一張卡片，需重新開啟版本記錄才會看到。
- 只在瀏覽器中以模擬後端測試過畫面，尚未在真實視窗中操作。
