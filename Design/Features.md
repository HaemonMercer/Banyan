## Drawer（收藏庫）

參考 Zotero。介面分三欄：左欄資料夾與標籤、中欄條目清單、右欄條目詳情。可收藏文獻，也可收藏影音、藝術品等資料。

### 資料夾（左欄）
左欄分為「資料夾」與「標籤」兩個區塊；點區塊標題（▾ / ▸）可摺疊，標題旁顯示數量。摺疊狀態會記住。

| 功能 | 說明 |
|---|---|
| 我的文獻庫 | 顯示所有條目 |
| 未分類 | 顯示不屬於任何資料夾的條目 |
| 新增資料夾 | 「資料夾」標題右側的 ＋；可建立在最上層，或建立為子資料夾（可多層巢狀） |
| 重新命名 | 雙擊資料夾名稱 |
| 刪除資料夾 | 子資料夾一併刪除；裡面的條目**保留**在文獻庫 |
| 完整路徑 | 滑鼠停在資料夾上顯示完整路徑，例如 `資料夾/資料夾01` |
| ⚙ 資料庫位置 | 在左欄底部，用來選擇資料存放位置（見「資料庫位置」） |

### 標籤（左欄）
用法和資料夾相同，列在資料夾下方。

| 功能 | 說明 |
|---|---|
| 標籤清單 | 依名稱排序，右側顯示使用該標籤的條目數 |
| 依標籤檢視 | 點標籤，中欄只顯示有這個標籤的條目（可再搜尋）；清單標題為「標籤：名稱」 |
| 新增條目 | 在標籤檢視中新增的條目會自動加上該標籤 |
| 重新命名 | 雙擊標籤或按 ✎；若改成已存在的標籤名稱（不分大小寫），兩個標籤會**合併** |
| 刪除標籤 | 按 🗑（會先確認）；標籤從所有條目上移除，條目本身不受影響 |
| 拖曳條目到標籤 | 條目加上該標籤；拖曳中目標標籤會高亮，游標旁顯示「加上標籤「X」」 |
| 建立標籤 | 在右欄為條目加上標籤；沒有任何條目使用的標籤會自動消失 |

### 條目清單（中欄）
| 功能 | 說明 |
|---|---|
| 新增條目 | 「＋ 新條目」選單依分類列出條目類型；新條目會自動放進目前所在的資料夾 |
| 搜尋 | 比對標題、所有作者與其他身分的姓名、標籤、摘要、筆記卡片的標題與內容、附件檔名，以及長度、媒介、尺寸、地點、編號等欄位 |
| 清單標題 | 顯示目前檢視的位置；在子資料夾中顯示完整路徑，例如 `資料夾/資料夾01` |
| 清單欄位 | 類型圖示、標題、作者（多位時顯示「第一位 等」；該類型的主要身分排在前面，例如書籍先列作者、再列譯者）、年份、附件數 |
| 摺疊顯示附件 | 有附件的條目前方有 ▸，點開後以縮排列出附件（檔名、大小；連結檔案顯示 🔗 與「連結」標籤）；雙擊附件列即開啟；新增或刪除附件後自動更新 |
| 全部展開 / 收合 | 點標題列的 ▸ / ▾ |
| 鍵盤操作 | ↑ / ↓ 切換選取（Shift＋↑ / ↓ 擴大選取範圍）；Ctrl＋A 全選；Esc 只保留一個；→ / ← 展開或收合選取條目的附件；+ / − 全部展開或收合；Delete 刪除選取的條目（會先確認） |

### 多選與框選
| 操作 | 結果 |
|---|---|
| 點一下 | 只選這個條目 |
| Ctrl＋點 | 加入或取消選取這個條目 |
| Shift＋點 | 選取從上一個點選的條目到這裡的範圍（Ctrl＋Shift＋點則加到原本的選取） |
| 框選 | 從條目的作者、日期、附件欄，或清單下方的空白處按住拖曳，畫出選取框；框到的條目被選取（按住 Ctrl 則加到原本的選取）；拖到清單上下邊緣會自動捲動 |
| 點空白處 | 取消選取 |
| 拖曳標題 | 拖曳到資料夾、標籤或右欄的「關聯」（見下方）；拖曳已選取的條目時，所有選取的條目一起拖；拖曳沒有選取的條目時，選取與右欄保持不變 |

選取多個條目時，清單標題顯示「已選 N / 全部」，最後點選的條目左側有一條色線。

### 大量編輯（右欄）
選取兩個以上的條目時，右欄改為「大量編輯」，所有變更套用到每個選取的條目：

| 區塊 | 功能 |
|---|---|
| 上方 | 列出選取的條目（最多 6 個，其餘顯示「還有 N 個」）；「取消多選」、「刪除 N 個」 |
| 標籤 | 顯示選取的條目已有的標籤與比例（例如「1/4」、「全部」）；按 × 從全部移除；輸入名稱按 Enter 為全部加上 |
| 資料夾 | 顯示所在的資料夾與比例；按 × 全部移出；「全部加入資料夾…」 |
| 類型 | 顯示各類型的數量；「全部改為…」（會先確認，欄位內容保留） |
| 設定欄位 | 選擇欄位（日期、出版社、出處、網址、摘要等）並輸入值，「套用」後取代全部的內容；留空則清空（會先確認） |
| 加入人員 | 選擇身分並輸入姓名，加到每個條目的人員清單最後；已有同身分同姓名的條目會略過 |
| 關聯 | 「讓這 N 個條目互相關聯」：選取的條目兩兩建立關聯；已有的關聯略過 |

各區塊可摺疊，摺疊狀態會記住。

### 拖曳到資料夾或標籤
| 操作 | 結果 |
|---|---|
| 拖到資料夾後放開 | **加入**該資料夾，保留原本所屬的其他資料夾 |
| 拖到標籤後放開 | 條目**加上**該標籤 |
| 按住 Shift 再放開 | **移動**：從目前檢視的資料夾移出，加入目標資料夾（在「我的文獻庫」或「未分類」中則等同加入） |
| 多個條目 | 拖曳已選取的條目時，所有選取的條目一起加入、移動或加上標籤；游標旁顯示「N 個條目」 |
| 拖曳中 | 游標旁顯示「加入「X」」或「移到「X」」（X 為資料夾完整路徑）；目標資料夾會高亮；停在收合的資料夾上約 0.7 秒會自動展開 |
| 取消 | 按 Esc，或在資料夾和標籤以外的地方放開 |
| 完成後 | 顯示短暫提示，例如「已加入「音樂」」、「已經在「音樂」裡了」 |

### 作者與身分
一個條目可以有多位人員，每位都有自己的身分，例如作者、譯者、編者。

| 功能 | 說明 |
|---|---|
| 每一列 | 左邊是身分下拉選單，右邊是姓名 |
| 新增 | 按「＋ 新增作者或其他身分」，或在姓名欄按 Enter 在下方新增一列 |
| 排序 | 滑鼠停在該列時出現 ↑ / ↓，可調整順序 |

### 條目詳情（右欄）
標題固定顯示在最上方；其餘分為「資料」（作者與身分、各欄位、摘要）、「筆記卡片」、「標籤」、「資料夾」、「附件」、「關聯」六個區塊，點區塊標題（▾ / ▸）可各自摺疊，標題旁顯示數量。上方「全部收合／全部展開」一次切換所有區塊。摺疊狀態對所有條目共用，並在下次開啟時保留。在摺疊的區塊按「＋ 新增」、「加入檔案」等按鈕時，該區塊會自動展開。

| 功能 | 說明 |
|---|---|
| 類型 | 下拉選單依分類列出，可隨時更改 |
| 編輯欄位 | 依條目類型顯示欄位與名稱；欄位失去焦點時自動儲存 |
| 作者與身分 | 多位人員，各有身分（見「作者與身分」） |
| 標籤 | 新增、移除；標籤名稱不分大小寫；所有標籤也列在左欄（見「標籤（左欄）」） |
| 所屬資料夾 | 以完整路徑列出條目所在的資料夾（例如 `資料夾/資料夾01`），按 × 從該資料夾移出；用「＋ 加入資料夾…」下拉選單加入其他資料夾。一個條目可以屬於多個資料夾 |
| 筆記卡片 | 見下方「筆記卡片」 |
| 關聯 | 見下方「關聯」 |

### 筆記卡片（參考 Heptabase）
條目不再有自己的筆記欄位。筆記是**卡片**，卡片引用條目；同一張卡片可以引用多個條目，也可以放到白板上和其他卡片連結。

| 功能 | 說明 |
|---|---|
| 清單 | 只顯示每張筆記卡片的名稱（🗒 標題）；滑鼠停留顯示內容開頭；在白板上的卡片右側有 🧩，點一下到白板中開啟 |
| 展開編輯 | 點卡片名稱展開，可編輯標題與內容（離開欄位時自動儲存），並使用下方的白板與取消連結功能；按「收合」回到只顯示名稱。一次只展開一張 |
| Markdown | 展開後內容是所見即所得的 Markdown 編輯器（和白板卡片相同，見 Whiteboard「卡片內容的 Markdown」）：點一下就在該位置編輯，離開或 Esc 結束並儲存。點 `[[卡片標題]]` 切換到 Whiteboard 並開啟該卡片；卡片不在任何白板上或找不到時提示 |
| 新增 | 詳情欄「筆記卡片」按「＋ 新增」：建立標題為「筆記：條目標題」的卡片，直接展開並聚焦內容 |
| 連結已有卡片 | 搜尋所有卡片（標題或內容），點一下讓它引用這個條目 |
| 放到白板 | 不在白板上的卡片有「🧩 放到白板…」選單，放在該白板現有卡片的右側 |
| 在白板中開啟 | 已在白板上的卡片顯示白板名稱，點一下切換到 Whiteboard 並選取、捲動到這張卡片 |
| 取消連結 | 只取消卡片和條目的關係，卡片本身保留 |
| 刪除條目時 | 只屬於這個條目、且不在任何白板上的筆記卡片一併刪除；放在白板上或也引用其他條目的卡片保留 |
| 舊筆記 | 升級到資料庫 v6 時，每個條目原本的筆記自動轉成一張「筆記：條目標題」的卡片並引用該條目 |

### 關聯（參考 Zotero 的「相關」）
兩個條目之間的關聯，例如論文和它的補充資料、同一部作品的書與電影版。關聯一定是**雙向**的：A 關聯到 B，B 的「關聯」區也會列出 A。

| 功能 | 說明 |
|---|---|
| 清單 | 類型圖示、標題、作者與年份，依標題排序；滑鼠停留顯示完整標題 |
| 前往 | 點一下選取那個條目；它不在目前的清單中時，切換到「我的文獻庫」並清除搜尋，清單會捲動到該條目 |
| 新增 | 按「＋ 新增」，搜尋標題或作者，點結果加入（可連續加入多個，已關聯的顯示「已關聯」）；按「完成」或 Esc 結束 |
| 拖曳加入 | 把中欄清單的條目拖到右欄的「關聯」區塊放開（區塊會高亮，游標旁顯示「加入關聯」）；可一次拖多個已選取的條目 |
| 移除 | 滑鼠停在該列時出現 ×；兩邊的關聯一起移除，條目本身不受影響 |
| 多個條目 | 大量編輯的「關聯」區可讓選取的條目互相關聯 |
| 刪除條目時 | 它的關聯一併移除 |
| 修改時間 | 新增或移除關聯時，兩個條目都算修改過 |

### 附件
| 功能 | 說明 |
|---|---|
| 加入附件 | 用按鈕選擇檔案，或把檔案拖進視窗 |
| 5 GB 以下 | 檔案**複製**到資料庫的 `storage` 資料夾；檔名重複時自動改為 `檔名 (2).pdf` |
| 超過 5 GB | **不複製**，只記錄原始檔案的完整路徑（連結檔案）；會提示「請勿移動或刪除原始檔案」 |
| 連結檔案的顯示 | 🔗 圖示、「連結」標籤、斜體；滑鼠停留顯示完整路徑 |
| 開啟 / 位置 | 用系統預設程式開啟，或在檔案總管中顯示；連結檔案若已被移動、刪除或磁碟未連接，會顯示錯誤訊息 |
| 刪除附件 | 複製的附件：連同檔案一起刪除。連結檔案：按鈕變為「移除」，只刪除紀錄，**不會刪除原始檔案** |
| 刪除條目時 | 複製的附件檔案一併刪除；連結檔案的原始檔案不受影響（筆記卡片見「筆記卡片」） |
| 檔案大小 | 依大小顯示 B、KB、MB、GB |

連結門檻定義在 `src-tauri/src/drawer.rs` 的 `LINK_THRESHOLD`。

### 資料庫位置
資料庫由 `banyan.db` 和附件資料夾 `storage` 組成，兩者一起搬移。點「⚙ 資料庫位置」選擇資料夾後：

| 選擇的資料夾 | 可用選項 |
|---|---|
| 還沒有資料庫 | **把目前的資料庫搬到這裡**：複製資料庫與所有附件並改用新位置，原本的資料保留，需自行刪除<br>**在這裡建立新的空資料庫** |
| 已經有資料庫 | **開啟這個資料庫**：切換過去，之後可以切回來 |

- 其他選項：「在檔案總管中開啟」、「改回預設位置」。
- 切換後立即生效，不需重新啟動。
- 選擇的位置存在 `%APPDATA%\banyan\config.json`，下次啟動沿用。
- 啟動時若找不到設定的資料夾（例如 Dropbox 或外接硬碟未連接），改用預設位置並顯示警告，不會在原處建立空的資料庫。
- 拒絕的資料夾：附件資料夾內的資料夾、已有資料庫的資料夾（搬移時）、已有自己 `storage` 資料夾的資料夾。
- 搬移在背景執行，視窗不會卡住；中途失敗會刪除未完成的複本，原資料庫不受影響。

### 資料儲存
- 預設位置：`%APPDATA%\banyan\`（可用「資料庫位置」更改）
- 資料庫：`banyan.db`（SQLite，WAL 模式，結構版本 8；舊版資料庫在啟動時自動升級）
- 附件：`storage\<條目 id>\`
- 資料表：`collections`、`items`、`item_creators`（作者與身分）、`item_collections`、`tags`、`item_tags`、`attachments`、`item_relations`（關聯，每組只存一筆，`item_a < item_b`）；Whiteboard 使用 `whiteboards`、`cards`、`board_cards`、`card_links`、`card_items`（卡片引用的條目）（同一個資料庫，搬移資料庫位置時一起搬）
- `items.authors` 保留為清單顯示與搜尋用的摘要（每行一位，主要身分在前），由程式自動維護

### 已知限制
- 附件一次只能加到一個條目；選取多個條目時把檔案拖進視窗會提示只選一個。
- 大量編輯無法一次修改標題，也不能復原（「設定欄位」與「刪除」會先確認）。
- 無法直接在左欄建立還沒有條目使用的空白標籤。
- 關聯依標題的字碼排序，中文標題不是依筆畫或注音排列。
- 沒有垃圾桶，刪除為永久刪除。
- 姓名只有一個欄位，沒有分開姓與名。
- 附件列只能雙擊開啟；要刪除或在檔案總管中顯示附件，仍需到右欄的「附件」區操作。
- 尚未在真實視窗中驗證：選擇檔案、開啟附件、拖放檔案加入附件、拖曳條目到資料夾、實際搬移或切換資料庫、實際加入 5 GB 以上的檔案、清單中摺疊顯示附件、左欄標籤與右欄區塊摺疊、多選／框選與大量編輯、關聯（新增、拖曳加入、前往、移除）。（以上流程已用模擬後端在瀏覽器中測試過。）

## 檢查更新（手動）

左側直欄最下方的「更新」按鈕。只有按下時才檢查，不會在背景自動檢查或下載。

| 狀態 | 畫面 |
|---|---|
| 檢查中 | 顯示目前版本與「正在檢查是否有新版本…」 |
| 已是最新 | 「已經是最新版本」，可再檢查一次 |
| 有新版本 | 顯示新版本號、發布日期與更新說明；「稍後」或「下載並安裝」 |
| 下載中 | 進度條與已下載／總大小；下載中不能關閉對話框 |
| 安裝完成 | 「立即重新啟動」或「稍後重新啟動」（Windows 上安裝程式會自行關閉 App） |
| 錯誤 | 中文說明（找不到 latest.json、無法連線、簽章不符），「詳細資訊」可展開原始錯誤 |
| 尚未設定來源 | 更新網址仍是 `OWNER/REPO` 佔位時，直接提示要改哪裡，不送出請求 |

**技術細節**
- 使用 `tauri-plugin-updater`（只在桌面版啟用）與 `tauri-plugin-process`（重新啟動）。
- 更新來源：`src-tauri/tauri.conf.json` 的 `plugins.updater.endpoints`，目前是 `https://github.com/HaemonMercer/Banyan/releases/latest/download/latest.json`（repository 已存在，但還沒有發布任何 Release，所以檢查時會顯示「找不到更新資訊」）。
- 更新檔必須簽章：公鑰在 `tauri.conf.json`，私鑰在 `%USERPROFILE%\.tauri\banyan.key`（沒有密碼，不在專案中；遺失就無法再發布能被舊版接受的更新）。
- Windows 以 `passive` 模式安裝（顯示進度、不需操作）。
- 發布流程：設定 `TAURI_SIGNING_PRIVATE_KEY` 後 `npm run tauri build`，再執行 `node scripts/make-latest-json.mjs HaemonMercer/Banyan "更新說明"` 產生 `latest.json`，把安裝檔和 `latest.json` 上傳到 `v<版本>` 的 GitHub Release。腳本目前只處理 Windows NSIS 安裝檔。

## Whiteboard（白板）

參考 Heptabase。有**卡片**、**卡片之間的連結**（雙向可見，可加箭頭與備註）、**區塊**、**多選**、**側邊面板開啟卡片**、**卡片標籤**、**卡片庫**和**資料夾**。卡片與連結的整體關係在獨立的 Graph 模組中查看（見「Graph（關係圖）」）。介面分三欄：左欄卡片庫、資料夾與白板，中間畫布或卡片庫（開啟卡片時右側滑出側邊面板），右欄（上半部是可拖曳的「卡片／文獻」清單，下半部是選取卡片的連結與引用的文獻）。

### 資料夾與白板（左欄）
白板可以放進資料夾，資料夾可以多層巢狀（和 Drawer 的資料夾類似，但一個白板只屬於一個資料夾）。

| 功能 | 說明 |
|---|---|
| 新增 | 標題列的 ＋ 選單：「🧩 新白板」（放在最上層）或「📁 新資料夾」；滑鼠停在資料夾上：🧩 在裡面新增白板、＋ 新增子資料夾 |
| 開合資料夾 | 點資料夾；開合狀態會記住。開啟某個白板時，它所在的資料夾會自動展開 |
| 重新命名 | 雙擊名稱，或滑鼠停留時按 ✎；新白板建立後直接進入重新命名 |
| 移動 | 把白板或資料夾拖到另一個資料夾上；拖到標題列「白板」移到最上層。拖曳時游標旁顯示「移到「研究/論文」」，停在收合的資料夾上約 0.7 秒會展開；不能把資料夾移到它自己或子資料夾裡；Esc 取消 |
| 刪除資料夾 | 子資料夾一併刪除；裡面的白板**保留**，移到最上層（會先確認） |
| 刪除白板 | 滑鼠停在白板上按 🗑；上面的卡片和它們的連結一併刪除（會先確認） |
| 卡片數 | 白板名稱右側顯示卡片數量；滑鼠停留顯示完整路徑 |

### 畫布
| 操作 | 說明 |
|---|---|
| 新增卡片 | 在空白處雙擊，或按「＋ 新卡片」（放在畫面中央）；新卡片會自動聚焦標題 |
| 卡片顯示大致內容 | 平時卡片只顯示放得下的內容（字級略小、程式碼與圖片限制高度），不會出現捲軸；放不下時底部淡出並顯示「⋯」。點內容進入編輯時才看得到全部 |
| 縮小時的概覽 | 縮放到 55% 以下時，卡片改為概覽：標題放大加粗、內容換成約 90 字的純文字摘要（最多 3 行，各段以「·」分隔，`[[ ]]` 顯示為連結文字），隱藏引用的文獻標籤；字級隨縮放調整，縮得很小時仍看得清楚 |
| 編輯卡片 | 直接在卡片上輸入標題；內容是所見即所得的 Markdown 編輯器：點一下內容就在點的位置開始編輯（在標題按 Enter 則從結尾開始），畫面和閱讀時一樣；離開或按 Esc 結束編輯並自動儲存（見「卡片內容的 Markdown」） |
| 移動卡片 | 拖曳卡片頂端的把手列；選取多張時拖曳其中一張的把手會一起移動 |
| 框選 | 在空白處（或區塊內的空白處）拖曳出選取框，碰到的卡片都會被選取；按住 Shift 框選會加入原本的選取 |
| 多選 | Shift＋點卡片加入或移出選取；Ctrl＋A 選取白板上全部卡片 |
| 開啟卡片 | 卡片頂端的 ↗、選取一張卡片後按 Enter，或點右欄清單中的卡片，在側邊面板開啟（見「側邊面板」）；開啟中的卡片在白板上以虛線框標示 |
| 調整大小 | 拖曳卡片右下角（最小 120 × 60） |
| 刪除卡片 | 卡片右上角的 ×、右欄的「刪除卡片」、側邊面板的「刪除」，或選取卡片後按 Delete（多選時一次刪除全部）；它們的連結一併移除（會先確認） |
| 平移 | 按住空白鍵拖曳、按住滑鼠中鍵拖曳，或用滾輪／觸控板捲動（拖曳空白處現在是框選，和 Heptabase 相同） |
| 縮放 | Ctrl＋滾輪（以游標為中心），或右下角的 − / ＋；點百分比回到 100%；⤢ 顯示全部卡片（20% ~ 250%） |
| 開啟白板時 | 自動縮放到能看見所有卡片 |
| Esc | 取消選取；沒有選取時關閉側邊面板 |

### 區塊（Section）
白板上有名稱與顏色的區域，用來把卡片分組（參考 Heptabase 的 Section）。

| 功能 | 說明 |
|---|---|
| 新增 | 標題列的「▭ 區塊」：有選取卡片時，建立剛好包住它們的區塊；沒有選取時放在畫面中央。建立後直接輸入名稱 |

| 顏色 | 滑鼠停在區塊上時，標題列右側有 6 個色點（預設、藍、綠、黃、紅、紫） |

| 排列順序 | 區塊畫在連線與卡片的下方；區塊內的空白處可以框選、雙擊新增卡片 |

### 側邊面板（開啟卡片）
在畫布或卡片庫右側滑出，顯示整張卡片（參考 Heptabase 的開啟卡片）。白板上的卡片仍只顯示大致內容。

| 內容 | 說明 |
|---|---|
| 上方 | 卡片所在的白板（點一下到那個白板並定位到卡片；目前白板以綠框標示）、「刪除」、×（關閉，或按 Esc） |
| 標題 | 大字標題，離開欄位時儲存；Enter 跳到內容 |
| 標籤 | 見「標籤」 |
| 內容 | Markdown，點一下以所見即所得編輯器編輯，離開時儲存並依 `[[ ]]` 建立連結 |
| 連結 | 方向符號與備註；點一下在面板中開啟那張卡片 |
| 引用的文獻 | 點一下在 Drawer 中開啟 |
| 時間 | 建立與最後修改時間 |

- 面板中的修改會立即反映到白板上的卡片、右欄清單和卡片庫；在白板上修改後，面板也會重新載入（正在面板中輸入時除外）。

### 標籤
| 功能 | 說明 |
|---|---|
| 加標籤 | 在側邊面板標題下方輸入，Enter 加入（會提示已有的標籤）；開頭的 # 會自動去掉，大小寫不同視為同一個標籤 |

| 多張一起加 | 選取多張卡片後，在右欄下半部輸入標籤，按 Enter 或「加上」 |
| 顯示 | 白板上的卡片在標題下方顯示 #標籤（縮小到概覽時隱藏）；卡片庫與關係圖可以依標籤篩選 |

### 卡片庫
左欄最上方的「🗂 卡片庫」：所有卡片的總覽（參考 Heptabase 的 Card Library），包括不在任何白板上的卡片。

| 功能 | 說明 |
|---|---|
| 卡片 | 以格狀顯示標題、標籤、最多 5 行內容摘要、所在白板、連結數、引用文獻數與修改日期；點一下在側邊面板開啟 |
| 搜尋 | 比對標題與內容 |
| 位置 | 全部／在白板上／不在白板上 |
| 排序 | 最近修改、最近建立、標題（沒有標題的排最後） |
| 標籤 | 點標籤只顯示有這個標籤的卡片，再點一次或點「全部標籤」取消；顯示每個標籤的卡片數 |
| 新卡片 | 「＋ 新卡片」建立不在任何白板上的卡片並在面板中開啟 |
| 記住 | 位置、排序與標籤篩選會記住 |

### 右欄
| 區塊 | 說明 |
|---|---|
| 卡片／文獻清單（上半部） | 兩個分頁：「🗒 卡片」列出所有卡片（最近編輯的在前，最多 50 張；在目前白板上的標 ✓），每張在標題下方顯示最多 3 行內容（Markdown 轉成純文字摘要，段落以「·」分隔；沒有內容時顯示「（沒有內容）」），「📚 文獻」列出 Drawer 條目（最多 100 筆）；上方搜尋框篩選。點卡片在側邊面板開啟（在目前白板上的也會選取並捲動過去），雙擊文獻在 Drawer 中開啟 |
| 拖曳到卡片上 | 卡片 → 兩張卡片建立雙向連結；文獻 → 那張卡片引用這筆文獻。拖曳時目標卡片會高亮，游標旁顯示會發生什麼（例如「連結到「X」」「已經連結了」「讓「X」引用」） |
| 拖曳到空白處 | 卡片 → 放到白板上放開的位置（已經在這個白板上就跳過去）；文獻 → 建立一張引用它的筆記卡片「筆記：條目標題」，放在放開的位置 |
| 取消拖曳 | 按 Esc，或在畫布以外的地方放開 |
| 選取的卡片（下半部） | 卡片標題、「刪除卡片」、連結清單、引用的文獻清單（各有 × 可移除）；沒有選取卡片時顯示提示 |
| 多張卡片（下半部） | 選取多張時改為「已選取 N 張卡片」：包成區塊、為全部加上標籤、刪除全部、取消選取 |

### 連結（雙向可見、可指向、可加備註）
一對卡片只會有一條連結，兩張卡片的連結清單都會列出它（雙向鏈結）。連結可以有方向（箭頭）和一段備註。

| 功能 | 說明 |
|---|---|
| 預設方向 | 拖曳圓點或從右欄拖曳建立的連結，箭頭指向放開的那張卡片；`[[ ]]` 建立的連結，從寫 `[[ ]]` 的卡片指向被提到的卡片；升級前就有的連結維持無方向 |
| 編輯方向與備註 | 點連線（或線上的備註）選取，右欄下半部變成「連結」：方向四選一（A → B、B → A、↔ 雙向箭頭、— 無方向），以及備註（例如「支持」「反駁」「導致」）；Enter 儲存，Shift＋Enter 換行。雙擊連線直接跳到備註框 |
| 畫布上 | 有方向的一端畫箭頭（沒有箭頭的一端是圓點）；備註以小標籤顯示在線段中間，點標籤也能選取連結 |
| 連結清單 | 選取卡片時，每條連結前面標 → （這張指向它）、←（它指向這張）、↔ 或 —，有備註時顯示在標題下方 |

| 功能 | 說明 |
|---|---|
| 拖曳建立 | 滑鼠停在卡片上時，右側出現圓點；把圓點拖到另一張卡片上放開。拖曳時顯示虛線，目標卡片會高亮 |
| 從右欄拖曳 | 把右欄清單中的卡片拖到白板上的卡片（見「右欄」）；可以連到不在這個白板上的卡片 |
| 畫布上的連線 | 只畫出兩端都在這個白板上的連結；線從卡片邊緣連到另一張卡片的邊緣 |
| 移除連結 | 點連線選取後按 Delete 或線中央的 ×，或在右欄連結清單按 × |
| 連結清單（右欄） | 列出所有連到這張卡片的卡片；卡片在其他白板時顯示白板名稱 |
| 跳到連結的卡片 | 點清單中的卡片：同一個白板就捲動過去並選取；在其他白板就切換過去 |
| 不能連到自己 | 同一張卡片不能連結到自己；重複連結時提示「已經連結了」 |
| 用 `[[ ]]` 建立 | 卡片（白板或 Drawer 筆記卡片）存檔時，內容中每個 `[[標題]]` 都會和同標題的卡片建立連結；反過來，先寫了 `[[X]]`、之後才建立或改名成 X 的卡片，存檔時也會連上。同名卡片有多張時，優先選同一個白板上的，再選最近編輯的。建立新連結時提示「依 [[ ]] 建立了 N 條連結」。只會新增、不會自動移除：刪掉 `[[ ]]` 後連結仍保留，需要手動移除 |

### 卡片內容的 Markdown
所有模組共用同一套 Markdown 語法（`src/markdown/`，以 unified / remark 為基礎）。白板卡片與 Drawer 筆記卡片都使用。

編輯器是所見即所得（Milkdown：ProseMirror ＋ remark），存檔仍是 Markdown 文字：
- 輸入 Markdown 符號會直接變成格式，例如行首 `## ` 變標題、`**粗體**`、`- ` 變清單、`> ` 變引用；Ctrl＋Z／Ctrl＋Shift＋Z 復原與重做。
- `[[卡片標題]]`、數學式、directive 這類編輯器沒有對應格式的語法，會顯示成排版後的「區塊」（和閱讀時一樣），存檔時原樣寫回、不會遺失。**雙擊區塊**可以編輯它的原始文字（清空即刪除）；點區塊裡的 `[[連結]]` 一樣會開啟卡片。
- 打完 `]]`，或貼上含有 `[[...]]` 的文字，會自動變成連結區塊；打完 `$...$` 會變成數學式區塊。

| 語法 | 說明 |
|---|---|
| 基本與 GFM | 標題、粗體／斜體、清單、引用、程式碼、表格、待辦清單（`- [ ]`）、刪除線、自動連結 |
| 數學式 | `$行內$`、`$$區塊$$`（KaTeX） |
| `[[卡片標題]]` | 連到同標題的卡片（英文不分大小寫）；`[[標題\|顯示文字]]` 可改顯示文字。點一下先找目前白板，再找其他白板並切換過去；找不到時提示。存檔時自動建立雙向連結（見「雙向連結」） |
| 自動完成 | 編輯時輸入 `[[` 會在游標下方列出卡片標題（最多 8 個，排除正在編輯的卡片），邊打邊篩選；↑ / ↓ 選擇，Enter 或 Tab 插入連結區塊，Esc 關閉清單。白板卡片與 Drawer 筆記卡片都有 |
| 提示框 | `:::note`、`:::tip`、`:::warning` … `:::` |
| 自訂語法（directive） | `:名稱[文字]{屬性}`、`::名稱{屬性}`、`:::名稱` … `:::`；尚未定義的名稱會保留內容顯示。像 `10:30`、`note:abc` 這類一般文字不受影響 |
| 外部連結 | 用系統瀏覽器開啟 |

- 不會顯示原始 HTML（安全考量）。
- 擴充方式：新功能一律用 directive，在 `src/markdown/directives.tsx` 以 `registerDirective` 註冊顯示方式，不需修改解析器。

### 引用 Drawer 條目
| 功能 | 說明 |
|---|---|
| 卡片上的標籤 | 卡片引用的條目顯示在卡片底部（類型圖示＋標題），滑鼠停留顯示作者與年份；點一下切換到 Drawer 並選取該條目 |
| 引用條目 | 從右欄「📚 文獻」把條目拖到卡片上；拖到空白處則建立引用它的新筆記卡片 |
| 取消引用 | 右欄下半部「引用的文獻」清單的 × |
| 雙向 | 條目的詳情欄「筆記卡片」會列出所有引用它的卡片 |
| 放上已有卡片 | 從右欄「🗒 卡片」把卡片（例如在 Drawer 寫的筆記）拖到白板空白處（取代原本標題列的「＋ 已有卡片」） |

### 資料
- 卡片與白板分開存放（`cards`、`board_cards`），同一張卡片可以出現在多個白板上。
- 區塊存在 `board_sections`（每個白板各自的區塊），卡片標籤存在 `card_tags`（不分大小寫，和 Drawer 條目的標籤分開）；資料庫 v9。
- 連結存在 `card_links`，每對卡片只存一筆（id 小的在前），兩邊都能查到；`direction`（0 無、1 前→後、2 後→前、3 雙向）和 `note` 記錄方向與備註。
- 資料夾存在 `whiteboard_folders`（`parent_id` 巢狀），白板的 `folder_id` 指向所在資料夾（資料庫 v7）。
- 刪除白板時，只刪除**不在其他白板上**的卡片。

### 已知限制
- 第一次編輯一張卡片後，存檔的 Markdown 會被整理成編輯器的寫法（例如清單符號、空行、跳脫字元），排版結果不變，但原始文字可能和手寫的不同。
- 數學式、directive、`[[ ]]` 區塊只能雙擊後在對話框裡改原始文字，不能在卡片中直接編輯；待辦清單的勾選框不能直接點選切換。
- 右欄清單一次只能拖一個項目；卡片清單最多顯示 50 張、文獻最多 100 筆，其餘需要搜尋。
- `[[ ]]` 建立的連結不會隨文字刪除而自動移除（連結表沒有記錄來源，無法分辨是手動或 `[[ ]]` 建立的）。
- 反向比對只認完整的 `[[標題]]` 或 `[[標題|`，括號內多了空白（例如 `[[ 標題 ]]`）不會被反向找到；寫在程式碼區塊裡的 `[[ ]]` 也會被反向比對到。
- 自動完成的清單在打字後約 0.1 秒才更新，打得很快時按 Enter 可能變成換行。
- 白板操作（移動、刪除、連結、區塊）沒有復原（Undo），復原只在卡片內容編輯器中有效。
- 區塊不能互相包含（巢狀）；區塊的成員是「完全在區塊裡的卡片」，移動時才計算，沒有另外記錄。
- 多選只能選卡片，不能同時選取區塊或連線；多張卡片還不能一次調整大小或一次建立連結。
- 卡片標籤和 Drawer 條目的標籤是兩套。
- 卡片庫一次最多顯示 1000 張。
- 畫布的位置與縮放不會記住，每次開啟白板都會自動縮放到全部卡片。
- 一個白板只能放在一個資料夾裡。
- 只在瀏覽器中以模擬後端測試過，尚未在真實視窗中操作。

## Graph（關係圖）

獨立的模組（左側直欄 🕸 Graph），不屬於 Whiteboard 或 Drawer：把卡片、卡片之間的連結，以及卡片引用的 Drawer 條目畫成一張力導向圖。資料來自 Whiteboard 的卡片與連結和 Drawer 的條目。

### 範圍（左欄）
| 選項 | 顯示 |
|---|---|
| 🕸 全部卡片 | 所有卡片，包括不在任何白板上的 |
| 📁 資料夾 | 這個白板資料夾裡所有白板上的卡片（含子資料夾）；▸ 可開合，開合狀態會記住 |
| 🧩 白板 | 這個白板上的卡片（右側顯示卡片數） |

- 選擇的範圍會記住；記住的白板或資料夾被刪除時改回「全部卡片」。
- 左欄下方的「標籤」：點一下只顯示有這個標籤的卡片（和範圍一起套用），標題會加上「· #標籤」。
- 連結只畫兩端都在範圍內的。

### 圖
| 功能 | 說明 |
|---|---|
| 節點 | 卡片是圓點；勾選「顯示文獻」時，卡片引用的 Drawer 條目是方形節點，以虛線連到引用它的卡片 |
| 連線 | 依連結方向畫箭頭；備註顯示在線段中間 |
| 操作 | 拖曳節點調整位置、拖曳空白處平移、滾輪縮放；點節點只亮出它和相鄰的節點，左下角顯示名稱、所在白板與相鄰數 |
| 開啟 | 雙擊卡片（或按「在白板中開啟」）切換到 Whiteboard，開啟它所在的白板並選取；不在任何白板上的卡片會提示無法開啟。雙擊條目在 Drawer 中開啟 |
| 排列 | 開啟時先計算好大致的佈局再顯示；↻ 重新排列、⤢ 顯示全部 |

### 已知限制
- 節點位置不會保存，每次開啟重新排列。
- 排列是每對節點互相計算，卡片很多（數千張）時會變慢；目前只有範圍篩選，沒有搜尋或依標籤篩選。
- 連結的方向與備註只能在 Whiteboard 中編輯，關係圖是唯讀的。
- 範圍只能依白板與資料夾選擇，還不能依 Drawer 的資料夾或標籤選擇。
