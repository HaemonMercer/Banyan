## Markdown 區塊編輯器（`src/editor/`）

- **文件就是 Markdown**：文件本體永遠是一段 CommonMark 字串；畫面上的區塊是用 markdown-it（`commonmark` 預設）解析後切出來的視圖。每個區塊記住自己在原始碼的行範圍。
- **CommonMark 0.31.2**：652 個規格範例全部通過，由區塊組回的 HTML 與規格逐字相同，不做正規化（`npm test`）。測試也確認每個非空白行都屬於某個區塊。
- **區塊**：段落、標題、程式碼、引用、分隔線、HTML 區塊各是一個區塊；頂層清單的每個項目各是一個區塊。連結參考定義沒有輸出，以灰色原始碼區塊顯示，仍可編輯。
- **所見即所得編輯**：點區塊就在原地直接編輯排好的文字（粗體、斜體、顏色、連結都照最後的樣子顯示，游標放在點到的字上），不再看到 Markdown 原始碼。區塊語法（`# `、`- `、`1. `、`> `）不顯示，只編輯後面的內容；每次輸入都把內容轉回行內 Markdown，只改動該區塊的行，其他原始碼一字不動。使用者打的 `*`、`_`、`[`、`<`、行首的 `# `、`- `、`1. `、`> ` 等會自動跳脫，不會意外變成格式。強調在 CommonMark 規則下不成立時（例如中文標點旁的粗體）自動改用 `<strong>`／`<em>`。打出 ```` ``` ```` 等會吞掉後面內容的語法時，編輯區自動擴大涵蓋受影響的區塊。
  - 段落開頭打 `# `、`## `、`### `、`- `（或 `* `、`+ `）、`1. `、`> `、```` ``` ```` 直接轉成對應的區塊（像 Notion）。
  - 有選取時按粗體等格式（含顏色、連結）：以畫面上選到的字為準切換（選取裡看得到的字全部都有這個格式就拿掉，否則全部加上；空白不算），選取保留在同一段文字上。不受選取邊界剛好落在 `**` 記號旁影響；跨過好幾段格式也可以。
  - 沒有選取時按粗體等格式（含顏色）：接著打的字就有（或沒有）那個格式，狀態列立即顯示；之後每打一個字、輸入法每選好一個詞都會確認格式正確（就算瀏覽器或輸入法把字插進原本的粗體裡也會搬出來），直到游標移走。在粗體中間按 Enter，前後兩段都保有粗體。
  - 連結：Ctrl＋K 或格式列的連結按鈕開啟網址輸入框，Enter 套用、Esc 取消；在連結裡再按就拿掉連結。
  - 貼上：單行文字以純文字貼上（不帶網頁格式）；多行或 Banyan 區塊照區塊貼上。
  - 程式碼區塊、HTML 區塊、參考連結定義、分隔線，以及無法拆開的複雜區塊（含巢狀清單或多個段落的清單項目、多段引用、Setext 標題）仍用原始碼文字框編輯。
- **鍵盤**：Enter 切成新區塊（清單項目延續同樣的標記與編號；空項目按 Enter 離開清單；程式碼區塊內是一般換行）；Shift＋Enter 硬換行（行尾 `\`）；在開頭按 Backspace 先去掉區塊前綴，再與上一個區塊合併；上下左右鍵在區塊間移動；清單中 Tab／Shift＋Tab 縮排；Esc 離開編輯並選取該區塊；Ctrl＋Z／Ctrl＋Y（Ctrl＋Shift＋Z）復原與重做，連續打字合併成一筆。
- **行內格式與下方格式列**：編輯區塊時，畫面下方出現一個小格式列：左邊是區塊類型，中間是粗體 **B**、斜體 *I*、底線 U、刪除線 S、行內程式碼 `</>`、連結、顏色「A▾」按鈕，右邊顯示游標所在文字的狀態（「粗體」「底線・刪除線」「紅字・黃色螢光・藍底」「一般文字」…），啟用中的按鈕以藍色標示。狀態用 markdown-it 解析判斷，與 CommonMark 渲染結果一致（不成對的 `**` 不算粗體）。
  - 切換：按鈕或快捷鍵 Ctrl＋B／I／U／E／K、Ctrl＋Shift＋X（刪除線）。有選取時包住選取文字（前後空白留在記號外，選取保留在文字上），選取已是該格式時取消，選取在格式中間一段時前後保留原本格式；沒有選取時，在格式裡就取消整段，不在就放一對記號讓接著打的字有格式。行內程式碼內容含反引號時自動加長；連結包成 `[文字](https://)` 並選取網址，在連結裡再按就拿掉連結保留文字。
  - 顏色選單（A▾）：文字顏色、螢光標記、區塊背景三排，各有「預設」與九種顏色（灰、棕、橘、黃、綠、藍、紫、粉紅、紅，與 Notion 相同，淺色／深色模式各有對應的色調）。選「預設」拿掉顏色；游標在有顏色的文字裡沒有選取時整段換色；在紅字中間選一段換成藍字時前後仍是紅字；選取裡原有的同種標籤會先拿掉，不會層層疊。區塊背景作用在整個區塊（清單是整份清單），設定後仍在編輯同一個區塊。區塊選單（⋮⋮）也有「背景顏色」，多選時套用到每個區塊。
  - 儲存格式：CommonMark 沒有刪除線、底線、顏色，用 CommonMark 允許的行內 HTML：`<s>刪除線</s>`、`<u>底線</u>`、`<span class="red">紅字</span>`、`<mark class="yellow">螢光</mark>`（`<mark>` 沒有 class 時是黃色）；區塊背景用區塊容器 `<div class="bg-blue">`（與縮排、多欄相同的寫法）。標籤之間的文字仍照常當 Markdown 解析。有背景色的區塊搬移、縮排、當父區塊時背景色跟著區塊走。
  - 程式碼、HTML、參考連結區塊中行內格式按鈕停用（顯示「原始文字」），但可以設定區塊背景。
- **圖片、GIF、影片**：斜線選單的「圖片」「影片」開啟選擇檔案視窗（可多選）；編輯中貼上圖片（截圖、複製的圖片檔）；從檔案總管把檔案拖進頁面（放在滑鼠位置最近的區塊後面）。檔案複製到 App 資料夾的 `media/`（以內容雜湊命名，同一個檔案只存一份），Markdown 寫相對路徑；顯示時換成 Tauri asset protocol 的網址。只有前端（瀏覽器預覽）時改用 data URL。
  - 圖片、GIF 是 CommonMark 的圖片：`![說明](media/xxx.png)`（說明預設是檔名）；影片是 HTML 區塊 `<video src="media/xxx.mp4" controls>` ＋ `</video>`。
  - **圖說**：圖片、影片下方可以直接點來輸入圖說，Enter 或點別處儲存、Esc 取消；沒有圖說時只在滑過或選取時出現「加上圖說…」。圖說一律在圖片（影片）上方或下方的中央，寬度與圖片相同（長的圖說會換行）。CommonMark 沒有圖說語法，寫成圖片標題 `![說明](media/x.png "圖說")`（其他軟體顯示成滑鼠提示），影片寫成 `title` 屬性；引號、`<`、`>`、`&` 會跳脫。
  - **圖說位置**：選單可以切換圖說在上方或下方。上方存成外層容器 `<div class="caption-top">`（和對齊、背景色一樣算是區塊的一部分，可以同時存在），下方就是沒有容器。
  - **物件選單**：選取圖片、影片時，上方浮出選單：對齊（靠左、置中、靠右）、大小（原始、25%、50%、75%、100%）、圖說（「圖說」按鈕直接進入圖說編輯、上方／下方）。選單跟著圖片的對齊位置。
  - **大小**：寬度是版面寬度的百分比，存成外層容器 `<div class="width-50">`（25／50／75／100），原始大小就是拿掉容器；可與對齊、圖說位置、背景色同時使用。
  - **對齊**：CommonMark 沒有對齊語法，置中、靠右存成外層容器 `<div class="align-center">`／`<div class="align-right">`（與背景色相同的寫法），靠左就是拿掉容器；可與區塊背景色同時使用，搬移、縮排時跟著區塊走。
  - 點圖片或影片是選取（可拖曳、刪除、複製），影片的播放控制照常可按；連按兩下開啟原始碼編輯（改說明或路徑）。插入的區塊若是空白區塊就直接取代，否則放在下面，插入後選取。
- **表格**：斜線選單的「表格」插入 3×3（第一列是標題列）。CommonMark 沒有表格語法（`|` 表格是 GFM），存成 HTML 區塊 `<table>`（每列一行、沒有空行），任何 CommonMark 渲染器都會照樣顯示。點表格進入表格編輯：每格是純文字，Tab／Shift＋Tab 換格（最後一格再按 Tab 新增一列）、Enter 到下一列（最後一列會新增）、Shift＋Enter 換行、上下方向鍵換列、Esc 完成並選取表格；上方工具列可新增列（下方）、新增欄（右邊）、刪除列、刪除欄、切換標題列。`<`、`&` 等自動跳脫。
- **斜線選單**：在行首或空白後輸入 `/` 開啟，可打字篩選（中英文關鍵字），方向鍵與 Enter／Tab 選擇：文字、標題 1～3、項目清單、編號清單、引用、程式碼、分隔線。
- **區塊把手**：滑到區塊左側出現「＋」（在下方新增區塊並開啟斜線選單；清單項目後新增同一份清單的項目）與「⋮⋮」（拖曳搬移，點擊開啟選單：刪除、複製、轉換成各種類型）。拖曳時有跟著滑鼠的預覽與藍色插入線，Esc 取消；用指標事件實作，不用 HTML5 拖放（Tauri 在 Windows 上的檔案拖放功能會攔截它）。
- **縮排（子區塊）**：編輯中按 Tab 增加縮排、Shift＋Tab 減少縮排（清單項目仍是清單的巢狀縮排；程式碼區塊內 Tab 插入空格）；區塊選單也有「增加縮排」「減少縮排」。縮排後的區塊是**上方區塊的子區塊**：搬移、刪除、建立副本、拖到旁邊成欄時，父區塊連同子區塊一起；放到子區塊上下就成為同一個父區塊的子區塊；放到有子區塊的區塊「下方」時接在子區塊之後。**縮排只有一層**：已縮排的區塊不能再縮、有子區塊的區塊不能放進縮排；縮排有子區塊的區塊時，子區塊一起移進來成為同層；舊文件裡的巢狀縮排會在下次整理時攤平。上方沒有區塊（文件或欄位的第一個區塊）時不能縮排。減少縮排時，原本在它下面的兄弟區塊變成它的子區塊。空白區塊也可以先按 Tab 再打字。
- **多欄**：把區塊拖到另一個區塊的右側（右邊四分之一）或左緣，出現藍色直線，放開後兩者並排成兩欄；拖到欄位中的區塊旁邊會在多欄中再加一欄。欄位中的區塊可上下搬移、拖出欄外；一欄空了就自動移除，只剩一欄時取消多欄。拖曳欄位之間空隙左半邊的細線可調整欄寬（最小 64px）。欄位中的把手只留拖曳鈕。
- **版面的儲存格式**：CommonMark 沒有欄位與縮排，用 HTML 區塊包起來——`<div class="columns">`、`<div class="column">`（欄寬寫成 `style="flex: 1.44"`）、`<div class="indent">`，每個標籤自成一行、前後空行，中間的內容照常當 Markdown 解析，所以仍是合法的 CommonMark，任何 CommonMark 渲染器都會輸出對應的 `<div>`。編輯器把這些標籤藏起來，以欄位與縮排顯示；標籤不配對時當一般 HTML 區塊顯示。字數不計標籤。
- **空白區塊**：允許空白區塊（像 Notion 一樣可以留空行）。CommonMark 沒有空段落，空白區塊存成只有 `&nbsp;` 的段落（任何 Markdown 軟體都顯示成一個空行）；編輯時編輯框是空的，離開時才寫回 `&nbsp;`。連按 Enter 會留下多個空白區塊；在段落開頭按 Enter 會在上方多一個空白區塊；空白區塊按 Backspace 刪除。空的清單項目也保留。只有整份文件只剩一個空白區塊時離開才清空。點文件下方空白處時，若最後一個區塊是空白區塊就直接編輯它。字數不計 `&nbsp;`。
- **區塊選取與多選**：
  - 選取方式：編輯中按 Esc 選取該區塊；點 ⋮⋮ 選取並開啟選單；在頁面空白處（左右邊界、文件下方）按住拖曳框選；在區塊文字上按住拖到別的區塊，選取中間所有區塊；Shift＋點擊從起點延伸；Ctrl＋點擊加入或移出；未編輯時 Ctrl＋A 全選（編輯中文字已全選時再按 Ctrl＋A 也是全選）。選取的區塊以淡藍底標示，父區塊被選取時子區塊一起標示。
  - 對選取的操作：↑／↓ 移動選取、Shift＋↑／↓ 延伸；Enter 編輯第一個；Delete／Backspace 刪除（之後選取附近的區塊）；Tab／Shift＋Tab 一起縮排；Ctrl＋D 建立副本（選取副本）；Ctrl＋C／Ctrl＋X 以 Markdown 複製、剪下；Ctrl＋V 把剪貼簿的 Markdown 貼在選取區塊後面（選取貼上的區塊）；在編輯中的區塊裡貼上複製的區塊（或多行 Markdown）時，直接貼成區塊：在游標處把區塊切開，貼上的區塊放在中間並選取（程式碼區塊與單行文字照一般文字貼上）；複製同一份清單中相鄰的項目時保持緊湊清單；Esc 或點空白處取消。
  - **整組多欄**：多欄裡的區塊全部被選取時（例如框選兩欄），整組多欄當成一個單位——搬移、複製、建立副本、剪下、刪除都保留 `<div class="columns">` 與欄寬，拖曳預覽顯示「多欄排版」；只選部分欄位時照常把那些區塊搬出欄外。整組多欄不能放進另一個欄位（不做巢狀多欄），也不會被轉換類型或縮排。
  - 拖曳選取中任一區塊的 ⋮⋮ 會一起搬移（保持原順序，搬完仍選取），拖到旁邊則一起成為新的一欄。選取多個時區塊選單顯示「已選取 N 個區塊」，轉換類型、縮排、建立副本、刪除都套用到全部。
- **連結**：一般點擊是編輯；按住 Ctrl 點擊用系統瀏覽器開啟（`tauri-plugin-opener`）。
- **安全**：顯示前以 DOMPurify 清理 HTML，Markdown 中的 `<script>`、事件屬性等不會執行。
- **介面**：Notion 風格的置中頁面（最寬 720px），深色模式跟隨系統。文件開頭的一級標題放大成頁面標題；中文用 700 粗細，避免中文字型沒有半粗體而顯示成一般字重。編輯中的區塊以淡藍底與細框標示，右側（寬視窗）顯示區塊類型與 Esc 提示。把手、選單用 SVG 圖示；斜線選單每項有說明與 Markdown 語法，底部有按鍵提示；區塊選單標出目前類型，靠近視窗邊緣時往內收。頂端列為「Banyan / 文件標題」、儲存狀態、字數（中日韓文字每字一個）與「原始碼」切換；原始碼面板有標題列與關閉按鈕。視窗預設 1100×760，最小 520×400。文件自動存到 localStorage。

### 已知限制

- 複雜區塊（巢狀清單、多段落）與程式碼區塊仍以原始碼編輯。
- 編輯過的區塊會重新產生行內原始碼：參考式連結變成行內連結、軟換行變成空白、`__粗體__` 變成 `**粗體**`（渲染結果相同）；沒編輯過的區塊不受影響。
- 巢狀清單、引用內的內容跟著外層區塊一起編輯，沒有再拆成更小的區塊。
- 欄位與縮排只能包整份清單，不能只包清單中的一個項目；清單項目的 Tab 是清單巢狀，不是縮排區。
- 欄位與縮排在其他 Markdown 軟體中只會是沒有樣式的 `<div>`（GitHub 等會移除 `class`／`style`），內容仍正常顯示。
- 只支援 CommonMark，不含 GFM（`|` 表格、待辦清單）；表格以 HTML 區塊儲存，儲存格只有純文字；刪除線、底線、顏色以行內 HTML 儲存，在 GitHub 等會移除 class 的地方只會剩下刪除線與底線。
- 還不能開啟或儲存 `.md` 檔。

## 日記（`src/journal/`，參考 Logseq）

- **每天一頁**：每天的日記是一份獨立的 Markdown，用同一個區塊編輯器編輯（所有編輯功能都能用：斜線選單、格式、圖片、表格、多欄…）。
- **儲存**：App 資料夾的 `journals/` 底下，一天一個檔，檔名與 Logseq 相同（`2026_11_17.md`）；打字後 0.4 秒自動寫入，關閉視窗前會把沒寫的寫掉。內容刪光（只剩空白或空白區塊）就刪檔。`journals/` 與 `media/` 在同一層，所以日記裡的 `media/檔名` 圖片照常顯示。只有前端（瀏覽器預覽）時存在 localStorage。
- **日記串**（頂端列「日記」）：像 Logseq 的 Journals，今天在最上面（還沒寫也會出現，顯示「今天發生了什麼？」提示），往下是以前寫過的日子，新的在前；每次顯示 10 天，捲到底再載入更早的。每天的標題是「11 月 17 日」（不是今年的加上年份）、星期，與「今天／昨天／前天」標籤。日期跨過午夜會自動換成新的一天。
- **單日頁面**：點日記串裡的日期標題開啟。上方有前一天／後一天，以及「上一篇／下一篇」（跳到前後有寫的日記）；還沒寫的日子會提示「打字就會建立」。
- **月曆**（頂端列「日曆」）：月份切換、有寫日記的日子有圓點、今天以藍字標示、底下顯示這個月寫了幾天；點任何一天（含未來）開啟那天的單日頁面。「今天」按鈕直接開今天。
- **好幾個編輯器並存**：日記串裡每天各是一個編輯器。復原（Ctrl＋Z／Y）、區塊選取的按鍵、Ctrl＋A、剪貼簿只作用在最後操作的那一天；點到別天時，原本那天自動結束編輯並取消選取。
- 頂端列的原始碼面板與字數跟著目前的頁面（單日頁面、文件）；日記串不提供原始碼面板。上次開啟的畫面（日記串、某一天、文件）會記住。

- **筆記符號**：日記裡一般的清單項目以「–」顯示（子彈筆記的筆記），任務是「•」、事件是「○」。
- 單日頁面下方有反向連結（`[[2026-11-17]]` 連到那一天）。

### 已知限制

- 還沒有標籤（`#標籤`）與全文搜尋。
- 區塊不能從一天拖到另一天（可以複製貼上）；方向鍵不會跨到上一天或下一天。

## 頁面連結與反向連結（`src/pages/`，參考 Logseq）

- **寫法**：`[[頁面名稱]]`（與 Logseq、Obsidian 相同）。CommonMark 沒有這個語法，`[[名稱]]` 照規格渲染成普通文字；編輯器只在顯示時把它換成連結（不改 markdown-it 的規則，CommonMark 規格測試不受影響），在其他 Markdown 軟體裡就是「[[名稱]]」幾個字。名稱不分大小寫；`[[2026-11-17]]` 連到那天的日記。
- **輸入**：打 `[[` 跳出頁面建議（開頭相符的在前，沒有同名頁面時最後一項是「新增頁面」），↑↓ 選擇、Enter／Tab 確認、Esc 關閉；選好後寫成 `[[名稱]]`，游標放在後面。自己打完 `[[名稱]]` 也一樣是連結（所見即所得轉回 Markdown 時，完整的 `[[…]]` 不跳脫方括號；單獨的 `[` 照常跳脫）。編輯時連結後面放一個零寬空白，接著打的字不會跑進連結裡。
- **開啟**：點連結開啟那一頁（像 Logseq）；編輯中按住 Ctrl 點。方括號以淡色顯示。
- **頁面**：每頁一個 Markdown 檔，存在 App 資料夾的 `pages/名稱.md`（Rust 指令 `page_list`、`page_read`、`page_write`；Windows 不允許的字元與 `%` 寫成 `%XX`，和 Logseq 一樣是 URL 編碼）。被連到但還沒寫的頁面點開是空白頁，打字才建立檔案；內容刪光就刪檔。瀏覽器預覽時存在 localStorage。
- **反向連結**：頁面與單日頁面最下面列出「N 個反向連結」——哪些日記、頁面提到這裡，以及提到它的那幾個區塊（任務顯示符號），日記新的在前、頁面依名稱。點區塊開啟來源，點區塊裡的連結開啟那一頁。啟動時把所有日記與頁面讀進記憶體計算。
- **所有頁面**（頂端列「頁面」）：有內容的頁面加上被提到但還沒寫的頁面（標「還沒有內容」），顯示被幾份文件提到；上方輸入框可以搜尋，按 Enter 開啟或新增。

### 已知限制

- 頁面還不能改名或刪除（刪光內容會刪檔，但仍被提到時會留在清單裡）；改名不會更新其他文件裡的連結。
- 反向連結是唯讀的，不能在那裡直接編輯；沒有「未連結的提及」。
- 名稱裡不能有方括號；程式碼區塊與行內程式碼裡的 `[[…]]` 不算連結。

## 子彈筆記（`src/bujo/`，Bullet Journal）

- **快速記錄**：任務與事件是清單項目加上方括號標記（與 GitHub、Obsidian 的待辦寫法相容），畫面上以子彈筆記的符號顯示（SVG 圖示 `TaskIcon`，各種字型下大小一致、與第一行文字垂直置中；清單項目、右鍵選單、月誌、符號說明都用同一組），標記本身藏起來：

  | 符號 | 意義 | Markdown |
  |---|---|---|
  | □ 方框 | 任務 | `- [ ] 內容` |
  | 框裡 ✕ | 完成 | `- [x] 內容` |
  | 框裡 ← | 已排程 | `- [<] 內容 [[2026-11-20]]` |
  | 劃掉的方框 | 取消 | `- [-] 內容` |
  | ○ | 事件 | `- [o] 內容` |
  | – | 筆記 | `- 內容`（一般清單項目） |

  沒有傳統子彈筆記的「已遷移」`[>]`（2026-11-18 使用者要求拿掉）：要在別天做一律排程。以前寫的 `- [>] 內容` 現在只是普通的筆記文字。

- **輸入**：段落或清單項目開頭打 `[] `（或 `[ ] `）變成任務，`[x] ` 完成、`[o] ` 事件、`[<] ` 已排程、`[-] ` 取消也可以直接打。中文輸入法打出來的括號（「」【】［］〔〕）、全形字（ｘ、ｏ、○、＜…）與全形空白都認得；輸入法一次送出整串也會觸發（組字中不觸發，選好字時再檢查）。只有打字當下開頭變成快捷時才觸發，已經是這樣開頭的文字在後面繼續打字不會轉換。斜線選單與區塊選單有「任務」「事件」。任務按 Enter 下一行還是任務（事件之後還是事件），空的任務按 Enter 離開清單；開頭按 Backspace 先拿掉任務標記（變回筆記）。編輯中按 Ctrl＋Enter：任務切換完成，段落變成任務。
- **切換**：點符號切換任務 ↔ 完成（已排程的點了變完成，再點回到已排程，日期留著）；在符號上按右鍵開啟選單：任務、完成、取消、事件、筆記（拿掉符號）、排程到某一天（日期選擇器）。完成的文字變淡，取消加刪除線；已排程的在寫它的那天也變淡（要做的是排到的那天）。
- **待辦清單（核取方塊）**：和子彈筆記的任務分開的 Notion 風格待辦，畫面上是可以打勾的方框，勾選後文字變淡加刪除線。寫成 `* [ ] 內容`／`* [x] 內容`（清單標記用 `*`，任務用 `-`，在原始碼裡分得出來；其他 Markdown 軟體也都當成待辦）。段落開頭打 `*[] `（或 `* [] `、`*[ ] `）變成待辦，`*[x] ` 是勾好的；全形 `＊`、中文輸入法的「」【】與全形空白也認得（打 `* ` 先變成以 `*` 開頭的項目符號，接著打 `[] ` 就變成待辦）。斜線選單、區塊選單的「待辦清單」插入或轉換；Enter 下一行是未勾選的待辦；點方框或 Ctrl＋Enter 切換；沒有右鍵狀態選單。行事曆的「未完成」也會列出未勾選的待辦。
- **行事曆**（側邊欄「行事曆」、Alt＋2；取代原本的子彈筆記頁；參考 Google 日曆、Apple 行事曆、Thunderbird）：每日紀錄仍寫在日記裡，這裡是總覽與排程。
  - **版面**（依使用者畫的線框）：頁面標題就是 App 頂端列的「行事曆」，頁面本身不再有大標題。行事曆填滿整個內容區、不留白：上面一列左邊是目前範圍（「2026 年」「2026 年 11 月」「2026 年 11 月 15 – 21 日」「2026 年 11 月 18 日 星期三」）、「今天」、‹ ›（上一段／下一段），右邊對齊右欄是年／月／週／日切換（記住上次的檢視）與「?」說明；下面左邊是月曆或時間表，右欄上面是小月曆、下面是未完成，之間都用細線分隔。月曆的每一週平均分配高度，一格放得下幾項就顯示幾項（跟著視窗大小）；時間表與未完成各自捲動。視窗窄於 900px 時右欄排到下面，整頁捲動。
  - **快捷鍵**（游標不在輸入框時）：Y／M／W／D 年／月／週／日，T 今天，J、N、→ 下一段，K、P、← 上一段，C 新增（開在月曆上方；原本的「＋ 建立」按鈕拿掉了，點空白處也能新增）。
  - **年檢視**：12 個月的小月曆（視窗夠寬時排成 3、4 欄，自己捲動）。有項目的日子底色依數量變深（1、2、3 項以上三種深淺），有過期沒做的任務是紅字，今天藍色圓底；滑鼠停在日子上顯示「11 月 18 日 星期三：1 個事件、3 個任務」。點日子切到那天的日檢視，點月份名稱切到那個月的月檢視；‹ › 換年。
  - **月檢視**：星期日開頭，只顯示有這個月日子的週（5 或 6 週）。每格列出那天的任務與事件（排在寫的那天；沒時間的在前，有時間的依時間排並顯示開始時間），放不下的收成「還有 N 項」。點日期數字或「還有 N 項」切到那天的日檢視。今天的日期數字是藍色圓底，週末格子底色略深，別的月份的日子變淡，事件有淡藍底，過期沒做的任務是紅字。
  - **週檢視、日檢視**：上方是日期列（點日期切到日檢視；日檢視有「開啟這天的日記」），下面是「全天」列（沒有時間的項目）與 0–24 時的時間表（一小時 48px，打開時捲到早上 7 點或更早的第一個項目）。有時間的項目依開始、結束時間排成方塊（只有開始時間的算一小時），事件藍色、任務灰色；時間重疊的並排並互相蓋住一點（像 Google 日曆）。今天那一欄底色淡藍，有一條紅色的現在時間線（每 30 秒更新）。
  - **時間**：寫在內容最前面 `- [o] 14:00-15:30 開會`（也可以只寫開始 `9:30`），普通文字，其他 Markdown 軟體也看得懂（`time.ts`）。
  - **新增**：點月曆格子的空白處、全天列或時間表的某個時段（對齊半小時，預設一小時），在點的位置旁邊開新增視窗：標題、事件／任務（點時段預設事件，其他預設任務）、日期、開始／結束時間（「全天」清掉時間），Enter 或「儲存」加到那天日記的最後面（`[[連結]]` 保留）。改開始時間時結束時間跟著移。點外面或 Esc 關掉，關掉的那一下不會又開新的。
  - **詳細**：點項目開詳細視窗：標題（裡面的 `[[連結]]` 可以點）、排在哪天的日期標籤、「Schedule」（日期選擇器，重新排程；只有未完成、已排程的任務與事件）、開始／結束時間（直接改、「全天」拿掉時間）、狀態（排程過的是已排程、完成、取消；其他是任務、完成、取消、事件）、寫在哪天、「開啟日記」。點符號仍然是直接切換完成。
  - **拖曳**：同一天裡拖到時間表改時間（對齊 15 分鐘，長度不變）、拖到全天列拿掉時間。拖到別天就是排程：原本那行標成 `<`、行尾寫上日期（事件還是事件，只加日期），拖回寫的那天就取消排程；拖到時間表時一併改時間。完成、取消的拖到別天沒有作用。
  - **右邊面板**：小月曆（換月、點日期跳過去，今天藍色圓底，有項目的日子下面有一點）與「未完成」：排在今天以前、還沒做的任務，每個有「Schedule」（日期選擇器，可以選今天，原本的標成 <）與「Cancel」。  - 視窗窄於 980px 時右邊面板排到月曆下方。
- **日記的「該做的事」**（`DayAgenda.tsx`、`agenda.ts`）：日記串與單日頁面的每一天，標題下方列出：
  - **Today’s Tasks／Today’s Events**（其他天是「Tasks for Nov 20」「Events for Nov 20」）：排程到這天、寫在別處（別天的日記或頁面）的任務與事件，依時間排，附來源（「from Nov 16」或頁面名稱）與「Reschedule」。排到這天的任務照一般任務顯示（符號是 ←），點符號完成。寫在這天日記裡的不重複列出。未來的日子在單日頁面也看得到。
  - **Overdue**（只有今天）：未完成或已排程、排的日子（排程日期，沒有就是寫的那天）在今天以前的任務，附日期標籤、「Schedule」（可以選今天）與「Cancel」。
  - 沒有項目時整塊不顯示。
- **排程**（2026-11-18 使用者說明：不是搬過去，而是像附加日期一樣出現在那天的「該做的事」）：任務留在寫它的地方，標成 `<`、行尾寫上排到的日期 `- [<] 任務 [[2026-11-20]]`。行事曆把它排在那天（寫的那天不再出現），那天日記上方的「該做的事」列出它，那天的反向連結也有它；過了那天沒完成就出現在今天的 Overdue。重新排程只換日期；排回寫的那天就拿掉日期、變回任務。完成時日期留著（還是排在那天）。舊的沒有日期的 `[<]` 不會出現在行事曆。
- **沒有手動附加日期的操作**：日期只由排程寫入（右鍵選單「排程到」、行事曆的「Schedule」、詳細視窗、拖到別天、該做的事的「Schedule／Reschedule」）。
- 任務裡可以寫 `[[頁面]]`，專案或主題頁面的反向連結就會列出所有相關的任務。

### 已知限制

- 行事曆只看日記裡的任務；頁面裡的任務不會出現（但會出現在反向連結）。格子太小時文字會截斷。沒有重複的事件、提醒、拖曳改長度、刪除（用「取消」）；編輯器裡的時間只是普通文字。
- 排程日期只認一行的任務最後面的 `[[YYYY-MM-DD]]`；編輯器裡日期顯示成普通連結。
- 沒有優先（`*`）與靈感（`!`）符號、沒有集合（Collections）頁、沒有習慣追蹤表。

## 白板（`src/board/`，參考 Heptabase）

- **卡片就是文件**：白板上的卡片指向既有的頁面（`[[名稱]]` 那種）或某天的日記，內容不另外存；在卡片裡直接用同一個區塊編輯器編輯（所見即所得、斜線選單、`[[` 自動完成都能用），改的就是那份 Markdown。同一份文件在一個白板上只放一張，可以放在好幾個白板上。
- **儲存**：每個白板一個 JSON 檔 `whiteboards/名稱.json`（Rust 指令 `board_list`、`board_read`、`board_write`，檔名與頁面一樣 URL 編碼），只記卡片位置／大小／顏色、連線、區段；固定欄位順序、座標取到小數一位。只有前端時存在 localStorage。畫面位置與縮放是個人瀏覽狀態，存在 localStorage（`banyan.boardCamera.名稱`），不寫進檔案；第一次開啟時自動符合畫面。
- **新增卡片**：連按兩下空白處、工具列「Card」或右鍵「Add card here」開啟搜尋：頁面（有內容的與被提到的）、今天與寫過的日記；打 `YYYY-MM-DD` 是那天的日記；沒有同名頁面時可以「Create page」。已經在白板上的標「On board」，選它會捲到那張卡片。
- **操作**：拖標題列搬移（選取多張時一起動）；Shift／Ctrl＋點擊加入選取；空白處拖曳框選；方向鍵微調（Shift 一次 40）；拉右邊改寬、右下角改寬高（高度預設跟著內容，最高 440px 後在卡片裡捲動；連按兩下右下角或右鍵「Automatic height」恢復）；連按兩下標題列開啟頁面或日記；Delete 從白板拿掉（頁面不受影響）；Ctrl＋Z／Y 復原（焦點在畫布時；在卡片裡編輯時是編輯器的復原）；Ctrl＋A 全選。
- **連線**：滑過卡片時四邊出現圓點，拖到另一張卡片就連起來（帶箭頭的弧線，依兩張卡片的相對位置自動選邊）；點一下選取、連按兩下或右鍵加標籤、反轉方向、刪除。拿掉卡片時連線一起拿掉。
- **區段**：工具列「Section」（有選取卡片時包住它們）、右鍵「Add section here」或多選後右鍵「Group in a section」；拖標題時中心點在框內的卡片與整個在框內的區段一起移動；右下角改大小；連按兩下標題改名。
- **顏色**：卡片（標題列底色）與區段可設九種顏色，與編輯器相同。
- **平移與縮放**：滾輪／觸控板平移、Ctrl＋滾輪（捏合）以滑鼠為中心縮放（15%～250%）；按住空白鍵或滑鼠中鍵拖曳平移；右下角縮小、百分比（回到 100%）、放大、符合畫面；Ctrl＋＝／－／0、Shift＋1。背景點格跟著平移縮放。
- **白板清單**（側邊欄「Whiteboards」、Alt＋5）：縮圖（卡片、區段、連線的位置）、卡片數；上方輸入名稱 Enter 新增或開啟；滑過出現刪除（確認後刪除白板檔，頁面與日記保留）。白板可以收藏、會出現在「最近」。
- **放在哪些白板上**：頁面（反向連結上方）與單日日記下方列出放了它的白板，點了開啟。
- **編輯器配合**：編輯器的格式列、區塊選單、框選框、拖曳預覽、網址輸入框改用 portal 放到 `body`；斜線選單與頁面連結選單用 `Floating` 固定在編輯中區塊的下方（下面放不下就放上面）。在縮放、會捲動的卡片裡也不會被裁掉或跑位。

### 已知限制

- 卡片只能是頁面或日記，還沒有純文字卡片、圖片或手繪；也還不能從頁面或側邊欄拖曳文件到白板上。
- 頁面改名不存在（App 沒有改名功能），所以卡片不會跟著改名；`renameRef` 已準備好。
- 卡片很多時每張都是完整的編輯器，效能還沒最佳化（沒有依畫面範圍延遲載入）。
- 卡片裡的表格工具列、媒體物件選單仍在卡片內，卡片太小時可能被裁切。
- 縮放不是 100% 時，卡片裡編輯器的拖曳預覽與插入線位置以畫面座標計算，可能略有偏差。

## 介面（`src/shell/`）

- **左側邊欄**：今天、日記、行事曆、所有頁面、白板、文件；下方是「收藏」與「最近」（最近開過的 8 個日記或頁面，已收藏的不重複列出）。可收合（Ctrl＋），狀態記在 localStorage；視窗窄於 760px 時變成蓋在內容上的抽屜，切換畫面後自動收起。
- **頂端列**：上一頁／下一頁（App 內的瀏覽紀錄，最多 50 筆）、目前畫面的圖示與標題、收藏星號（只有單日日記與頁面）；右邊是儲存狀態、字數、日曆、原始碼。
- **收藏**：單日日記或頁面按星號或 Alt＋S 加入／取消，存在 localStorage（`banyan.favorites`）。
- **主題**：跟隨系統／淺色／深色，側邊欄底部切換（`banyan.theme`）。顏色仍是 `editor.css` 的變數；深色變數同時寫在 `@media (prefers-color-scheme: dark)` 的 `:root:not([data-theme="light"])` 與 `:root[data-theme="dark"]`，新增顏色變數時兩處都要加。`main.tsx` 在畫面出來前先套用，避免深色啟動時閃白。
- **快捷鍵**（`shortcuts.ts`，用 `KeyboardEvent.code`，避開編輯器已用的 Ctrl 組合鍵）：Alt＋T 今天、Alt＋1～5 切換畫面（5 是白板）、Alt＋←／→ 上一頁／下一頁、Alt＋↑／↓ 後一天／前一天的日記、Alt＋S 收藏、Alt＋M 原始碼面板、Ctrl＋ 側邊欄、Ctrl＋/ 快捷鍵一覽（含編輯器快捷鍵）。

### 已知限制

- 收藏與最近存在 localStorage，不跟著日記檔案走；頁面改名或刪除後，收藏裡的舊名稱不會自動更新。
- 還沒有全文搜尋或指令面板。
